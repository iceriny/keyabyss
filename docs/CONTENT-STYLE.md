# 咒典文案与图鉴

## 命名约定

保留「寒墨之书」「千纸夜行」「未完待续」「无瑕落款」等已有名称。新名称优先使用书、卷、页、纸、笔、墨、印、批注、标点等意象，同时保留流派或效果辨识度。例如「超导银墨」「灼痕行书」「凛冬残卷」「连笔字帖」。

界面统一称「咒典」；敌人身上的输入内容称「咒文」，菜单英文指令称「词令」。连续完词称「连笔」，释放终式所需的资源称「共鸣」。防御操作仍直接写「弹反」「闪避」，指南用「回锋」「折页」作辅助标题；生命、护盾、伤害等数值保持直白。四流派的施法计数为霜印、雷印、灵印、焰印。

## 稀有度与排序

`Relic.rarity` 支持 `common`、`rare`、`curse`、`awaken`；未填写时为普通。通灵羽毛笔和未完待续显式标为 `rare`，不再从用途标签 `tag` 推断稀有度。

图鉴和随身构筑共同使用 `src/ui/relic-presentation.ts`：普通 → 稀有 → 诅咒 → 觉醒，同级保留登记顺序。排序创建新数组，不改动内容登记及奖励抽取顺序。卡片同时展示稀有度文字、用途和对应墨色，觉醒前置名称直接读取内容定义。

## 页面与验证

遗物定义中的数值表达式与描述模板由 `src/shared/relic-values.ts` 展示，战斗与描述共用求值器，详见[遗物数值与公式](RELIC-VALUES.md)。图鉴和局外显示公式；局内显示当前构筑的计算结果，按住 `\` 显示数值及公式，松开或窗口失焦恢复。升级候选按取得下一层后的构筑预览，已持有遗物按当前层数计算。伤害预览采用当前目标词长，无目标时采用5字（长短词遗物采用7字/4字），以无错字普通施法、当前连笔为基准。卡片只显示效果与数值，不附加预览基准说明；底部统一提示「按住 `\` 显示详情」。固定常量保持原值。

对应验证：`node --test tests/relic-values.test.cjs` 和 `python -X utf8 tests/relic-values-browser.py`。

游戏面向桌面键盘操作，**不需要兼容小屏（移动端）布局**。默认不新增或维护移动端布局、断点和小屏适配测试，详见 [项目核心规则](../AGENT.md)。咒典、敌人、遗物和施法指南共用开放式双列卡片：半透明渐变、背景模糊、顶部渐隐刻线，无封闭边框和圆角。桌面低分辨率窗口保留内容滚动；指南拆分弹反和闪避，并提供术语页边注。

- `npm run test:ui`：已有交互回归。
