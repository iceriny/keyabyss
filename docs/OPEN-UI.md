# 金丝水晶 · 开放式 UI

本约定适用于书库、出征、战斗 HUD、奖励、事件、图鉴、设置与记录。材质和色系以[金丝水晶视觉规范](ART-DIRECTION.md)为准；这里定义信息组织与交互。实际实施范围见[阶段总结](STAGE-SUMMARY.md)。

## 开放的阅读空间

场景提供氛围，文字、留白、通透材质和局部金丝组织信息。阅读区域可以通过半透明染色、柔焦与渐隐光层获得深度；外缘融入场景，不形成实体矩形底板、四边框、圆角卡片或整块投影。

开放布局不禁止局部边框。内容组、控件或物件可用简约金边、金丝与短分隔线说明归属；禁止包围整个页面或弹层的外框。不要把所有内容无分区地铺开，也不把“没有边框”当作信息层级的替代品。

材质内部的金丝以自然弧线、藤蔓与叶脉般的纹样为主，局部镶边才承担清楚的轮廓。纹样不冒充按钮或输入进度。嵌入深度按视觉收益与性能成本选用，不要求每个容器增加实时深度效果，取舍遵循视觉规范。

标题、段落、图形和操作通过对齐与间距建立归属。需要增强阅读时，降低其后场景的对比与细节；不要给每个分组套一层同样的玻璃卡片。短提示可以有柔和局部背景，轮廓仍保持轻盈。

## 文字与操作

- 默认使用汇文明朝体；小字、词令和辅助说明使用京華老宋体 v3.0。正文、数字和词令始终清楚，模糊不作用于字形。
- 主要统计数字继承正确的信息层级，不被小字样式意外缩小。颜色按文字、状态与元素语义使用，不以金色替代全部强调。
- 按钮用文字、词令、短刻线和局部光表达操作区域。主操作更清楚，危险操作有直白说明和克制警示色。
- 鼠标悬停、词令匹配与选中状态可辨，禁用仍可阅读。普通控件不启用默认键盘焦点、Tab／方向键遍历、Enter 隐式确认或悬浮 Tooltip；必要说明在页面或显式详情中呈现。
- 所有可点击、可操作项提供可见词令，通过同一个真实控件执行操作。文本框由点击或对应词令显式进入编辑，编辑期间字符与编辑键不触发页面词令；滑条等需要连续调整的控件由词令显式取得调整归属，Esc 退出后恢复页面命令。
- 书库左右键切换法书、Enter 进入游戏是明确的页面操作，不建立按钮焦点链。战斗 Tab 切换目标、输入框内编辑按键保持各自语义；焦点取决于当前操作需要，不因按钮存在就自动分配。
- 按键提示共用具名按键组件，键帽与解释文字分层，不把所有快捷键写成裸文字。词令使用辅助字体，不能与按键提示混淆。
- 输入词咒悬浮显示，完成部分着法书色，进度沿短刻线柔和推进；字符确认即时生效，进度动效不延迟规则提交，不使用矩形输入框占据战场。减少动态时直接显示当前进度。

## 固定外层与内部滚动

弹层标题、返回、分类导航及确认／保存等主操作位置固定，正文或列表在自己的区域滚动。短内容保持自然高度，长内容不撑动整页。

切换记录、分类或详情前先确定稳定占位。远征记录左右列表可独立滚动，长构筑与错词区域有各自空间；切换空记录与长记录时，窗口、标题和按钮不跳动。

桌面键鼠是目标交互。全屏和窗口共享同一信息结构，按实际可用空间安排内容；空间紧张时先减少装饰和间距，保留正文、主操作与内部滚动。不新增移动端布局要求，也不把某个历史 CSS 视口或渲染纹理尺寸当作所有界面的设计坐标。

设计基准为 1920×1080，实际分辨率、窗口／全屏和 UI 缩放在设置中统一管理。标题下方、正文与滚动条之间、页尾上方分别保留有目的的留白；不靠放大整页内边距解决局部拥挤。滚轮连续输入累积平滑目标，拖动滚动条立即接管，减少动态直接定位。

## 图鉴与成长

图鉴以检索、分类、独立图案与固定详情帮助查阅。详情说明实际效果、当前层数和局内觉醒条件；长正文内部滚动，切换内容不使窗口或主要操作跳动。

线性成长展示当前进度、已取得的增益和下一里程碑，不需要分配页或图网络。出征前不要求购买、撤点或选择副书。

## 战斗 HUD 与词咒

生命和护盾显示细进度条与准确数值，数值范围来自实际状态。连笔数字与节拍刻度占位固定，变化反馈不搬动 HUD，不遮住正在输入的词与危险预警。

头顶词咒采用两端消隐的开放刻线、羽化阅读阴影和清楚字形；英文、前缀高亮与输入游标保持同一基线。“头顶中文释义”（词令 `translation`）控制敌人词咒下的中文，不控制底部施法提示。释义按实际字宽排成最多两行，超长省略，无释义时不留空行。未选中释义使用辅助灰色，选中后柔和转为暖色，已输入英文前缀独立高亮。

英文、释义和阅读阴影作为完整词咒组件共同渐入、定位与避让；选中词咒优先排列并置于其他词咒之上，限制在可读范围内，避开生命、连笔和底部施法 HUD。HUD 与词咒须在同一坐标系中判定避让，优先取离敌人头顶最近的可读位置，不能把 UI 缩放后的全局坐标当作页面坐标。因边缘或避让偏离敌人时，用轻量连接指示保持归属，不加矩形底板。

终式就绪、连笔和防御反馈使用短暂悬浮文字、局部光和刻线，不拦截鼠标，不挤动常驻读数。所有特效只展示已经发生或确定可用的状态。

完词后的目标词咒服从主术命中时序，不能在弹道仍在飞行时直接换成新词；入场和重新出现的词咒渐入。精灵、词咒和镜头读取同一帧显示位置，尚未有效锁定的外围入场敌人不显示可选词。曾被有效锁定的敌人保留词咒与交战资格，击退到边缘不能使正在输入的单词消失；在途主术占用词咒的隐藏时序仍然有效。伤害与弹反短反馈靠近发生位置，避免战场中央的长句播报；短反馈不换行，必要时相互避让。

## 奖励、路线与事件

可选内容始终是视觉中心。选项并列展示名称、图形、效果和实际代价；条件与当前不可用原因就近说明。基础补给和离开选项清楚可见。

当前法书、生命护盾与构筑摘要是辅助信息，字号、亮度和动效低于选项。摘要保留名称与层数，详细效果通过显式详情查看；长列表内部滚动。持续漂浮和光点限制在法书附近。

路线先说明付出与获得，再直接选择；实际扣血、恢复、奖励和挑战内容保持可比较。规则见[产品设计](PRODUCT-DESIGN.md)。

## 书库、启动与结算

准备出征在书库场景中展开，主法书位置稳定，配置围绕它出现，当前主操作有清楚转换。加载反馈对应真实进度，失败可理解、可恢复；不靠重复出现的法书和多层对话框表现进度。

字体与必要资源就绪后再展示正式内容。首次继续与全屏操作含义分开；设置预览能够解释调整效果，但预览表现不能冒充实际战斗性能。

胜利、战败、主动结束具有不同色彩与仪式反馈，之后回落到可读的战报。标题、返回、重试和继续操作固定，结果重要性通过层级与留白表达。继续挑战说明将进入的难度或周目及保留的遗物；与清空局内遗物的新开局明确区分。

结算首屏只显示结果、进度和少量关键统计；战斗详情、构筑和错词按需查看，在固定区域切换。种子、内容版本等复现信息放入导出数据，不常驻玩家画面。书库法阵是法书背后的氛围层，柔光与流光不得盖过法书或穿过正文形成高亮纹样。

## 图形、动态与验收

不用 emoji 充当游戏图标。每件遗物有可辨认的矢量物件图形，图鉴、记录与选择页共用；机制图形对应实际作用，不能只有换色。独立图形是内容完成的一部分。

减少动态时停止装饰旋转、漂移、脉冲、流光与粒子，保留状态、静态材质和操作反馈。暂停时画面和信息状态一致。

验收关注阅读与交互：键鼠可达、提示可读、固定操作不移位、长内容可滚动、搜索不被详情遮挡、奖励摘要不抢中心、战斗文字不被光效吞没。视觉品质由实际观察判断，几何或自动化结果不能代替审美检查。
