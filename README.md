# 键渊 · 失控咒典

**用键盘施法，在失控的咒典中写出下一章。**

键渊是一款可离线游玩的打字肉鸽游戏。输入敌人身上的单词释放法术，在弹幕中弹反、闪避，选择遗物组合自己的构筑，挑战更深的章节。

[反馈问题与建议](https://github.com/iceriny/keyabyss/issues) · [参与贡献](CONTRIBUTING.md) · [更新记录](docs/CHANGELOG.md)

## 你会玩到什么

- **四本法书**：冰霜、雷电、纸灵与火焰，各有不同的施法节奏与终式。
- **自由构筑**：选择遗物、搭配效果，让每次远征走向不同的流派。
- **打字与战斗结合**：双手打字，无需普通移动；用弹反和闪避应对逼近的威胁。
- **选择自己的词库**：内置小学、初高中、四六级等词库，也能导入自己的单词。
- **逐步挑战**：五档难度、三章九场，以及通关后的下一周目。

## 开始游玩

游戏面向 **桌面键盘与鼠标**，请使用支持 WebGL 2 的浏览器。推荐全屏体验。

拿到离线发行包后：

1. 完整解压，保留所有文件和文件夹，打开其中的 `index.html`。
2. 等待字体准备完成，点击「继续进入」；首次进入可调节声音、画质与动态效果。
3. 选择法书，点击「准备出征」，选好词库和难度后进入咒典。

离线包无需安装或启动服务器。若下载的是仓库源码，请先按[本地运行说明](CONTRIBUTING.md#本地运行)启动或构建；源码根目录的 `index.html` 不能直接双击游玩。

### 常用操作

| 操作 | 作用 |
| --- | --- |
| 输入敌人身上的单词 | 首字母锁定目标，完成单词施法；错字不会清空进度 |
| Space | 弹反近身弹道与接触攻击 |
| 方向键 / Alt | 定向闪避 / 自动选择落点闪避 |
| 单独按 Shift | 共鸣充满时释放终式 |
| Tab / Shift+Tab | 切换目标 |
| Backspace | 放弃当前咒文 |
| Esc | 暂停；在菜单中清空词令或返回 |

菜单也支持鼠标操作、Tab 导航和 Enter 确认。按钮旁的英文是「词令」，直接敲完即可执行。更多战斗说明可在游戏内「玩法」和「咒典」查看。

### 词库、设置与记录

在词库页导入自己的 TXT、CSV、TSV、JSON 或 JSONL 文件，预览后再确认。可参考[词库示例](examples/README.md)。导入在本机处理，主动点击「同步源词表」时才会联网获取词库。

设置中可以调整音量、画质、屏幕震动、大字号咒文和减少动态效果。运行不流畅时，可以先降低特效等级。

设置、自定义词库和最近 50 份战报保存在当前浏览器中。刷新会结束当前战局；清理浏览器数据会移除本地记录。需要保留的词库和战报，可以在对应页面导出备份。

## 提 Issue

遇到 Bug 或有新想法，欢迎[提交 Issue](https://github.com/iceriny/keyabyss/issues/new)。提交前可以先搜索已有讨论，看看是否有人遇到相同情况。

**报告问题时，尽量提供：**

- 游戏版本（设置 → 关于）、操作系统和浏览器版本。
- 从哪里开始、做了哪些操作，以及预期结果和实际结果。
- 相关截图或录屏；显示问题请附窗口大小、是否全屏和浏览器缩放比例。
- 如果与战斗或词库有关，附上法书、难度、遗物组合或能复现问题的词条。

**提出建议时，说明你想改善的体验和使用场景。** 不必先设计完整方案，也欢迎讨论平衡、操作体验和词库需求。

## 提 PR

欢迎修复问题、改善体验、补充文案与词库，或加入新的游戏内容。较大的玩法和架构调整，建议先开 Issue 对齐方向。

1. Fork 仓库，在自己的分支完成一个明确的改动。
2. 按[贡献指南](CONTRIBUTING.md)运行项目，并检查受影响的功能。
3. 提交 PR，说明解决了什么问题、修改后的表现和验证结果；界面改动请附截图或短视频。

不确定从哪里开始，也可以先提交复现步骤、文案建议或测试反馈。项目以桌面体验为目标，暂不以移动端和触屏适配为贡献方向。
