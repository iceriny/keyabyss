# 四书战斗遥测参考

本文列出四书平衡中值得观察的玩法事件、指标口径及解释条件，供未来需要测量时选择使用。实施计划和验收独立于遥测系统；是否采集，以及采集范围、存储方式和工具，按后续实际分析需求决定。

机制定义见[四书战斗机制](FOUR-BOOKS-DESIGN.md)，整体评估见[收益与难度评估](COMBAT-BALANCE-DESIGN.md)。观察位置按业务事件和状态转换描述，随实现结构调整仍保持相同含义。

## 分析问题与观察边界

| 分析问题 | 适合观察的事件边界 | 最少需要的事实 | 可得到的指标 |
| --- | --- | --- | --- |
| 实际输入换来了多少战果 | 词咒开始、有效进度、完成、施法提交、伤害结算及目标死亡 | 有效人工字符数、词长、错误、辅助完成、开始／完成时间、施法身份、实际伤害及目标 | 每有效字符伤害、每次施法战果、完词间隔与实际击杀时间 |
| 识别与转火占用多少时间 | 目标变化、首个有效输入、完词和下一次目标输入 | 相邻目标、进度事件时间、防御动作及暂停区间 | 完词到下一次有效输入的间隔、目标切换次数；识别时间只能作为近似解释 |
| 目标死亡后输入是否得到兑现 | 输入中目标死亡、原词完成、施法改选目标或结束 | 已输入字符数、死亡来源、原词与新目标关联、实际结算结果 | 被保留的输入投入、转移施法比例、结束原因和重复计数情况 |
| 短词是否同时占据所有收益 | 完词、状态施加、强化触发、纸灵唤醒、终极收入 | 词长、实际人工投入、效果类别与数量、输入速度、识别间隔 | 分词长的单位投入收益、强化与终极频率 |
| 终极能否可靠解围 | 蓄能收入、可用、释放、清弹／击退、护盾消耗和终极结束 | 蓄能来源、等待及持续时间、范围内威胁数、实际清弹、敌人位移、实际吸收伤害 | 首次可用时间、使用间隔、实际防护收益与持续期间战果 |
| 闪避附伤的规模是否合理 | 闪避开始、路径命中、遗留效果生成与消失 | 充能状态、实际命中目标、有效伤害、控制及场效果寿命 | 每次闪避实际覆盖、单位时间附伤、保命与攻击用途的共存情况 |

## 纸灵观察点

| 事件边界 | 记录事实 | 解释用途 |
| --- | --- | --- |
| 唤醒、满员、维护、休眠及房波切换 | 活跃数量、累计输入投入、有效时间、状态变化原因 | 启动所需字符／完词／时间，满员覆盖率，强制等待与主动停笔造成的不同影响 |
| 普攻选择目标、开始飞行与实际命中 | 标记关系、选择结果、距离、飞行时间、命中及过量伤害 | 标记偏好是否有效，赶路损耗和转火代价 |
| 交叉斩指令与各纸灵结束攻击 | 参与数量、原目标、改选目标、实际伤害、结束原因 | 集火兑现比例、目标提前死亡后的有效收益 |
| 易伤变化与受伤结算 | 变化前后点数、来源、目标存活时间、应用倍率及基础伤害 | 各类敌人的实际易伤分布、满层可达性、遗物放大收益 |
| 纸鹤生成、阻挡、反伤与到期 | 阻挡对象、实际反伤、存在时间及退出原因 | 实际拦截收益、未触发比例与闪避后的持续保护 |
| 狂暴开始与结束 | 开始时纸灵数量、活动状态、伤害／飞行变化及实际命中 | 零纸灵起手、狂暴增益与结束后的持续状态 |

累计输出曲线以同条件参考场景比较冷启动损失和稳态收益。不同随机局的累计差距同时受敌人数量、存活及玩家行为影响；比较结果需保留这些条件。

## 灰烬观察点

| 事件边界 | 记录事实 | 解释用途 |
| --- | --- | --- |
| 火弹释放、实际碰撞、焰印与火雾生成 | 原定目标、实际碰撞目标、飞行时间、强化状态、效果位置 | 前排阻挡、施法到命中延迟、范围收益 |
| 灼烧施加、跳伤、停止与再次点燃 | 增量、实际接纳／溢出点数、每跳消耗及伤害、余热 | 冷目标与余热目标的燃烧时长、单体饱和与实际收益 |
| 火雾覆盖层数变化 | 覆盖数量、各场来源、合计施加速率及驻留时间 | 逐层减半的真实贡献，敌人是否停留足够久 |
| 命中后切换目标、后续补伤与目标死亡 | 转火时间、后续伤害来源、死亡时刻、剩余点数 | 一发后转火击杀率、补伤次数、尚未兑现即因死亡退出的点数 |
| 终极火浪及领域伤害结算 | 火浪、领域独立伤害和点数燃烧的各自来源 | 三部分实际收益及与普通火雾的配合 |

单次燃烧完整时长与击杀时间分别统计。普通敌人与 Boss 分组，点数溢出同时标明目标在场时间和施法次数。剩余点数可以解释潜在尾伤，需与已经发生的实际伤害分开。

## 寒墨观察点

| 事件边界 | 记录事实 | 解释用途 |
| --- | --- | --- |
| 冰锥／冰矛释放和各段命中 | 普通／强化／终极来源、发射位置、实际命中顺序与数量、逐目标伤害 | 额外命中概率、实际穿透收益及来源差异 |
| 寒气增加、衰减及减速档变化 | 点数、移动和攻击进度倍率、目标类别 | 有效减速时间、达到冻结条件所需投入 |
| 冻结开始、结束、再冻结间隔结束 | 时刻、点数、攻击阶段及剩余进度 | 冻结覆盖率、连续冻结节律、解冻后攻击是否继续 |
| 冰雾遮蔽开始、结束和敌人重新锁定 | 攻击类别、感知变化、接近行为、雾内驻留与寒气 | 遮蔽收益、敌人恢复攻击的时间及可理解性 |
| 终极选敌、生成冰锥及命中 | 目标、来袭方向、发射与命中时刻、伤害及寒气 | 定向冰锥兑现率、领域控制与直接伤害的贡献 |

普通、强化与终极弹道分组；穿透按实际命中数分布解释。敌人攻击频率变化同时受死亡、距离、冻结、遮蔽和攻击类别影响，因果比较需要匹配条件或明确对照。

## 雷鸣观察点

| 事件边界 | 记录事实 | 解释用途 |
| --- | --- | --- |
| 一次电链开始、每次接入及结束 | 本次基础额度、跳序、目标身份、接入距离、实际伤害、结束原因 | 有效链长、额外段贡献、重复命中及链路自然结束方式 |
| 感电施加、充能与衰减 | 前后点数、增量、消耗、增加额度、伤害恢复量 | 点数收支、充能覆盖及持续传播条件 |
| 按感电扩大范围或跨距离接入 | 候选目标点数、实际距离、选择结果、剩余额度 | 中高感电是否形成玩家可利用的连接 |
| 电爆主击、周边命中与电链接出 | 同次施法关联、主击／范围／电链伤害、点数施加时序 | 强化收益、同次新增感电是否参与本链、同一目标受到的各部分伤害 |
| 带电目标死亡与新敌进入 | 当时点数、当前带电目标数、存活规模、入场时刻 | 导电网络随死亡消失或随连续增援延续的条件 |
| 雷电领域周期施加与退出 | 覆盖目标、点数供给、期间施法和电链结果 | 终极期间传播强度及结束后的余效 |

传播次数、实际伤害和击杀数分别报告。场上敌人数、密度、目标耐久与增援节奏是解释条件。长链可能承担残血处理、范围削血或整群击杀，需要按结果区分。

## 关联与计量口径

需要关联时，可使用一次运行、房间／波次、词咒完成、原始施法、派生效果、电链和目标的稳定身份。伤害结算保留原始来源与直接执行者，便于区分主术、强化、状态、召唤物、闪避、终极和遗物。

- 实际伤害以实际扣除的生命为准；护盾吸收、过量伤害和状态点数分别记录。
- 每条状态变化保留变化前后值及增减原因；点数上限截断单独体现。
- 同一时刻的事件保留规则处理顺序，支持判断加点、消耗、伤害和死亡的先后。
- 区分真实经过时间、世界推进时间和允许玩家输入的有效时间，保留暂停、慢时间与流程等待区间。
- 同条件比较需要游戏与规则参数版本、法书、难度、章节／周目、词库与词长设置、构筑、成长和种子；God 与正式样本分别识别。
- 输入速度、准确率与自动化／真人来源影响解释。完词间隔包含识别、切换和防御，不能直接当作纯键入速度。

一次分析先选择所需事件，再确定细节粒度。高频跳伤和持续状态可用计数、区间汇总及抽样轨迹支持分析；涉及事件顺序的问题再保留相应细节。事件事实与派生指标分开，汇总保留目标类别和场景分组。

## 结果解读

平衡比较保留四书不同的时间曲线和场景优势。纸灵观察启动后能否追回损失，灰烬区分转火效率与单体收益递减，寒墨结合实际穿透和攻击压制，雷鸣结合有限敌群中的传播收益。

“控制避免了多少伤害”“某次转火是否最优”“如果继续使用另一法书会怎样”涉及反事实，单局事件只能提供部分依据。需要这类结论时，结合明确对照、重放条件或人工观察解释。
