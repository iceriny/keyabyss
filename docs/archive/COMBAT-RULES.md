# 战斗组合规则

> 历史归档：保留当时的方案、状态或检查结果，不作为当前待办、完成声明或实施约束。当前入口见[文档导航](../README.md)。

本文件约束战斗系统重构的实现；设计动机见 [重构计划](Combat_System_Refactoring_Plan.md)。模拟负责因果与资源，内容定义负责能力与数值，显示层只消费只读结果。保留现有系统边界，不引入通用 ECS 或依赖监听顺序的全局事件总线。

## 输入与残响

- 友方效果击杀正在输入的敌人时，保留原词、释义、已输入字符与错误状态。残响不是可受伤的敌人，也不阻止清房。
- 完成残响仍计一次正常施法；按原词计算威力，自动投向原位置附近的合法敌人。没有目标时，已支付主术最多在本房间等待四秒，出现目标后释放；重复完成会结算并替换旧缓存，不能无限堆积。
- 取消、主动切换、清房、重开与退出清除输入；清房丢弃未发出的房间载荷。残响完成前不自动换词，Tab 不悄悄改变残响。
- 新资源只由成功完成的敌人词条中实际人工输入的字符供给。错字、取消、辅助补全部分、符文与派生攻击不供给。一个词只支付一次，不要求限时完词。
- 散字余音是单独投资的遗物：目标提前死亡可释放已输入字母，在其他敌人当前词条的同字母位置留下标记。每个位置最多一枚；手打该位置并完词提供15%主术增伤，辅助补全部分不计算。有「聚字成页」时，每枚标记的收益改为当前直伤7.5%与下次完词付费复制额度7.5%。词条变化时标记失效，飞行字母目标死亡时消散，最多72枚在途；它不取代残响续写，也不产生新的字符供给。
- 词库允许可见短语空格，输入游标自动越过空格；空格不计有效字符，也仍可用于弹反。连字符与撇号按词形处理。

## 载荷与结算

- 每次人工施法建立独立根来源，并把当时的书、天赋、遗物和事件来源冻结在根上。主术、承载、碎片与传导各持有独立片段和剩余份额；派生攻击不增加施法、连笔、人工输入或材料供给。
- 命中前先从片段预留碎片、传导等后效，主命中只消费剩余威力；已付后效在首目标死亡后仍可向合法存活目标交付，不对尸体追加状态。`hit` 回执中的威力是片段本次已付份额，不是敌人实际掉血。
- 片段按合法蓝图执行冰穿透、火爆、雷链或纸刃；复制与拆分会减少父份额，不把同一材料整份给多个对象。`materialRate` 只改变人工字符供给；首次加工的威力保留率为 `clamp(0.85 + materialConserve, 0.3, 1)`。分裂先从父片段扣完整预留，子片段只取得保留后的威力，差额记加工损耗；复写成页也从其已付基值扣一次。已加工子片段的中继、后续拆分与释放不重复扣保留率，`reactionEfficiency` 只给首次派生一份额外倍率。深度、命中次数、载体容量及寿命限制循环；已发射片段不因兄弟片段先执行而失效。
- 副书须经合订开放，不能选择主书本身。有效人工字符按构筑的供给率积累，基础每12字一份材料，材料和复写均受各自容量与每词领取上限约束。主书免费起点的基础供给与同名投资可叠加；没有人工字符就不增加供给。
- 复写页消耗字符额度，并带着创建时片段快照执行相应法术蓝图。正常攻击、防御、热释放和到期采用一次性出口；防御先扣有限份额，遗响只能交出余额。兼容页可归并所有权；纸灵运输占用原攻击周期。清房不能让旧页攻击新房。
- 灼烧按贡献保存已付余额、速率、期限和回收资格，每次跳伤先扣余额。死亡、单份到期和续写抽取消费同一余额，按该份来源折损入热匣；回收来源不能再次回收。普通无来源灼烧不能回收。只有明确取得跨房储备能力时热匣可跨房保留，普通字符供给与在途页在清房时结算。

## 构筑

- 遗物通过提供、需要和改变的能力描述关联；不能按法书二元配方硬编码联动。候选保留深化、连接与探索空间，显示已有能力关联，不标记最优选择。
- 复写二阶增加缓存；三阶通过互斥的多页分发或少页重印改变结构。分支占用一次遗物选择。
- 天赋为144节点的跨元素星环图，主书决定免费起点，最多持有两个关键节点；合订与独卷互斥并具有点数机会成本。独卷按当前主书改写冰穿透、火储备、雷集中或纸编队结构，没有通用30%伤害倍率。输入配置必须在模拟入口重新校验。
- 当前内容包含140件遗物与24个有限作用域构筑事件。事件可临时借用、改写或演化构筑，也可在试炼完成后兑现；事件过期要同步当前构筑，但已付在途片段仍按创建时快照收尾。

## 性能与表现

- 每次人工主术共享一份根来源与预算，只有获得相应能力才供给材料、生成载体；不为每件遗物每次命中创建监听器。不对每次最近目标查询分配并排序全敌人列表。
- 纸灵运动和可见轨迹使用连续曲线。雷电分支仅负责视觉，不增加判定；冰与雷的视觉增强不得更改伤害或混用玩法 RNG。
- 不增加需要盯看的资源 HUD。继续使用现有血盾、词令和危险提示；构筑因果在选择说明和战后摘要展示。回执仅保留最近128条并报告丢弃数，未覆盖旧钩子的所有伤害来源。

当前实施阶段按要求未运行测试或构建，以上规则仍待整体统一验收。
