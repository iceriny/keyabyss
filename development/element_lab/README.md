# 冰与火材质小样

独立场景 `element_lab.tscn`。双击同目录 `run.cmd`，或在仓库根目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File development/element_lab/run.ps1
```

使用项目锁定的 Godot 4.7.2。首次拉取资源需先按工具链执行 import。缓存与用户目录隔离在 `.temp/element-lab/`，不加载玩家设置或存档。小样目录被正式导出排除；其认可的冰火机制已接入主项目，模拟器移至 `ui/effects/`、材质移至 `ui/materials/`，本场景继续调用同一实现。正式适配与验证见[元素材质](../../docs/art/ELEMENT-EFFECTS.md)。

## 观察与操作

同一垂直俯视空间中，左侧结晶，右侧燃烧；共享背景、光照与平面速度场。移动鼠标照明，按住左键拖动搅动气流。按钮可重新结晶、停止／恢复供火、暂停、关闭／开启探照光、隐藏／显示冰膜；Esc 离开。暂停只冻结演化，仍可移动灯光观察静止晶面的受光。“水汽”在 ρ₀=0.42／0.56 间切换，以相同种子重新生长，便于判断密度影响；“重新结晶”则改变种子位置。

## 实现与取舍

- 冰晶不引用此前生成的冰图。依据 [Snowflake simulator](https://www.ibiblio.org/e-notes/webgl/snow/snowflake.htm) 的六邻域扩散、边界冻结和按邻冰数量附着规则重新实现 GPU 求解；三个种子竞争有限水汽。`frost_growth.glsl` 两阶段避免一边计数一边覆写状态；记录真实首次附着轮次。320²、RGBA32F 双缓冲约 3.125 MiB，每秒目标 480 轮，3000 轮后停止。新种子只改变初始位置，枝条不预先绘制。
- 参考的 [Frost 2D 源码](https://www.ibiblio.org/e-notes/webgl/snow/frost.htm) 在附着后继续累加年龄／厚度，但显示主要表现为亮度。这里将已冻结格点空闲的水汽通道复用为沉积高度，早结晶格点持续增厚，不再用很快饱和的年龄亮度。高度在六邻域重建成脊面，参与动态法线、折射、吸收、散射及高光；不会生成固定亮边。纵向沉积属于游戏近似，来源视作表面上方供给，不计入二维水汽质量守恒，不是三维热力学求解。
- `frost_surface.glsl` 另以双稳态反应／扩散近似薄层凝冻。枝段附着 480 轮后才开始触发膜层，900 轮时充分参与；六向有界采样判断枝网包围程度，冰膜从成熟枝段连接枝间区域，不自主越过外露晶尖。冰膜可以连续覆盖枝间，内部形态与细节由材质处理。新增 320² RGBA16F 双缓冲约 1.563 MiB，每帧两个稳定半步；包围信息只在第一个半步更新，第二个复用，10 秒后停止调度；主枝 3000 轮后停止。
- 两张内置 imagegen 素材位于 `assets/art/effects/`：`ice_microstructure.png` 驱动膜层起伏、透光密度与边缘，`frost_microfacets.png` 补细针状晶面。微晶按晶格三个轴向混合，膜层细节在普通照明下也保留。边缘以高低频纹理强化阈值，并用像素足迹抗锯齿；不靠压缩整个冰膜范围消除模糊。主枝的轮廓与分枝仍由求解器决定。纹理采用 1024 尺寸上限、GPU 压缩与 mipmaps，只取内部 UV 区域，不依赖生成图边缘无缝性。[素材来源和完整提示词](../../docs/art/ICE-SOURCES.md)。
- 火焰读取现有 `FluidField2D` 速度场，在独立 512×288 RGBA16F 双缓冲中输运燃料、温度与少量烟。新增存储约 2.25 MiB，一帧一次燃烧／输运 dispatch。热态驱动颜色和发光，保留局部过曝，火星缩小并随寿命衰减。简化燃烧思路参考 [Andrew Chan](https://andrewkchan.dev/posts/fire.html)。
- 共享流体关闭重力浮升与沉降，风为零；运动来自平面旋涡、燃料分布变化及鼠标扰动。渲染中的虚拟灯高只用于折面受光，不施加屏幕向上加速度。冰晶固定在同一空间的薄层上，空气从上方经过；没有加入融化、伤害或新的游戏规则。

## 实际证据

2026-10-08 历史证据在 `.temp/element-lab/branch-first/`：同场景实际生长、燃烧、移动灯光、隐藏冰膜、关灯及停火截图；数据在 `observations.json`。1.2 秒时 5969 个晶体格点均未覆盖膜层，5 秒时出现 11206 个枝间膜格点；最终有 16768 个晶体格点、14055 个枝间膜格点和 253 个未覆膜晶体格点，图像显示外围晶尖领先。早期附着四分位的平均沉积高度 0.644，晚期四分位 0.120（模型单位）。停火约 4 秒后最大温度由 2.721 降到 0.059，零浮力／沉降检查通过。`branch-first.log` 无脚本或 shader 错误，启动仍有一次“无 2D 内容时启用 MSAA”的引擎警告。2026-10-10 起小样高度统计读取表面平滑高度并乘显示系数7，与材质一致，不能直接与旧原始沉积值比较；本轮未重采小样完整流程，正式弧面与分辨率调整的窗口证据见阶段总结。

此前同种子 ρ₀=0.56 的 `.temp/element-lab/rho056/` 最终冻结格点 25220，主枝较密、枝间更容易连片；它验证未改动的主枝密度行为，不代表当前冰膜外观。提高 ρ₀ 不等于直接生成冰膜或三维厚度；默认保留 0.42，提供 0.56 对比。

RTX 4070 SUPER 上，在结晶仍迭代的 2–4.5 秒区间，通过 RenderingDevice 时间戳包围结晶、膜层、共享流体及燃烧 compute 调度：148 个样本，中位 0.323 ms、P95 0.339 ms。采样区间不截图；数值不包含材质绘制和后处理，不代表 P620。跨轮采样存在 GPU 频率与负载变化，不由旧值差异推断优化收益。旧 `final/`、`relief-final/`、`film-detail/` 等目录仅作研究对照。以上为接入前小样证据，正式战斗另行采样，不混用成本或验收结论。

复现采集时，将 `--capture=res://.temp/element-lab/<目录>` 和可选 `--rho=0.56` 放在 Godot 的 `--` 之后；使用 PowerShell 包装脚本时，整组参数通过 `-EngineArguments @(...)` 传入，避免 PowerShell 消耗分隔符。
