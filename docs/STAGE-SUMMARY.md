## 通用流体与设置

GPU 二维速度与独立高分辨率密度／温度场同时输送密度加权颜色和年龄，支持独立变换、遮罩、风、沉降、冷热浮力、涡量和硬边界。实体沿连续路径传递相对动量，以紧支撑流函数形成前推、侧向绕流和后侧补位；同一节点提供圆钝与细长双尖受力，法书／角色使用前者，鼠标／飞行物使用后者。形状、纵横比、作用范围和响应速度分别配置，停下后保留空气惯性，不强制清零。雾作为被动浓度运输，不把数值残余压缩放大成亮圈；硬障碍只用于占据整个模拟切片的结构。首页补雾集中下部并向上平滑消隐，空气域仍覆盖全场；书体和鼠标可把已有雾带起，快速折返点保留，淡出同步注销。环境细扰动不再依赖雾量和雾龄，空白处也有空气演化。战场稀薄全域补雾，额外痕迹半衰期约 0.73 秒。法书柔光／阴影按采样范围自然消隐。

闪避通过短时预设在身体后侧按移动距离补雾，起步较浓、释放量逐渐减弱，停止时不再堆雾或引发爆炸；飞行物以实际尺寸推流，在后侧留下少量余速的元素尾迹。FluidMedium 配置物质，FluidEffectProfile／FluidEmitter2D 组合方向力、旋转、径向推吸、补雾、粒子和原生光照；已提供风、补雾、方向冲击、闪避、近战横扫、爆炸、吸力及电光预设。雷电沿命中路径提交原生光源，场景、雾和粒子共用 Light2D；粒子采样同一速度场。流体设置为关闭／低／中／高／极高，各开启档随显示帧更新，以速度网格、雾网格及压力精度区分成本。接口和近似范围见[流体视觉工具](FLUID-EFFECTS.md)。

主菜单关闭场矩形的 7% 显示边缘羽化，让雾自然贴住窗口下沿；向上稀疏由补雾空间分布控制。这层羽化原本只减显示透明度，并非物理斥力。局部场仍可用 `edge_fade` 配置边界消隐。

[使用说明](FLUID-EFFECTS.md)已补齐编辑器接入、节点与资源、参数单位与默认值、调参顺序、常见配方及故障排查。FluidBody2D 可直接用手动半尺寸接入无碰撞的视觉节点，提供 `rebase()` 排除瞬移扫掠；发射器 `end_offset` 可在 Inspector 配置。零淡出效果现在在持续时间结束时归零。实际 Forward+ 节点接入定向检查 `test_fluid.gd -- --usage` 为 0 失败，覆盖手动尺寸、坐标与缩放、碰撞覆盖、GPU 空气响应、注销、沿线效果、资源只读和寿命边界；本次未重复完整流体回归或录像。

实际 Forward+／RTX 4070 SUPER 流体回归 0 失败，证据 `.temp/fluid/run-12292-2559328/results.json`。覆盖四档网格、高刷新率、快速折返、首步起点雾形变化、两种受力形态、小目标响应、无雾空气、停止惯性、后侧汇入、三条平行尾迹不汇聚、闪避终点前方无脱离雾圈、停止发射、细涡流、首页下部覆盖、战场 30 秒环境密度，以及物质／照明／生命周期。40 秒实际输入录像及抽帧复核见 `.temp/fluid/body-shapes.mp4`，包含切书、快速鼠标、出征及冰火闪避／飞行物。没有增加网格、纹理、派发或压力迭代，移除速度步骤的雾龄纹理采样；实际耗时仍受设备与负载影响。录像、性能短样本与观察范围见 `.temp/fluid/review.md`；不代表低端设备、全法书组合或用户最终审美验收。

- 弹反成功在原窗口内继续承接来弹，每次激活只触发一次近身推开、声音和冲击波；周边推开不额外造成伤害。世界进入 0.52 秒短暂停顿与平滑恢复，真实输入、防御冷却和闪避计时独立推进，固定步仍是唯一规则所有者。对应规则检查覆盖无伤推开、时缓与真实防御时间的分离。
- `single_room.tres` 定义三波单房，每波三名敌人，种子决定八向来袭扇区，分散出生在外围冷区并走入有效战场，波间隔 1.6 秒；纸刃保留剩余工作进入下一波，末波胜利不等待无目标的伴飞消耗。五档压力参数、词库词长与渐进设置、可重复种子、生命和共鸣数值及进度接通。暂停与结算保留战场，通过开放柔焦层承载正文和操作，重试建立全新会话。
- 战斗空间按原生技术路线统一为 1920×1080 设计基准；移动、射程、碰撞与等距闪避在此空间中计算。世界、危险提示与 HUD 共用窗口输出像素密度，宽高比变化只调整显示映射，HDR 层随真实窗口尺寸刷新。没有保留旧 Web 的 1280×800 战场基准。
- 对照旧 `ActorPainter`、`ArcaneBackdrop`、`SpellBrush`、`FlameBrush`、`Shockwave`、`CounterPulse`、`WordLabelLayout` 与 `Battle.tsx` 后，补入施法蓄光、后坐、角色内部纹样、冻结晶片、纸灵伴飞、分材质碎片与投射物尾迹收束。背景织纹用导数平滑并压低中央对比。词目标位于敌人上方，按实际词宽布局，当前目标与已输入字母区分；HUD 显示实际完词与主术强化周期、弹反冷却、残响续写。纸灵每三词的交叉合击已进入固定步，两次后效在首目标死亡后仍能继续，不产生额外人工收入。单房不显示未接入的房间进度。波前与折射共享时序，位移总长度有预算，文字及危险提示不进入折射。
- 角色使用独立矢量轮廓与表面材质，呈现披风折面、金丝、受击、冻结、灼烧和溶解。冰晶、暖金火焰、雷弧分叉、纸刃折面及交叉合击具有不同形态。敌人词条无底板，以随文字淡入的字形细衬保持辨识。冰晶通过透明度退场，避免收缩至零产生无效多边形。
