[内容取舍](03-CONTENT-DECISIONS.md) · [候选目录](05-CONTENT-CATALOG.md) · [旧内容事实](../../build-system-design/01-CURRENT-SYSTEM.md)

基线 767b349 的 308 项内容逐项对应：144 天赋、140 遗物、24 事件。去向是语义迁移与合并，不是兼容存档的直接 ID 替换，也不表示实现已完成。部分规则已接入，实际状态见[阶段总结](../STAGE-SUMMARY.md)。

“数值重配”表示保留该强化方向并进入新的刻度集合，次数／新增供给等可能改成损耗或费用改善；不是保留旧统计数值。系列 N 的多个实例由新图关系安排，不强行一对一复制旧路线。
