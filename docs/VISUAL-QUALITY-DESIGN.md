# 视效分级与成本方案

日期：2026-10-18。本文规定低／中／高画质、流体精度和减少动态的职责、目标外观与实施边界，属于[全面性能优化](migration/PLAN.md#全面性能优化)的P3／P5设计。实现已开始接入，实测与取舍记录在[实施记录](migration/PERFORMANCE-IMPLEMENTATION.md#视效分级实施两组对照重设)；执行状态只维护在[TODO](TODO.md#全面性能优化)。

## 1. 目标与取舍

三档应是同一套美术的不同精细程度。低档仍有柔和光晕、连续尾迹、冰晶与膜面、火焰与纸张材质、金丝水晶界面；中档提供完整的日常体验；高档增加微观细节、局部受光与空间层次。增加粒子、模糊半径或亮度本身不构成升档收益。

优先消除各档共有的浪费，再调整装饰预算。档位必须实际减少CPU准备、GPU求解、采样或覆盖面积，不能只把效果画淡、缩小参数却照常计算。低档尤其需要摆脱比中高档更重的旧绘制路径。

各档共同保留：真实弹体和纸灵数量、位置／方向／反射状态、危险轮廓、伤害与作用范围、命中时刻、起手／持续／结束阶段、当前目标与输入进度。正文、词咒、HUD、危险提示保持清晰；60Hz规则、事件顺序、RNG、伤害和资源不参与画质取舍。

范围包括战斗四书、敌弹、道具／群体事件、流体与照明、菜单／阅读页材质、切换与生命周期。星空之书仍为候选研究，不纳入本次四书完成标准；以后接入时遵守相同分级约定。

## 3. 设置职责

保留现有三个设置入口和存档值，不新增一排高级开关。

| 设置 | 控制内容 | 与其他设置的关系 |
| --- | --- | --- |
| 画质：低／中／高 | 材质采样、尾迹装饰层、粒子装饰密度、照明总预算、冰晶精度、燃烧精度、柔焦／折射 | 全场表现的成本档；保留正常运动，不替用户开启减少动态 |
| 流体效果：关闭／低／中／高／极高 | 空气输运、雾密度场、雾中散射的空间精度和求解成本 | 保留独立选择；低画质＋极高流体是允许但仍昂贵的组合。关闭后以非流体材质维持火场身份和范围 |
| 减少动态 | 装饰漂移／旋转／脉冲／频闪、镜头扭曲和震动、长拖尾及动态雾流 | 与画质正交，保留选中、命中、范围和阶段反馈；不作为性能预设，也不修改保存的画质／流体值 |

设置说明用玩家能看到的差别，例如“画质影响材质细节、光晕与装饰密度”“流体效果影响空气流动和雾气细节”。不向玩家展示线程数、网格大小、dispatch或预算计数。保持当前默认值；是否更改默认须由后续同档实测与画面比较决定。首轮不引入自动降档、动态分辨率或按显卡型号猜档位。

本表为实施目标，不把尚未出现的画面描述成已交付。高档以当前已认可的形态、层次与柔光为参照；中低档允许降低装饰精度，但不能改变对象识别。

| 主术／纸灵 | 全部真实身体；短主带，交叉攻击路径仍明确 | 主带＋柔光层，纸张折面与交叉动作完整 | 保留细丝与宽柔光，重点强化命中／交叉时刻，普通飞行控制覆盖 |

| 雷电 | 主链、连接对象、落点和强化电爆完整；减少次级分叉 | 少量次级枝与局部闪光 | 多层细丝和柔光，但控制峰值亮度；分叉不被误读为额外命中 |

### 尾迹统一实现

低档也使用缓存弹头和批量几何，仍在原清晰Canvas内合成。尾迹统一在弹头之后，全部危险轮廓置前，避免其他弹的尾迹覆盖弹头；需实际检查密集交叉处，不只凭CPU下降验收。复用当前纯数值路径和动态上传，去掉宽装饰带，保留平滑羽化主带，消除逐段画线接缝。中高档仍在HDR世界合成尾迹。

曲线预算按显示尺寸与曲率使用，16／32／48点可作为低／中／高的初始目标，而非强制截断上限。起终点、反射折点与急弯必须保留；必要时让这些点占用更多预算，不能把弯弹画成直线。中高档敌弹现有物理宽度插值继续保留；主术／纸灵各自检查Line2D的渐细、接头和末端，不机械套用敌弹材质。

纸灵隐藏装饰时直接跳过几何准备；显示时同一条路径只准备一次并共享层间数据。不能通过少显示几只纸灵或略去交叉路径控制成本。有界多核仍只计算当帧纯数值数据，小批串行，主线程有序合并；不为每个效果另开线程。

### 冰火与流体

冰晶先保留现有128／160／224²及160／256／384²网格作为起点，优化成熟期、不可见覆盖和同帧重复工作；不同精度必须以相同实际冰龄核对晶尖领先、连膜速度、透光和边缘，不直接缩减生长步数。已有稳定性尺度与有界子步继续沿用。

高档的多块冰应优先按屏幕占用分配装饰精度：终式与玩家附近的大范围结构保留完整表现，远小区域用较低网格。所有付费实例仍显示各自实际边界、年龄和退出；不能合并有不同寿命的规则对象。首轮不采用整屏冰面一张贴图替代实时生长。

燃烧分辨率从雾网格中解耦，由画质控制，初始候选长边192／256／384；这些是待校准的成本起点，不是已验证参数。流体打开时仍读取速度场，流体关闭时使用连续的非流体火焰材质保留火舌、热核和到期淡出，不只留下圆环。中高档正常模式保留现有燃烧过程；关闭流体的替代表现单独验收，不冒充同像素优化。

空气速度／雾网格的四档和压力迭代先保留，避免同时改数值算法与视觉档位。优化CPU输入准备、灯光候选、未提交来源和GPU有效工作范围；不以隔帧更新让低档雾流跳动。高／极高流体须有可观察的卷曲、边界或散射改善，否则继续调成本，而不是默认升级更好。

## 5. 群体预算与渲染成本

只对装饰分配预算，必要提示每个事件都即时呈现。采用稳定优先级：玩家操作结果与当前威胁附近的反馈优先，其次可见领域／终式，最后远处环境装饰。同级沿用稳定身份，避免逐帧换灯、闪烁或粒子时有时无。多个来源不能各自耗尽一套“全局”预算。

| 成本 | 实施规则 | 参数起点／判据 |
| --- | --- | --- |
| PointLight2D | 统一统计流体灯、接触灯、领域端点灯和终式灯；失去灯光的对象保留自身材质和局部柔光 | 同时可见4／8／12盏作为低／中／高候选上限；优先复用当前灯位容器，不把换灯做成节点创建风暴 |
| 短命粒子 | 先保证每次命中的必要闪光，再给装饰碎屑／火星额度；按活跃总量与同帧新建成本共同限制 | 装饰发射量约为当前高档的35%／65%／100%作为起点；低档尽量单层。具体总量由两组压力样本校准，不能只限制单个发射器 |
| 尾迹／光晕 | 几何共享、控制宽带层数与像素覆盖；身体与主要路径不参与淘汰 | 升档应有可见层次；同档密集时先收敛最外层柔光，不改变亮核或把相邻轨迹粘成光块 |
| 边缘柔焦 | 从当前各档相同25采样改为真实分档，减少重复纹理读取 | 低／中／高候选为5／9／25次，保留近似核宽与平滑过渡；不能通过更硬的边缘掩盖滤波缺陷 |
| 水晶材质 | 共用已有结构图与金丝，按档选择滤波／色散路径；局部与页面捕获复用 | 低档仍通透；嵌套页不再叠模糊。降低的是多余采样与高频光学，不是正文清晰度 |
| 背景复制与离屏 | 按实际消费者启停；不显示时停止相应更新／计算 | 不合并有不同前后合成关系的捕获；保留纹理身份与正确依赖释放顺序 |
| 抗锯齿与输出 | 优先在当前原生分辨率下优化；局部线条羽化保持 | 首轮不同时降低世界分辨率与抗锯齿，避免收益无法归因及细线破碎；有明确GPU填充瓶颈再单项比较 |

预算减少应当减少实际创建／计算／上传，不能只设`visible=false`或alpha为0。必要反馈不排队到下一帧；被舍弃的装饰不延迟补播。已出生的短命效果自然退场，避免为了腾额度突然闪灭。需要复用对象时以实际创建峰值为依据，避免先为所有类型引入通用池。

以上参数在高档的视觉回归不过关时调整，不能用表格数字覆盖已认可外观。低档应在相同设备、流体与负载下更省，若CPU瓶颈使降档整帧收益有限，应记录原因并继续优化共享路径，不声称“显卡差所以只能这样”。

## 6. 减少动态与切换

减少动态不等于隐藏技能：身体／弹头仍真实运动，方向与范围提示保留；雷链按真实目标连接，命中用简短稳定反馈；停止装饰旋转、震动、折射扰动、流动雾与连续闪烁。敌弹保留短方向尾迹，纸灵交叉保留必要路径，不用长柔光拖屏。

冰面／火场保留静态材质和生效／结束过渡。既有冰面保留当下结构、立即冻结演变；新生冰面采用最多0.5秒的有限入场后冻结，不在切换时同步跑完整生长。恢复时从冻结结构继续，不追补停用期间；淡出继续服从真实生命周期。该有限入场替代预烘成熟缓存，减少资源与初始化成本，其静态结构不等同于正常成熟冰。火场静态解析材质保留热核、暗部与完整范围。

切档规则：

1. 通过`BattlePage.apply_options`及现有设置应用入口统一发布已解析参数，组件不在每帧反复解析配置。共用字段放在一个小型分级定义中，四书特殊行为仍由组件持有，不另建通用渲染框架。
2. 颜色、光学、预算和后续发射密度即时更新；已有冰晶保持创建时网格与种子，新生实例使用新档。降档释放显存的完整效果因此可能要等旧冰域退出，设置说明与诊断应区分这点。
3. 短命粒子与临时光自然退场；持续源的额外装饰停止发射。升档不回放已经发生的爆发，不让旧对象重新入场或重新生长。
4. 流体重建与燃烧依赖在渲染线程有序处理，保留消费者纹理身份；切换期间由同一场的简化材质承接，不出现白块、黑帧或暂时丢失范围。新资源就绪后替换，不能每次切换无界叠加两套模拟。
5. 低→高→低、流体关→开、减少动态开→关以及暂停／恢复后，参数和对象寿命保持一致。退场必须停止对应compute、离屏更新、灯光和绑定维护。

## 7. 接入顺序与验收

顺序以可独立审查的结果为界，不另外维护活动清单：

| 顺序 | 交付内容 | 主要文件 |
| --- | --- | --- |
| A 统一含义并修复浪费 | 小型分级定义、拆开低档与减少动态；低档弹头缓存／尾迹批次、纸灵隐藏时跳过路径 | `app_settings.gd`、`battle_page.gd`、`battle_visuals.gd`、`battle_threat_*`、`battle_spirit_visual.gd` |
| B 补齐三档材质 | 敌弹与主术连续尾迹、冰晶三档外观、流体关闭时的完整火场、减少动态静态承接 | `ThreatRibbonGeometry.cs`、`ice_patch.gd`、`frost_growth.gd`、`fluid_atmosphere.gd`、`combustion.gd`、相关材质 |
| C 控制群体和全屏成本 | 全场装饰灯／粒子预算、分档柔焦、既有水晶光学收束、切换与资源释放 | `fluid_field_2d.gd`、`battle_visuals.gd`、`spell_field_visual.gd`、`ultimate_field.gd`、`battle_stage.gd`、水晶材质 |
| D 形成可交付档位 | 四书同事件视觉对照、两组整帧前后数据、目标机可行配置与准确设置说明 | 现有测试入口、性能实施记录、设置界面与测试包验收 |

**视觉检查**：低／中／高使用相同事件与实际效果年龄，查看起手、持续、退场；覆盖直／弯／反射弹、纸灵交叉、冰终式叠局部冰、火终式、雷链、群体反制，以及水晶菜单／长阅读页。先用已有窗口／截图入口，修复分节、跳变、白块、光晕硬边与文字遮挡的根因。主术／纸灵不能沿用敌弹的通过结论。

**性能检查**：只有基线与极限两种负载定义。为本方案重设为6目标／96弹／纸灵书真实4容量，以及18目标／256弹／纸灵书真实10容量＋纸鹤，包含实际输入的反制与终式。两组各12段，三档经过相同四书，每段12秒剔除前2秒；控制流体中档与1080p，不扩成画质×五档流体×四书×分辨率全排列。夹具、构筑与事件窗详见实施记录；与原29秒纸灵数据不可直接比较。流体关闭、减少动态及切档检查在计时外完成，不增加性能负载组。

固定分辨率、流体档和构筑时比较画质；比较流体时固定画质。预热、截图回读、编译与性能采样分离，单窗口串行运行，完成一组立即写入结果。记录整帧p50／p95／p99／最大、事件窗、CPU几何／流体准备、GPU求解／绘制和对象／灯／粒子数量；不把嵌套区间相加，也不由减粒子数量推断FPS收益。

本机高画质的高压目标继续采用p95≤16.67ms、p99≤20ms；中低档还须证明成本降低与可读性。正式性能结论用Release；目标中低档机器另测，明确其CPU、GPU和所选设置，不能只拿4070数据宣称覆盖。声音开启、连续挑战与长期退场沿用全面优化的验收缺口，不在本方案中伪装为已完成。

**正确性检查**：同输入的战斗事件／伤害／支付不因画质变化；所有真实敌弹和纸灵可见；必要范围与规则吻合；暂停、慢时、切档、重开和离开页面后无残留计算。新增必要材质使用正式资源并纳入渲染准备。GDScript按锁定引擎检查，按改动选择现有最小回归；资料与画面证据保留失败及局部复验，不凭一次截图宣布整档完成。
