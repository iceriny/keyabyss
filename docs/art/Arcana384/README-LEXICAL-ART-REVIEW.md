# Arcana384 常用合词字形验收

50个登记词的词义与字形已逐项核对并接受。基础384字的字形、编码与核心含义保持不变。

47个双根词、3个三根词采用横向合写。冰的固态外壳与内部水纹、交换的双向回路已按词义修订；其余词形在共享笔画中保留可学习的根身份。

合字开关只改变书写形态，不改变词义。未知连续长串不在内部猜词；词界和精确操作的括号继续有效。
