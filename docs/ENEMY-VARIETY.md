# 敌人攻击与精英词条

敌人通过 `EnemyProfile.attackSequence` 声明攻击顺序。第一次释放使用索引0，成功调用攻击后推进 `attackIndex`，超过序列长度后循环。缺省仍使用 `attack`，保留既有行动、战区、攻击距离、冷却和状态处理。

| 敌人 | 交替攻击 |
| --- | --- |
| 飞羽射手 | 瞄准扇形弹幕 `fan` → 弧线追射 `curve` |
| 缚页使 | 转弯弹幕 `bind` → 预警射线 `laser` |
| 墨弹炮手 | 脚下爆区 `bombard` → 两侧夹击 `crossfire` |

夹击在玩家左右各110距离创建半径65的爆区，预警时间为 `max(1.2, 1.5 × pressure.warning)`。爆区沿用现有可见预警与伤害结算，中心保留通道；战场边缘沿用 `makeBlast` 的边界约束。轮换与夹击本身不追加随机数或延时任务。

三名 Boss 按释放次数的奇偶交替攻击，首次为奇数攻击，保留原有血量、阶段、行动节奏与防御按键。吞墨巨像奇数攻击释放环形弹幕和脚下半径90、预警1.25秒的爆区；偶数攻击释放扇形弹幕，在玩家左右各110处形成半径65、预警1.25秒的爆区。第三阶段偶数攻击仍附带射线。镜页织者奇数攻击释放射线和正向曲线环弹；偶数攻击释放反向曲线环弹，在玩家上下各110处形成半径65、预警1.3秒的爆区。大校对官奇数攻击保留环弹与射线；偶数攻击保留环弹，在玩家左右各135处形成半径75、分别预警1.25和1.65秒的爆区。三者既有阶段追加攻击仍随阶段生效；延迟攻击沿用 Boss 来源标识。

回响与铁铸精英声明 `wordPreference: "punctuated"`。在存在合适候选时，以50%概率优先从所选词库现有的连字符或英文撇号词中抽取。主词库和符号子池使用相同玩法随机源，并共享最近词历史。保留渐进词长、优先未占用首字母、避开最近词、避免重复词及词库耗尽后的既有回落顺序。

符号子池与长度/首字母索引按主 `WordPool` 缓存，不在每次抽词时扫描全词库。若词长范围没有符号词、符号候选会降低避重复优先级，或所有词本来都含符号，则沿用主池。不会插入词库外词条或带空格短语；符号仍需逐字符输入，空格保持弹反。

生成敌人时先确定精英，再抽取一次词条；刷新时从被刷新的敌人读取相同精英偏好。选词函数只返回词条，输入中的目标词与进度不会因此改写。

`tests/enemy-variety.test.cjs` 覆盖攻击轮换与行动边界、夹击预警、词库边界、词长与抽词优先级、缓存、生成/刷新接线和内容格式校验。
