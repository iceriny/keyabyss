# 弹反、定向闪避与难度节奏

2026-09-20 · 实施设计与验收记录。战场以 1920×1080 为视觉基准，模拟距离使用等比缩放前的世界单位。

## 目标与操作

玩家双手打字，没有普通移动。完整词条是主要输出，空格弹反是可反复使用的近身防御，定向闪避负责改变位置和避开激光 / 地面爆炸。多敌人的能力独立运行，不加入全局攻击配额；处置顺序不当仍会积累压力。

| 输入 | 行为 |
| --- | --- |
| 单按 Space | 开启弹反；次数不限，不消耗闪避 |
| 方向键 | 立即往对应方向闪避 |
| Alt | 立即按威胁评分自动择位闪避 |
| Shift 轻按 | 释放终式；组合键不触发 |

方向键和 Alt 在按下时触发，自动重复不重复施放；空格独立触发弹反。数字 1–4 在战斗中只作为咒文字符，不再承载闪避方向。防御保留当前咒文进度。自动择位与新规则详见 [本轮更新](RITUAL-UPDATE.md)。

## 参数与命中协议

`src/shared/defense.ts` 是公共参数与映射入口。

| 参数 | 当前值 |
| --- | --- |
| 弹反窗口 | 0.24 秒 |
| 弹反冷却（从按下开始） | 0.70 秒 |
| 回响护腕冷却 | 0.49 秒（减少 30%） |
| 反弹半径 | 42 世界单位，额外计入子弹半径 |
| 反击伤害 | 32；重弹 40 |
| 接触反击冲量 | 700，沿用实体质量与速度上限 |
| 接触反击失衡 | 普通敌人至少 0.85 秒 |
| 闪避无敌 | 从启动起完整 1 秒，位移结束仍持续 |
| 闪避位移时间 | 0.17 秒 |

弹反可在同一窗口接住一组弹道；音效、成功文字和 +3 共鸣每窗口只奖励一次。没有击中威胁时不会自动伤害附近敌人。窗口外或冷却中的空格不会提供保护。弹反没有全伤害无敌，激光 / 地面爆炸需要闪避、击杀来源或绿色符文处置。

`DefenseSystem` 负责开启窗口、成功反馈、反射方向、接触打断与伤害转交。`ProjectileSystem` 使用线段扫掠检测近身弹道，将其改为友方弹道；优先朝仍存活的发射者当时位置反射，来源不存在则反向。反弹后取消曲率和加速，速度至少 360、通常为原来的 1.6 倍，寿命 3 秒；不追踪，实际碰到第一个敌人时才结算且仅结算一次。友方反弹不会伤害玩家、触发擦弹或极限闪避，也不会被玩家清弹误删。

`EnemySystem` 在接触伤害入口调用弹反，打断冲锋和蓄力、分离重叠实体、施加强击退及中等伤害；质量和撞墙 / 撞人机制继续有效。激光与地面爆炸沿用原有伤害通道。所有防御计时按真实战斗时间递减，暂停冻结，新房间清零弹反状态。

## 遗物与法书扩展

新增「回响护腕」`rebound`（`parryHaste`）和「返咒铭文」`inscription`（`parryAffinity`），共 58 件遗物。均通过现有内容清单、数值授权、奖励与图鉴管道接入。

`BookBehavior.counterHit` 是可选扩展钩子，仅持有返咒铭文时调用：

- 寒墨：48 点积寒，达到阈值后冻结。
- 雷纹：叠加导电，第三次触发已有过载机制。
- 灰烬：叠加灼烧并复用火焰命中效果。
- 灵契：施加标记、指定纸灵目标并增加 2 秒纸灵活动时间。

反射弹道和接触反击使用同一钩子。没有铭文时为普通反击伤害；没有声明此钩子的新法书也有普通伤害回退，不需要修改防御系统里的职业分支。

停帧沙漏保留闪避后 1.5 秒世界减速到 10% 的能力，取消旧 WASD 移动和暂停打字的输入劫持。现在可以继续施法；闪避充能、无敌与弹反计时均按真实时间运行。

## 敌人能力范围

边缘模糊范围保持原样，`canEnemyAct` 仍限制清晰区；`EnemyRange.inAttackRange` 另行控制启动范围。普通能力默认 310，可通过 `EnemyProfile.attackRange` 定义。驻地单位在范围外先接近，再驻地施法；冷却在射程外不倒计时，因此不会刚走进来就立即打出积攒攻击。

冲锋范围按 `chargeSpeed × min(1.35, pressure.speed) × 0.42` 计算，给加速和接触留余量，实际冲锋持续 0.53 秒。路径预警锁定发动时的目标位置。五档难度、两种冲锋单位均验证可以实际接触静止目标。

直接发射入口及延迟来源会重新验证允许范围。已经发出的独立子弹继续飞行；Boss 保留专用场地攻击与预警，不套普通敌人射程。远程单位最后 0.75 秒射击准备显示渐亮外圈。没有全局并发攻击限制。

## 五档节奏

| 难度 | 生命 | 基础出敌间隔 | 基础闪避充能 | 攻击 / 预警时间系数 | 敌人基础生命系数 |
| --- | --- | --- | --- | --- | --- |
| 启程 | 155 | 4.30 秒 | 3.60 秒 | 1.60 | 0.72 |
| 冒险 | 125 | 3.25 秒 | 4.20 秒 | 1.30 | 0.90 |
| 深渊 | 110 | 2.25 秒 | 4.80 秒 | 1.08 | 1.12 |
| 噩梦 | 100 | 1.80 秒 | 5.30 秒 | 0.94 | 1.28 |
| 灭世 | 90 | 1.50 秒 | 5.80 秒 | 0.84 | 1.44 |

表中为基础值，章节 / 波次的显式成长和遗物仍会调整。低档生命、伤害、精英比例与速度更宽容；后续生命和频率成长减缓。清完波次后的喘息为 4 / 3.5 / 3 / 2.5 / 2 秒。所有档位保持同样的弹反窗口、冷却和闪避无敌，难度不通过改变基础按键手感体现。

启程 / 冒险每章的渐进词长上限增长 1，高档增长 2；词库选择与关闭渐进仍由玩家明确控制，不根据打字表现暗中增压。处置敌人仍是主要输出，弹反避免持续消耗闪避，闪避可保留给范围攻击和改变位置。

`tools/balance.cjs` 已改用合法的方向持键、弹反与闪避输入，并覆盖四本法书。运行 `npm run balance:defense` 可重现本轮矩阵。`defense-balance-probe.json` 记录 30 / 60 / 90 WPM、五档难度、四本法书的 150 秒规则输入模拟，以及低档关闭防御的对照；未覆写生命、冷却或无敌。当前固定小学词库样本中低档 30 WPM 可持续推进；高档也能被精确反应的机器人保持存活。本探针用于发现规则和节奏问题，不将其视为人类难度标定：机器人读取精确威胁，没有模拟误字与分心。

## 启动与界面

`StartupGate` 在首页之前展示简约页面，等待 Three.js 渲染器预热、四张法书图片和字体加载，完成后显示任意点击 / 任意键继续提示，配合呼吸光晕、漂浮光点和缓慢旋转的符印。点击屏幕任意位置或按任意键进入首页并解锁音频。失败显示错误和重试；不能启动不可见的战斗。大词库仍在选定出征时完整按需读取，不在启动时解析全部词库。出征读取的取消 / 重试保护继续有效。

暂停页的开放背景、无外框布局、衬线标题、刻线选项和高对比主按钮推广到共享 Modal / ChoiceCard：准备出征、遗物、路线、设置、词库和图鉴统一使用。保留字段焦点、下拉键盘协议、窄屏滚动与减少动态。HUD 显示弹反就绪 / 冷却 / 活跃窗口、方向映射和无敌剩余时间；Three.js 在角色前方绘制弹反环与成功冲击波。

- 本轮 UI 12 组、加载 4 组、全屏 8 组回归通过，共 31 组浏览器检查。
- `npm run build`：内容校验、TypeScript、依赖边界和离线文件完整性校验。
