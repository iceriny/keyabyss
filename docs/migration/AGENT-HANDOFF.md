## S1 的实施次序与出口

1. **完成基线对应。** 在[数据映射](DATA-AND-ASSETS.md)中逐项登记 58 件原遗物的旧 ID、当前原生 ID、恢复／保留／合并决定、真实触发入口和现有证据。先审查源码，不先写一套新的内容目录。新增内容不进入本阶段池。
2. **切断场外复杂配置。** 首页不再导向天赋购买；以主书直接起局。奖励资格与编译同步脱离永久许可。线性成长接入前以零增益运行，人工字符和记录照常保存。
3. **恢复代表性规则。** 覆盖直接增伤、无错字、长短词、复制、防御、恢复以及各书特色；例如双生笔尖恢复周期复制，短咒连珠恢复短词收益，停笔沙漏恢复争取输入时间的用途。精确参数结合真实战斗校准。Ctrl 主动补全与已确认输入语义继续保留。
4. **贯通第一章。** 四书都能用普通档完成有差异的房间、三选一、简单路线和一个正式 Boss，并正确进入胜败与重开。第一章验证使用明确的代表性遗物子集，不冒充 58 件已经全部恢复。
5. **观察打字核心。** 检查连续输入是否流畅、词咒是否清楚、拿遗物后作用是否可感知、防御是否争取输入机会、Boss 是否要求合理转火。自动化结果与真人手感分别报告。

实现时先处理影响这些出口的依赖，随后清理退出代码／资源／测试／指南引用。不为删除天赋先重写整个 SpellRuntime，也不同时保留两套正式战斗执行器。被删效果的材料可以继续用于保留画面，不按目录名一刀切删除资产。
