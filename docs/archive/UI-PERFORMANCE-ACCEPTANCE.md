## 天赋图

- 使用整个桌面视口。预算、返回、搜索及页脚固定；右侧详情悬浮在图上，正文内部滚动，按钮保持固定。
- 四书起点组成中央核心，拓扑距离决定向外层级，法书与功能族决定扇区，前层邻接角度用于整理分支。图谱和路线由内容生成，两张图仍共用布局、避障和交互逻辑。
- 首次测量前不查询空间索引；查询范围极大时改为检查有限的现存节点，杜绝遍历海量空网格。整图购买状态仅在构筑改变后重算，选择节点只更新详情。
- 相机更新每动画帧合并一次；滚轮使用可取消的原生监听器；搜索和键盘定位避开详情覆盖区，并保证定位后的文字可读。
- 全屏图完全遮住书库时停止背后菜单场景的动画提交；关闭后恢复原菜单。

开发版图谱首次节点可见约 106 ms，发行版一次采样为 81 ms（点击至节点可见，非跨机器保证）。已查看 1920×1080 全图、详情及 1024×640 窗口截图。相关截图与交互证据：`.temp/four-issues/talents/`。

## 运行性能

保留原有粒子数量、特效强度、分辨率、Bloom 和扰动效果。本轮将相同帧的粒子阻尼计算提到循环外，原地整理过期视觉对象并保持绘制顺序，空粒子系统停止无效更新；文字排版按目标缓存，仅在词、释义或设置变化后重新度量。位置和命中框每帧仍跟随目标，事件选择状态也正确冻结视觉时间。

扩展现有原生渲染测试，分别记录模拟、视觉更新、GPU 实例填充、粒子、文字绘制耗时，并增加持续粒子爆发场景。以下为同机 Windows headless Chrome、1920×1080、DPR 1、最高特效的单轮采样；每场景约 2.2 秒。CPU 提交耗时包含向渲染器发出命令的时间，不是 GPU 时间。

| 场景 | 修改前 CPU 提交 P95 | 修改后 CPU 提交 P95 |
| --- | ---: | ---: |
| 普通战斗 | 1.4 ms | 1.3 ms |
| 密集弹幕 | 1.6 ms | 1.6 ms |
| 多场域 | 1.6 ms | 1.3 ms |
| 终式 | 1.9 ms | 1.4 ms |
| 持续粒子爆发 | 2.7 ms | 2.4 ms |

前后均约 60 FPS。粒子压力样本峰值分别为 1817 / 1844 个，不以削减粒子换取结果；视觉随机与帧时序会影响实际峰值。这些短采样支持本轮优化没有明显回归，不能推导所有设备或所有构筑都达到同样帧率。

多线程已纳入取舍：本机样本的模拟步骤 P95 约 0.2–0.3 ms，粒子高压更新约 1 ms。当前优先消除重复工作，并保留已有 GPU 实例化与批量提交。没有证据支持为了这些样本把可变战斗状态、输入次序和大量渲染对象跨 Worker 传递；因此本轮没有引入 Worker 或新的线程依赖。若后续真实低端设备采样呈现主线程长期超预算，应先用同一测试区分模拟、文字栅格化和 GPU 压力，再决定迁移边界。

原始前后样本：`.temp/four-issues/performance/before-stress/performance.json`、`after/report.json`。暂停画面像素一致、粒子到期、纹理复用、扰动与文字分层、WebGL 丢失/恢复检查均通过。
