# 书脉天赋

天赋是一张跨元素连通图。四种主书各有一个起点，所选主书的起点自动点亮且免费；穿过其他书的起点需要支付一点，并获得该元素的晶体、热载、传导或复写能力。每个节点必须与主书起点连通。撤回节点时，失去连接或必要能力的节点一并撤回并返还点数。

正常档案初始有两点。每累计完成 120 个有效人工字符获得一点，最多 24 点。只统计成功完成词条中的实际人工输入，主动结束也保留已完成的字符。旧战报没有 `manualCharacters` 时不追溯奖励。每个 `runId` 保留已计入的最大累计字符，继续周目只结算增量；结算 ID 防止同份战报再次奖励。

合订消耗两点，开放主书以外的一本副书。副书每 12 个人工有效字符供给一份材料，最多缓存三份，每次人工主术最多消耗一份。独卷也消耗两点，使主术威力提高 30%；合订和独卷互斥。遗响必须连接承页并实际拥有承载能力。

天赋在书库和战后调整，按主书分别保存分配。切换主书会重新检查该主书的图与副书。准备出征时可查看花费并选择已经开放的副书。战后记录保存出征天赋、副书、有效人工字符以及该次结算获得的点数。调整天赋用于下一次新远征，继续当前周目沿用本次远征的出征配置。

`resolveTalents(book, allocated, budget, godMode)` 是模拟与 UI 共用的入口，返回有效节点、花费、数值授予和能力。它清除未知、重复、超预算、不连通及互斥的输入。普通预算只接受有限数值，取整数后限制在 0–24；God Mode 不限预算，但仍检查图与能力。节点遍历使用内容固定顺序，所以输入数组顺序不会影响结果。原生主书起点只提供能力，不额外授予元素载荷。

普通进度保存在 StorageAdapter 的 `talents` 键，包括累计字符、各局最高计入值、结算回执与按主书分配。God Mode 配置单独保存在 `talents-god`，不奖励或消耗普通进度。新增的 God 战报只增加档案 `godCareer`，其检查点标记 `godMode`，不增加普通职业累计。God Mode 面板提供清理操作，重置其配置、清除 God 职业累计，并删除 God 战报与所有已标记的 God 检查点，包括已经超出最近 50 份战报范围的检查点。普通进度、普通战报和词库设置保持不变。现有档案不含 `settledIds`，以战报结算 ID 与按局检查点去重；旧 God 战报仍可识别并删除，但旧职业累计没有来源标记，因此不推算或改写该聚合值。

图与节点定义位于 `src/content/talents.ts`，纯校验位于 `src/shared/talents.ts`，跨局结算位于 `src/application/talentProgression.ts`。回归检查：`node --test tests/talents.test.cjs`。
