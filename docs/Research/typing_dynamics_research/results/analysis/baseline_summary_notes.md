# 主实验汇总表说明

所有数值是指定参数下的实际仿真输出，不是本次采集的人类实验数据。

A：连贯英文，自写句子，固定双槽位。B：独立随机英文词，固定双槽位。C：同分布随机词、随机静止位置。D：同分布随机词、随机位置、标称3度/秒缓慢移动。

主词库5875词，长度3–8字母，均匀独立抽取。当前词首次击键时显示下一词；允许依靠记忆输入；词尾纠错，空格提交；每场60秒墙钟计时。

`wpm5_mean`为每5个正确字符折算一个标准词。`correct_words_per_min`是完整正确英文词数/分钟。正确字符包含正确提交空格，故`correct_characters_per_min = 5*wpm5_mean = correct_letters_per_min+correct_words_per_min`。

`wpm5_ci_low/high`是固定模型参数下、按合成个体聚类重抽样的均值蒙特卡洛区间。`wpm5_person_p05/p95`是合成个体两场均值的5%与95%分位数，不是现实人群已验证的预测区间。参数先验不确定性见`uncertainty_intervals.csv`。
