# 收益与难度评估

适用范围为四书、当前196件局内遗物、简单路线、轻量线性成长和连续挑战。遗物保留原有跨书效果，按当前四书能力组织前置与强度；目录与叠加边界见[遗物系统](RELIC-SYSTEM.md)。目标规则见[产品设计](PRODUCT-DESIGN.md)与[四书战斗机制](FOUR-BOOKS-DESIGN.md)，实际状态见[阶段总结](STAGE-SUMMARY.md)。

## 评估时点与比较方式

S1 检查一章的输入、奖励和手感是否成立，S2 检查完整内容与连续挑战。正式内容和获取齐备后，在 S3 统一校准收益及五档难度。平衡不接入每次内容新增或提交钩子，不为每件遗物新建脚本。

同组比较固定词库／词长、难度、场景、种子和输入水平；分别保留慢、中、快三档的结果，不用平均数掩盖某档不可玩。输入通过正式路由，记录实际耗时、有效人工字符、错字、目标选择和防御动作。自动化能复现规则，不能代替真人手感。

观察清房／Boss 推进、实际扣血与过量、受到的伤害、死亡、可用输入时间、控制／防御收益及取得遗物后的变化。满血治疗和未用护盾不冒充收益；不要求把所有效果换算成同一种材料或统一 BP 预算。

## 四书比较口径

四书保留不同的收益曲线和擅长场景。相同输入投入下，同时观察短战斗、持续波次、稀疏／密集敌群、孤立 Boss 与增援；保留实际敌人数、存活时间、构筑与玩家转火条件。

- 纸灵同时看启动投入、稳态输出、追回前期损失的时间和停笔恢复；房波保留影响启动代价的支付频率。
- 灰烬分别看一发后转火、补伤与余热收益，以及长时间单体战的点数饱和。普通敌人的实际存活时间决定饱和是否发生。
- 寒墨按实际额外命中数评估穿透；控制结合攻击进度、冻结覆盖、冰雾遮蔽及有效输入时间解释。
- 雷鸣按有限敌群中的实际连接、伤害与剩余威胁评估；带电节点死亡和新敌入场影响传播的持续性。
- 词长同时影响单次威力、完词频率、固定状态增量与终极收入；死亡后保留的输入投入纳入比较。

未来需要量化时，可按[四书遥测参考](COMBAT-TELEMETRY.md)选择业务事件与指标。评估与机制交付可以使用现有检查和人工观察，是否引入遥测采集按实际需求决定。

## 成长与最高档门槛

场外成长全书共享、自动取得、较早封顶，只提供少量基础容错。具体阈值和幅度根据完整远征校准；最高档压力不倒逼恢复大天赋树或高倍永久数值。

| 起始条件 | 评估目标 |
| --- | --- |
| 前四档，初始成长、空遗物 | 不设高手必须先刷成长的门槛；各档保留明确压力差异 |
| 最高档，初始成长、空遗物直接开局 | 高手不能直接完成通关，单独检查，不由总体平均分抵消 |
| 最高档，已积累线性成长、空遗物 | 观察少量场外帮助的边界，不默认成长满级即可通关 |
| 较低档通关后保留遗物升入最高档 | 合理遗物积累与较好运气下，中等输入水平存在通关机会；这是重要的正式挑战路径 |
| 最高档后续周目 | 成熟组合继续面对公开压力，检查满层候选、补给和长期运行，不承诺无限周目均可通关 |

“高手”“中等水平”“较好运气”须在评估前声明输入范围、准确率、防御策略和种子取样方式，并辅以真实试玩。结果只适用于这些条件，不把有限机器人样本写成所有玩家的数学证明。若初始高手仍能通关最高档，按目标记录为未通过；不暗中检测账号等级判负。

升档和周目压力分别设计，避免同时增加 mode 与原 stage／loop 公式产生未经校准的重复增压。难度选项、当前档位、继续后的档位或周目对玩家可见。

### 五档与连续挑战采样

当前成长定为每 1000 个有效人工字符增加 4 点初始生命，5 阶封顶；新远征取快照，连续升档不重新领取。难度主要改变敌人耐久、出怪、攻击和防御窗口，最高档不检测账号等级或强制判负。最高档普通敌人生命倍率为 4.8、基础出怪间隔 0.55 秒、基础伤害倍率 6；章节伤害增幅在深度 2 封顶，生命、遭遇和 Boss 仍随章节推进。后续周目另增生命和攻击压力。

采样使用正式 Unicode 输入、随机奖励和休息路线，不注入生命、伤害或胜利；防御模型可预知碰撞几何，优于一般真人。慢速为 3 字符／秒、快速为 8 字符／秒且准确率 100%；中速为 5 个调度字符／秒，每二十次调度在已有输入进度时错一个字，实际准确率约 95.2%。固定奖励优先级为通用伤害、无错收益、生命、续命及护盾，没有按法书优化、不使用重抽或 Ctrl。结果说明这些可复现路径，不穷尽构筑与玩家能力。

- 四书初始成长的普通档慢速、梦魇快速样本均通过九房；中速从普通升至困难、梦魇也均实际通关，前四档没有账号成长限制。
- 两种种子的最高档快速冷开均四书败局。寒墨恢复主目标完整伤害、每个穿透目标独立 67% 伤害后已复测，两种子分别败于第八、三房；正常／强化主术最多命中二／四个目标，R044 再加二个，副目标不耗尽主目标的伤害。
- 雷鸣中速从普通保留遗物升至最高档完成九房，证明正式继承路径存在通关机会。纸灵与灰烬在相同通用取奖策略下分别败于最高档第八、七房；额外 20 点成长生命没有改变该样本胜负，不把场外成长当作通关保证。

主要证据在 `.temp/shrink/flow/`：`s2-870376`（慢／快与满成长冷开）、`s2-1055875`（中速继承）、`s2-881746`（第二种子冷开）。这三份中的寒墨属于穿透修复前对照。修复后的寒墨为 `s2-1564860`、`s2-904132`（两种子冷开）及 `s2-991865`（中速继承）：前三档全部通关，最高档败于第四房，起始遗物分别为 0／17／22／26 件。机制修正不保证不同战斗节奏下胜负单调改善。真人输入、防御及各书适配构筑仍须与这些机器人证据分开记录。
