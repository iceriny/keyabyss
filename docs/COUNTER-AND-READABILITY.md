# 弹反反馈与文字稳定性

## 行为调整

- Tooltip 仅由鼠标悬停正文触发。正文为 `p`、`li`、`dd` 或显式 `data-prose` 子树；标题、按钮名称、HUD 读数和键盘焦点不触发。每段只标记一次同一个术语，别名按同一 ID 去重。段落渲染标记避免共用组件再次处理后重复标记。
- 文字框固定在所属单位上方，边缘仅做视口夹取。取消局部避让、空位网格搜索和全局重排。绘制优先级：锁定目标 > 威胁等级 > 单词长度 > 稳定 ID。威胁按蓄力/冲锋、首领、精英、危险能力、其他能力、普通追击、道具分层，不随细微距离变化反复排序。鼠标命中从最上层向下查找。
- 弹反接触目标使用独立冲量，不再受通用 ±720 限幅。基础速度 2200，按质量平方根衰减；首领保留部分抗推能力。直接目标受 32 点基础弹反伤害，至少 1.2 秒硬直与 2.4 秒能力恢复间隔（首领硬直较短）。
- 每个成功窗口产生一次 105 范围压力波（计入敌人碰撞半径），周边敌人无伤击退，基础冲量 1050。力度仍按原来的 185 距离尺度略衰减，与触发范围解耦，因此同一位置的击退力度不变。压力波不清除、不反射、不推开弹道；原有近身弹反对弹道的反射照常执行。
- 压力击退期间降低阻尼，并禁止这次击退造成额外撞墙/撞敌伤害，避免把无伤控制变成隐形范围攻击。被推开的敌人暂不结算接触伤害。
- 成功弹反后触发 0.52 秒时间反馈：前 0.06 秒为 6% 世界速度，随后用 smoothstep 平滑恢复。只激活不成功不触发。世界时缓采用解析积分，避免不同帧率改变总时长；与停笔沙漏取较慢效果，不相乘。闪避充能、弹反窗口、冷却和无敌仍按真实时间结算；暂停冻结，换房/重开/回主页清理。
- 弹反闪光、射线与碎片略减，压力形变增宽、扩大范围并延缓衰退。整体位移系数低/中/高为 1.25 / 2 / 2.8，实体位移采样权重由 0.18 提至 0.52。文字层不扭曲，减少动态效果关闭位移场。

## 检查

构建（类型、架构、内容、离线资源）通过；136 项单元检查通过，包含位移距离、无伤周边控制、碰撞保护、时间曲线及恢复、文字位置与优先级。浏览器验证包含 UI 12 组、文本 5 组、原生渲染 2 组，以及弹反音画反馈回归。

`tests/counter-visual-browser.py` 在同一帧比较开启/关闭位移的 GPU 输出，1080P 下有 37,094 个像素的 RGB 差值超过 24，确认不是仅增加光效；另验证三档强度、减少动态效果、24 个拥挤文字的固定锚点与最上层命中。截图保存在本地 `docs/test-output-counter/`。

本目录此前没有 Git 仓库，本次建立初始源码提交。版本库保留代码、内容定义、词库、音效切片元数据和原始法书/SVG；依赖、构建产物、自动生成的 public 资源、测试截图与大型原始音效包不入库。重新构建音效需在 `art/Magic UI Designed/` 放置已有的本地源素材。
