# 特殊事件候选内容卡

> 历史归档：2026-10-08 调整范围前的设计、计划或证据。正文中的要求与“下一步”不构成当前任务；当前实施见[交接文档](../../../migration/AGENT-HANDOFF.md).

[内容总览](05-CONTENT-CATALOG.md) · [事件框架](04-SYSTEM-FRAMEWORK.md)

共 32 个候选。每个事件有两种不同的构筑行动，以及一个明确的基础行动；所有事件另外提供“保持现状，离开”。表内是设计效果，不是最终玩家文案。

这 32 项已接入原生出现池、冻结报价、资产交易、租期、试炼和奖励债务，接口见 [M3 接入说明](../migration/M3-INTEGRATION.md#事件和获取交接)。全部 96 个行动的合法情境与生命周期、定向失败及正式六房流程分别记录，证据见[阶段总结](../STAGE-SUMMARY.md)与 [M4 验收记录](../migration/M4-ACCEPTANCE.md)；目录检查不代表一局随机遇齐全部事件或收益已经平衡。

只有至少两种行动合法且产生实际变化时才进入出现池；不为了凑三选项强塞无用恢复、无目标替换或不存在的未来奖励。需要挑选资产时先让玩家选具体对象，再冻结最终报价。

房级=下一战斗房，章级=当前章剩余战斗，局级=本局。基础行动也占用这次事件路线的机会预算；不能在不改变机会预算的情况下偷偷多发一份完整奖励。数值起点见[内容总览](05-CONTENT-CATALOG.md)的参数表，最终报价必须展示具体数字和对象。

## 必须共同遵守的细则

1. 抵押记录具体实例、层数、使用次数及获取效果。返还恢复资产而不是重新领取，不重置复活、治疗、每房代价和敌弹回执。
2. 借来的能力或物品带租期；临时能力不授予特殊遗物许可。所有永久获得的特殊遗物仍需出征天赋许可，改名为事件变体也不能绕过。
3. 临时降低生命上限到期时只恢复上限，不免费把生命补满；同理暂减空间恢复后不自动制造法术。
4. E10、E25 等材质覆盖只使用已登记模式与参数范围。若替换结果是目录中的特殊遗物，必须满足该遗物许可；没有许可时只可选择合法普通工具或临时规则覆盖。
5. 无后续奖励时不能新增未来债务；最后一章不能提供无价值的跨章返还。到期边界在进入章节前统一结算。
6. 试炼失败不激活收益，死亡终结本局；已付代价和失败原因留在本局记录，不扣跨局天赋点。
7. 事件不假定低生命或缓慢输入是差表现。筛选依据实际能力和交易合法性，不暗中按玩家成绩补偿或惩罚。
8. E17 的资格来自正式标记创建事实，持有相关能力但未产生标记不满足条件。该事实随本局保存；行动只改变期限内后续新标记的用途，不搬运、恢复或再次兑现旧房标记。
