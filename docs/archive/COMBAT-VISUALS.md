# 战斗组合表现

> 历史归档：保留当时的方案、状态或检查结果，不作为当前待办、完成声明或实施约束。当前入口见[文档导航](../README.md)。

战斗状态由模拟生成，渲染层只读取位置、元素和寿命。承载纸页、冰晶与雷电分支共用现有图集、材质和实例批次，不增加资源 HUD 或独立玩法事件。

## 纸灵与纸页

纸灵离轨、俯冲、返回和交叉飞行采用三次 Bézier 曲线。起点控制柄沿上一阶段速度建立，低速离轨也保留原方向；控制柄最长为航程的 80%，极近距离保留至多 12 个世界单位的转弯空间。返回控制柄接收轨道切线，端点采样限于曲线的 0–1 区间。各阶段速度、时长范围、目标选择和伤害定义沿用原值。

纸灵和纸刃拖尾使用带切线长度限制的 Hermite 采样。相邻控制柄由同一个节点切线决定，短段和重复坐标不会产生长回环。输入坐标保持不变；采样最多 64 点，实际画质档位采用 36、48、60 点预算。冰弹和雷电不使用纸灵曲线。

承载纸页复用 `paper-spirit` 图集，尺寸小于召唤纸灵，并以冰蓝、暖橙、浅金或纸紫墨印表达已承载的元素。页面中心跟随模拟提供的坐标，渲染只增加轻微角度摆动与淡入淡出；每帧最多显示六页。每页最多一个精灵和六个效果实例。

减少动态设置下，纸灵拖尾只保留最近六个历史点，最多采样十二点并降低亮度；额外飞散纸屑和纸页摆动关闭。纸灵与纸页的实际位置始终可见。

散字使用 Canvas 的词令字体显示，沿模拟提供的位置飞行，不额外改变运动。落字对应的敌人词令字符以暖金覆盖，位置由原词文字度量决定，不改变词令宽度或基线。只在标记记录与当前词相符时显示高亮，换词后旧记录不会染色。飞行字母不使用实体框；减少动态时关闭文字光晕。

## 冰霜与雷电

碎冰命中使用放射晶体、晶体白色细棱和外围细冰屑形成远近层次，低亮度冷雾在命中范围内展开。沿用现有碎片事件和颜色，因此冰霜与镜面碎片各自保留原色。高画质单次碎片效果最多约 63 个普通实例，位移效果继续受既有 32 个实例上限约束。

雷电保留三层主路径：外侧弱光、元素色主干和细白芯。更细的侧枝从主干节点分出，分支长度由主路径距离与固定效果种子决定；高画质追加短末梢。每条主路径最多 48 段、约 202 个普通实例，所有分支只绘制图形。减少动态时减少侧枝并关闭末梢。

所有抖动和变化来自现有效果种子、页面标识与显示时间，不调用玩法 RNG。总绘制继续受 `InstancedBatch` 既有容量限制。
