## 关系与自动布局

每本书从中心分出三条机制分支。普通强化按作用组织，机制节点接入对应分支，关键天赋接到其强化的机制。跨书路线不再使用统一的第 7、第 10 个普通节点作为端点。

| 共用路线 | 两端机制 |
| --- | --- |
| 合订 | 晶构 ↔ 蓄热 |
| 独卷 | 短路分枝 ↔ 复文 |
| 储备回收 | 余热回收 ↔ 回路 |
| 碎片与连锁 | 析晶 ↔ 导流 |
| 法术防御 | 冰匣 ↔ 护页 |
| 字母标记 | 焚页 ↔ 承页 |
| 纸灵接力 | 递书 ↔ 页间中继 |
| 冰火转化 | 热匣 ↔ 解冻出口 |

`src/content/talents.ts` 是可通行连接的唯一来源，规则解析与图形展示从这里读取。空间接近本身不新增解锁权限；能力前置与互斥仍由规则验证。

共享布局器在构建时完成：按连接距离选择中央法书顺序、全图弹簧求解、减少交叉、标签避让、优先安排短路径，再让长路径避让已有线条。没有逐节点坐标、随机数或页面打开后的物理模拟。登记顺序反转仍生成相同布局。非多起点图继续使用同一引擎的区域布局分支。

详情中的路线逐步调用真实分配规则校验，按点数成本搜索；预算不足时仍可查看未来路线。对于无法找到满足条件的路线，不展示未经验证的路径。该搜索不承诺穷举所有需要绕行取得额外能力的构筑。相邻天赋和路线节点可点击查看。

## 视觉

普通强化、机制和关键天赋有不同尺寸与轮廓层次；符号对应冰晶、热量、连锁、碎片、纸页、防御和回收。节点增加石质渐变、金属刻边与局部高光。连线使用凹刻底层、端点法书色过渡、圆滑转折及金色路线提示。互斥与额外条件仅在相关节点被选中时显示，避免混入全图成长主干。

保留全屏图谱、右侧固定悬浮详情、桌面键鼠操作，以及遗物图共用的缩放、搜索和渲染逻辑。

- 25 项天赋及图布局测试通过：四书连通、撤点、预算、能力与互斥、路线逐步分配、存档隔离与迁移、顺序无关布局、节点和文字避让。

- 类型、架构与发行构建通过；159 个离线文件、7z 与 ZIP 完整性检查通过。
- Python Playwright：图谱与事件 3 项、分配及跨局持久化 6 项通过。覆盖搜索、路线高亮、相邻节点跳转、缩放、拖动、固定详情、普通预算、副书、God Mode 清理和事件单次提交；无页面或控制台错误。
