秘序 Arcana 256

把抽象概念写成优雅、克制的魔法符文。256 个独立字形，一字一义；真实可变字重，保留轻盈的曲线与开放的留白。

输入下方字表中的汉字，或 U+E000–U+E0FF 私用区字符。点击任意字卡可插入对应汉字。

256 个概念 · 字形索引

可选连字

两个概念经共享笔画、围合或嵌套重组为一个新的合成符号。仅开启 dlig 时替换，原始文字仍保留两个字符。

在设计软件中使用

安装 fonts / Arcana256-VF.ttf，选择 “Arcana256 VF”，再调整 Weight 轴（300–750）。不支持可变字体的软件，可安装 Regular、Medium、Bold 三个静态 TTF。两套家族名不同，可同时安装。

这份 HTML 已内嵌 WOFF2 字体，无需联网，也不需要先安装字体。

映射与兼容性

汉字只是便于输入和记忆的语义别名；同一字形也映射至 PUA。该字体没有普通字母、数字、标点或完整汉字字库，仅含 256 基本符号、可选连字及空白的 .notdef / 空格。其他字符可能由系统字体回退显示。

这些是原创虚构符号，不代表真实文字、宗教或历史传统。语义由本项目约定；连字不是自动语言翻译。
