# 文本、术语与 UI 反馈

后续交互修订：提示只在正文鼠标悬停时触发，同段相同术语（含别名）只触发一次。标题、按钮名称、HUD 读数及键盘焦点不再触发，详见 [COUNTER-AND-READABILITY.md](COUNTER-AND-READABILITY.md)。下文首次接入时的覆盖范围以此修订为准。

## 当前效果

- `GameText` 统一渲染主菜单、准备出征、设置、指南、图鉴、遗物选择、路线、战报、加载提示和 HUD 文案。整数、小数、百分比、正负值、千分位、无限符号及带量词的中文数值统一以金色强调。
- 57 条战斗术语可以在图鉴的「术语」页查阅，支持关键词搜索、分类和空结果提示。法书、终式、遗物、敌人及路线名称也可悬浮解释，共 150 个解释条目。
- Tooltip 延迟 280ms 出现，离开后延迟 160ms 关闭；允许移入提示内容阅读。Esc 先关闭提示，点击、输入、切换界面、失焦或锚点移除均会关闭。提示本身不增加 Tab 停靠点，也不占用按钮点击。
- UI 增加选中光线呼吸、按钮底部光线展开、主按钮扫光、图鉴卡片符号反馈、弹窗标题线展开、内容渐入、施法和防御状态辉光。低档降低装饰成本，减少动态效果关闭新增动画。
- 窄屏主菜单的法书选择与底部操作说明按内容顺序排列，避免重叠挡住术语。

战斗咒文的待输入字符、词令缓冲和编辑框保持原始文本，避免干扰正确字符与输入进度；战场飘字继续使用原有伤害、治疗和元素颜色。

## 结构与扩展

`src/content/glossary.ts` 是术语说明的唯一来源。`TERMS` 保存概念、分类和别名；`GLOSSARY` 将现有内容注册表中的法书、终式、敌人、遗物及路线定义组合进来，不复制这些内容的说明。新增注册内容会自动进入名称提示索引。弹反数值读取 `DEFENSE`，避免说明与规则分离。

`src/shared/game-text.ts` 是无 DOM 依赖的解析器。术语用 Trie 按最长名称匹配，避免「直接施法」「闪避充能」被短术语抢占。扫描复杂度为 O(文本长度 × 最长术语长度)，不按整本图鉴逐项搜索。512 条有界缓存避免计时数字不断累积。

新组件使用方式：

```tsx
import { GameText } from './GameText';
import { Tooltip } from './Tooltip';

<GameText><p>直接施法伤害提高 35%，获得 12 点护盾。</p></GameText>
<Tooltip title="刷新候选" description="消耗 1 次重掷。">
  <span>查看规则</span>
</Tooltip>
```

`GameText` 可以包裹整段原生 JSX 树；自定义组件在内部包裹自己的输出。共用的 Button、ChoiceCard、Stat、Field、Select 和 Modal 已接入。`data-plain-text` 可标记需保持原样的子树；`terms={false}` 仅染色数值。解析只生成 React 文本节点，不使用 HTML 注入或重写已挂载 DOM。

`Tooltip` 是轻量触发组件，`TooltipHost` 是整个应用唯一的 Portal。定位复用 `@floating-ui/dom` 的 offset、flip、shift、autoUpdate；仅打开提示时监听位置与锚点有效性，关闭后清理，不为每个术语创建动画循环。提示正文只染色数值，不再嵌套提示。

`src/ui/effects.css` 集中管理新增文本视觉和 UI 反馈。应用通过 `body[data-ui-fx]` 同步特效档位，通过 `.reduced-motion` 同步减少动态效果设置。
