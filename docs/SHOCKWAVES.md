# 冲击波与空间位移修正（2026-09-21）

## 排查结果

所有空间位移入口已核对：弹反、冲击、终式、雷电、内爆、火焰爆发、冰霜碎裂，以及持续引力场和火场热扰动。

旧径向场使用正向 UV 偏移取样，导致内容视觉上向内收缩；弹反同时叠加中心旋涡，亮环和位移圈又使用不同扩散曲线。普通内爆的亮环收缩，但位移圈仍然扩张。高强度时逐轴限制 UV 位移还会破坏斜向径向对称；实体与背景采用不同位移权重，辉光留在原位，进一步造成分层与拉扯感。

## 实现

- 位移场统一表示可见运动方向，合成使用逆向取样 `sceneUV = uv - motion / worldSpan`。世界坐标 Y 向下与 UV Y 向上的换算保留在统一出口，同时处理局部旋转。
- `Shockwave.ts` 为可见环和位移场提供同一个传播半径。爆发向外扩展，内爆向内收缩；压力峰后有较弱反向恢复区。位移仅发生在经过的环带中，中心恢复正常。
- 振幅随波宽约束并随时间消退，避免折叠采样产生重影。位移四边形预留 3 个波宽，移除原先从半径 55% 开始消退、过早削弱波前的遮罩。
- 弹反不再混入旋涡，各档只占用一个压力场实例。可见环与波前同步，保留克制的亮边和碎片。
- 背景、实体、辉光共用同一个取样位置。重叠位移按世界空间向量长度限幅，避免逐轴夹取使圆波变形。Canvas 文字不参与变形。
- 引力场保留内吸和切向流动，火场保留热扰动；普通无位移命中特效使用原有扩散曲线。低/中/高档、32 个场的预算、减少动态效果与离线渲染保持兼容。

## 验证

- 构建、类型、内容、架构和离线资源检查通过；138 项单元检查通过。
- `tests/shockwave-browser.py`：3 组浏览器检查。用真实 GPU UV 渐变探针检查上下左右的合成取样方向，确认外扩与内缩相反、无切向串扰、中心稳定；检查连续帧半径、七类瞬态效果、引力与热扰动及减少动态效果。
- `tests/counter-visual-browser.py`：2 组浏览器回归通过，验证实际位移像素、特效档位、文字层与覆盖命中。
- 1080P 连续帧与探针结果位于本地 `docs/test-output-shockwave/`；波前半径在四个时点依次约为 46、87、135、180 世界单位。

本轮没有改动战斗伤害、击退或时间反馈规则。

## 持续火场热扰动收敛

上一轮仅降低单个火场振幅，多个火场仍会叠加位移。现将单场振幅收敛至 0.20–0.36 世界单位，并降低空间频率和流动速度；相交火场按相交数量分摊位移预算，远处火场不受影响。场地最多 14 个持续场，直接做圆形相交检查，无额外渲染通道和贴图。光效、火焰爆发、弹反与引力场保持原有参数。

构建与 2 项冲击波单元检查通过；`tests/shockwave-browser.py` 的 5 组检查通过。真实 GPU 位移缓冲验证覆盖 1 / 14 个火场、低 / 中 / 高三档和 3 个动画时刻，最大位移约 1.34 世界单位（1080P 下约 2 像素）。保留减少动态效果关闭位移及其他冲击波的四方向验证。
