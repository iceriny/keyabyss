# 内容取舍与职责

定位：有效的内容取舍依据。输入为[旧系统盘点](../archive/build-system-design/01-CURRENT-SYSTEM.md)与[组合探索](02-COMBINATION-EXPLORATION.md)；完整旧内容追踪见[去向表](appendix-content-disposition.md)，保留集合见[候选内容](05-CONTENT-CATALOG.md)。部分规则已实施，实际范围见[阶段总结](../STAGE-SUMMARY.md)。

## 1. 判断标准

一项内容值得留下，不是因为已经有代码或图标，而是它提供了可以理解、能够实际使用的选择。按以下标准逐项判断：

1. 取得后能独立工作，或前置清楚且只需很短准备；不能三件集齐前全部无用。
2. 至少能与两种不同来源或用途发生组合；专门强化法书终式的内容可以例外，但必须明确其窄用途。
3. 增加目标、次数、容量、时间或新出口时，收益来源与失去的机会可解释。
4. 普通数值节点改善一种已理解的能力；特殊节点确实改变执行方式，不以更大的数值冒充机制。
5. 否定作用有理由：两种模式争用同一资源或同一决策，才互斥；不为维持预设流派互斥。
6. 对低血敌人、耐久目标、慢输入至少有明确可用边界，不要求所有内容处处强。

## 2. 保留的基础

| 保留方向 | 理由 | 必须调整的部分 |
| --- | --- | --- |
| 四书原生攻击、终式、闪避与弹反 | 维持鲜明手感，玩家仍在打字与选目标 | 原生效果要进入统一资源与事件事实，不能旁路重复获得奖励 |
| 跨局赚点、出征前配置、God 隔离 | 长期成长是已确认需求 | 为新游戏建立进度；后续更新保留本游戏已赚成长，M6 统一校准点数与成本 |
| 一词展开、死亡后继续已获后效 | 与快节奏、低血怪相容 | 将“已获资格”写成命中事务事实，避免多入口重复结算 |
| 复写、防御、遗响、储备、运输 | 能产生用途改变和价值反转 | 抽象成不同对象共享的操作，消除固定纸页或冰火组合判断 |
| 散字、词长、准确输入和连笔 | 保留打字游戏本身的构筑特色 | 奖励跟随真实字符、一次回执与机会转移，防止短词和辅助补全刷供给 |
| 纯数值、防御、恢复等易懂遗物 | 构筑需要可靠底座和新手可读选择 | 用统一 BP 重新定价，不能原封保留大幅乘算 |
| 演化、互斥、冻结事件报价 | 已有合理的资产与事务基础 | 演化根据真实改变设计，不继续每族固定六件 |

## 3. 重写与合并

### 固定开关变成可复用规则

`thermalRelease` 不再意味着“某几种特定法术的开关”，而是符合热量与外壳条件时执行提前开启。`carrierRelay` 对所有允许导电、尚有传递机会的保存对象成立。`mergePayload` 合并的是兼容份额和目标策略，不能丢失来源。

同一种操作允许从不同渠道进入，但多次取得操作许可不重复生成完整收入。重复来源要么改变明确参数、提供另一类对象，要么在候选池中排除实际无变化的选项。

### 同职能内容合并，差异回到参数与对象

- `paper-carrier`、`copyPages` 的重复入口汇入“复写”规则；保留数种制造纸页的遗物，它们在价格、保存时间、外壳性质上不同。
- 多处“遗响”汇入 T22；遗物可以改变它的释放对象、时间和损耗，但不以毫无独立用途的遗响开关占据普通随机奖励。
- `storm-relay`、`transport-relay`、`geometry-network` 归入转交规则与不同路径模式，不保留三处同开关当三种玩法。
- `paper-salvage`、`transmutation-return` 等区分为对象结束、无目标、地面区域结束三种真实回收入口；同一份剩余仍只可收一次。
- 合订与独卷都向全图开放；不再因旧桥位把兼修放在冰火、独卷放在雷纸之间。位置由概念关系决定。

### 去掉模板约束

八条共用路线不是新图的八条必经桥；十二个遗物族不再必须各有基础、强化、两分支、连接和事件版。一个机制可以只有一件独特遗物，另一个也可以有多种互不替代的加工工具。

数值节点允许重复，但重复位置必须服务真实路径。取消为了画图填充无关统计、为了凑族数量制造几乎相同的遗物、为了稀有度制造无代价全面更强的上位件。

## 4. 明确移除或替代的设计

| 被移除的设计 | 替代方向 | 移除原因 |
| --- | --- | --- |
| 冰与火两个布尔值共同触发固定碎片 | 易碎结构接受足量热加工后分配剩余威力 | 需要可迁移的规则，不需要隐藏配方 |
| 每个共用族固定七节点、每个遗物族固定六件 | 按独立作用、分歧和连接需求安排内容 | 模板数量不能表达玩法合理性 |
| 全局最多两个关键节点 | 真实模式互斥、路径费用、有限总点数 | 全局上限会切断合理的长路径和第三机制组合 |
| 永久点亮后撤点仍保留所有特殊遗物资格 | 本次出征配置生成稳定许可 | 否则长期配置对本局掉落失去意义 |
| 每个事件重复扣 3 生命换 2% 威力 | 事件各自至少两种实际不同的行动及离开 | 通用第二选项掩盖内容浅层重复 |
| 所有派生禁止继续触发 | 继承白名单、有限工作量、真实来源和单次领取 | 全面禁用会损失组合深度；全面放开会循环 |
| 纯靠更高敌人血量补高难度 | 供给、构筑成长、遭遇组织和公开推进压力共同设计 | 不把每个小怪变成等多词的木桩 |
| `hourglass` 的全世界 10% 时间、输入与冷却另走真实时钟 | 限定对象的局部缓行与有限防御窗口 | 不同时间轴的巨大放大足以覆盖其他构筑价值 |

“移除”是设计去向，不表示文件已经删除。实现时先退出注册并处理现有引用；若已进入本游戏存档，再处理其版本兼容。文件按仓库规则移入 `.delete/`，不永久删除。

## 5. 探索想法的取舍

| 想法 | 设计结论 | 进入候选时的边界 |
| --- | --- | --- |
| 热开／耐热的用途反转 | 纳入 | 针对外壳性质，二者是同一热处理槽的不同模式 |
| 份额聚合、分散、穿透、不同目标策略 | 纳入 | 分配已付份额；保持来源、命中上限和时间成本 |
| 地面区域参与导电与回收 | 纳入 | 有限储量与作用次数；不新增自主生产资源的单位 |
| 过量威力保留 | 收紧纳入 | 只转交尚未提交给目标的份额；已提交的过量伤害不重新铸币 |
| 敌弹作为一次有限返还机会 | 纳入关键节点 | 仅真实敌弹，一弹一次；不能产生人工输入或无限工作量 |
| 跨根聚合 | 暂缓主动机制 | 引擎保留分账能力；首批聚合限定同次人工根，避免把等待调度做成复杂资源游戏 |
| 自定义规则顺序、任意脚本遗物 | 不纳入 | 顺序由类型化阶段与模式确定，玩家不编辑程序 |
| 事件临时重写永久天赋连线 | 不纳入 | 事件借能力或覆盖规则，不改变账号图拓扑与分配合法性 |
| 天赋开放部分特殊遗物 | 纳入 | 许可与能力需求分开，事件借能力不越权永久开池 |
| 星空完整法书与专属节点 | 后续扩展 | 预留书位与材料注册契约；当前没有占位节点与虚假可选项 |

## 6. 内容职责的最终分配

天赋提供稳定可规划的能力入口、重要模式和特殊遗物许可。遗物提供本局变化、属性差异、专门工具和资产演化；基础入口可与天赋重叠，但不能重复领取同份收入。事件改变期限、规则覆盖、资产与遭遇机会，永远显式说明付出和失效后留下什么。

保留书籍终式的少量专用遗物：并非所有内容都必须完全通用。它们在图中靠近对应书籍，清楚标记主书需求；通用机制不得为了方便实现也全加书籍限制。

## 7. 逐项追踪的约定

[去向附录](appendix-content-disposition.md)覆盖全部 144 个旧天赋、140 件旧遗物、24 个旧事件。每项记录保留意图、改写、合并或替代去向；不以“其他全部保留”略过。

去向只记录设计意图，不承担旧浏览器档案转换；同 ID 不等于新旧效果兼容。Godot 按新游戏建立成长，本游戏后续更新的版本处理见[数据与算法](06-DATA-AND-ALGORITHMS.md)。任何候选调整须同步更新去向表，防止同时实现被合并的多个入口。
