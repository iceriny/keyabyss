# 战斗元素材质

2026-10-09。已将用户认可的俯视冰火小样接入根工程。正式战斗与小样共用模拟器、材质和微观纹理；主项目不引用 `development/`。当前特效已导出 Windows Debug 测试包 `builds/keyabyss-playtest-20261009-vfx/`，正式 Release 尚未重导。

## 战斗接线

- `SpellFieldVisual` 的寒墨冰域与 `UltimateField` 的寒墨终式创建 `IcePatch`。位置、半径、存续和退出读取实际付费对象，不改变伤害或冻结规则。命中是短暂冷闪与碎晶，冻结敌人保留本体轮廓并附着同源微晶，不为每次命中建立模拟器。
- `FrostGrowth` 在六邻域格点扩散水汽、附着并沉积增厚。半径220及以上的大冰域使用5～7个随机凝结点，较小冰域及独立小样保持2～4个；各点位置仍随种子变化，共同竞争原有水汽。冰膜从成熟枝网延迟铺展，六向包围度让外露晶尖领先；材质纹理决定膜层起伏、透光细节和破碎边缘。旧冰晶图集及到达图退出运行引用，移入 `.delete/element-integration/retired-ice/`。
- 普通冰域按新建时的低／中／高画质使用 128／160／224² 网格，大范围终式用 160／256／384²。迭代上限与网格成比例，成长时钟读取战斗时间，每帧补算有上限；高于320²的晶格同步调整膜层扩散、包围取样范围及噪声尺度，积分子步按扩散系数收短（最多25 ms），同帧复用枝网包围信息。主晶面使用平滑沉积高度的弧面表现，外围保留碎冰和星点。暂停不演化，到期停止模拟并淡出。减少动态关闭折射及粒子，保留结晶形态和区域辨识。
- `FluidAtmosphere` 将真实火场、焚世终式和火焰冲击写入一个 `Combustion` 燃料列表。燃料／热量／少量烟在现有流体速度中输运，热气自身发光并保留局部亮核；不为每个火场另建速度或压力求解器。场内火星读取同一气流，战场无屏幕向上浮力、无沉降。
- 燃烧网格跟随流体雾场分辨率，一帧一次 dispatch，输入限 64 个源。供火停止后继续冷却，尾段结束即停止绘制和调度。流体关闭／重建前先解除速度纹理依赖，重新连接后保持材质采样身份；减少动态不显示运动燃烧，已有安静的范围底色仍保留。
- 效果处于战场 HDR 视口，正文、词咒与危险预警保持原有独立层级。冰域使用局部原生灯光，火场共用有预算的流体灯光。冰火分别使用现有背景复制边界，不为每块冰新增全屏复制。
- 弹反、反制与爆墨由 `BattleVisuals._spawn_item_burst` 消费已提交事件。弹反为金白亮核与回弹碎晶，反制为青金晶屑与短促散光，爆墨为白热爆点与金橙火星。两层原生 GPU 粒子承担范围与速度，局部 shader 表现亮核、柔光、碎光和稀薄雾光；扩散亮部使用平面噪声打散，避免沿角度拉成长花瓣。雾是辅助层，不承担主体轮廓。
- 火书直接命中使用局部白热核心、带细节的橙色热光和 0.42 秒短寿命火星；普通命中材质半径 85，范围爆破仍按原有半径显示。命中照明快速衰减，减少动态保留柔和暖色光斑，持续燃烧伤害不重复触发爆闪。
- 三者节点寿命分别为 0.42／0.58／0.64 秒。反制道具尺度 367.5、爆墨 255，弹反起手 140、成功反击 320；粒子速度按尺度与寿命设置，径向发射后减速，无上下重力。大小、速度及发射时间分散，晶面亮暗与柔光共用金丝水晶配色。
- 这些事件不再向流场注入密度、推力或燃料，也不读取流体速度；关闭流体仍能显示。局部薄雾由二维噪声材质表现，高画质短时灯光照亮现有场景雾气。普通法术火场仍由 `Combustion` 模拟输运与冷却，引力与闪电的流体交互保持原接线。
- 高画质两层共 74 颗粒子，中画质 40 颗，弹反分别约 47／25 颗；低画质与减少动态保留安静光斑，不发射粒子。暂停由场景树统一停止，寿命结束释放整个节点及子粒子，切换低画质／减少动态立即退出粒子和灯光。无需深度步进、三维噪声、额外屏幕复制或 GPU 读回；性能尚未实测。
- 共享雾气照明保留沿灯光路径的密度遮光，去掉将屏幕密度导数转成凸起表面的法线照明，避免把气体边缘描成褶皱。
- 引力对敌我弹体的速度变化由固定战斗步提交；同一范围在雾场形成压力投影后的内流，持续场／光环随真实对象退出，瞬时吸引短暂衰减。无需从 GPU 读回流体来决定弹道。
- 闪电与雷鸣终式区域均使用金色，闪电保持 HDR 核心与柔光，分叉几何不变；沿途灯光与放电峰值同步，照亮已有雾气，并服从共享灯光预算和减少动态设置。

## 验证

10 月 9 日用户实拍否定了道具体积云团；该实现及专用三维噪声已移入 `.delete/particle-bursts-20261009/`。此前[概念分镜](BURST-STORYBOARD.png)仅保留作过程资料，不代表当前效果。粒子与 shader 经用户截图反馈收短光扫，并加强火书命中；资源导入、Debug 导出通过，独立 EXE 在 Forward+ 下启动 240 帧、退出 0，日志无错误。启动使用隔离 APPDATA，日志位于 `.temp/vfx-playtest-20261009/startup.log`。未运行玩法测试、战斗视觉复验或性能采样，引力与闪电的后续改动仍未单独验证。以下为此前冰火接入证据。

使用锁定 Godot 4.7.2、Forward+、RTX 4070 SUPER 与隔离用户目录。真实完词、道具完成与终式夹具在 `tests/godot/test_feedback_effects.gd`，可用 `--book=frost`、`--book=flame`、`--low`、`--reduce-motion`、`--measure` 选取范围。验证包含暂停、冰晶领先／膜层连接、局部热量、画质关闭再开启、减少动态和到期释放。

完整运行证据与成本结果见[阶段总结](../STAGE-SUMMARY.md)。本机短时采样不代替 P620 或完整遭遇下的长时体验；玩家存档未改，Git 未提交。
