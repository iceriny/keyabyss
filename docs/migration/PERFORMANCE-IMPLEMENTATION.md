## 2026-10-19 异步存档与线程边界

本批将首次档案读取、校验、JSON编码、临时文件回读及原子替换交给独立线程；God转移的读取与锁定备份保护也使用后台任务。主线程准备独立候选快照、继续绘制并等待回执，落盘成功后才提交奖励／路线／战斗状态。RunSession持有的私有候选交接给线程直到提交，公开异步保存仍深复制以隔离调用方后续修改；避免正式流程重复复制完整历史。

进行中的事务阻止重复操作，输入覆盖层每次移动到最后兄弟节点以正确拦截鼠标，键盘路由暂缓；画面、动画、FPS仍运行。关闭窗口等待事务完成再保存退出；失焦暂停延后到回执，跨档接管先停战斗。Bootstrap等待应用异步初始化完成再交接开场。同步事务夹具保留同步仓库路径，正式运行使用异步路径；后台耗时独立记录，不累加到接收结果帧的CPU scope。

并行职责：既有尾迹纯数值几何最多4路；词库准备和诊断写入已有后台线程；存档单写者顺序提交。固定步伤害、奖励事件、节点／材质上传保留主线程顺序。当前任务无需进程隔离，拆为多进程会额外复制快照、引入IPC和退出协调，因此本批采用线程。

验收使用空历史基线／53条真实历史副本极限两个负载（源档本轮游玩后已更新），同一1080p菜单背景分别运行同步／异步运输，覆盖首次读取、起局、书页、检查点和追加历史。6个真实词条形成合法进行中检查点；真实出征和关闭另走应用链路。测试窗口右上角启用现有FPS组件，保留产品60FPS上限。
