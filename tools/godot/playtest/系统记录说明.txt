周期卡顿的 Windows 系统记录

适用：游戏从首页到战场周期卡顿，而且“无诊断对照.cmd”仍然卡顿。
使用当前测试包，不需要重新下载游戏、安装 Godot 或改动画质。

1. 把“开始系统记录.cmd”和“保存系统记录.cmd”放到 keyabyss.exe 所在目录。
2. 先关闭游戏。右键“开始系统记录.cmd”，选择“以管理员身份运行”。看到 Recording started 后关闭这个命令窗口；记录会继续。
3. 正常双击包内原有“启动并记录.cmd”，回到游戏保持原有设置，在首页或战场复现数次卡顿，约30秒即可。游戏本身不用管理员身份运行。
4. 正常退出游戏。右键“保存系统记录.cmd”，选择“以管理员身份运行”，等待保存完成。
5. 同目录 logs 中会有 system-stall-*.etl，以及游戏的 engine-*.log 和 session-*.jsonl。把这次的文件一起带回开发机，放入项目 .temp/logs/。

这是 Windows 自带的 WPR，记录线程调度、调用栈和 GPU 活动，不更改游戏设置。开始脚本必须显示成功；若开始或保存报错，保留窗口中的原始错误，不要继续重试或自行取消其他正在进行的系统记录。采集结束要执行保存脚本，它同时停止本次记录。
