# 交互约定

启动先预热战场、图片与字体，完成后显示任意点击 / 任意键继续提示，配合呼吸光晕、漂浮光点和缓慢旋转的符印，点击屏幕任意位置或按任意键进入首页并解锁音频。首页是法书选择与出征入口。具体词库、难度、词长与种子在出征面板确认；教学仅首次出现，后续从玩法菜单查阅。

## 输入归属

1. 战斗：完整咒文、弹反、定向闪避、目标切换、终式与暂停。菜单词 `start` / `quit` 在战斗中仅是咒文。
2. 菜单：React 按钮声明 `word` / `shortcut`；`CommandBuffer` 拒绝重复或互为前缀的词令。错字保留前缀，Backspace 删一字，Esc 清空后再返回。
3. 字段：文本和范围输入独占字母与方向键；Enter 提交，Esc 回滚，Tab 离开。多行 Enter 保留换行。输入框是全局禁止文字选择规则的例外。
4. 自定义下拉：独立 listbox 焦点，上下方向键 / Home / End 浏览，Enter 或点击提交，Esc 取消并回到触发器；点击外部关闭。不使用隐藏的原生 select。

菜单 Tab / Shift+Tab 和方向键按控件顺序导航，Enter / Space 触发焦点。弹窗背景使用 `inert`，焦点循环限制在弹窗。嵌套面板通过页面栈返回；从设置返回暂停，不会意外恢复战斗。

Shift 终式在单键松开时触发；按住 Shift 输入大写、下划线或 Shift+Tab 会取消单键意图。窗口失焦 / 切换标签页清除按键意图并暂停。

## 复用组件

`Button`、`ChoiceCard`、`Modal`、`Select`、`Toggle`、`Field`、`Meter`、`Stat`、`Key` 和 `Command` 位于 `src/ui/components.tsx`。新增动作应通过这些组件声明，不再手工创建 DOM 或绑定重复监听器。

`KeyboardLayer` 只管理输入归属、导航和词令；`src/input.ts` 是纯解析器。React 负责 DOM，TypeScript 系统负责模拟，Three.js 原生渲染战场，不共享游戏随机流。

升级与路线不可 Esc 跳过。结束本局进入独立确认，取消后保持同一组选项。删除自定义词库也需要确认。导入解析和同步结果在页面卸载后不会再写入界面；下载与导出通过 Blob 完成。

施法时输入前缀同时显示在主角头顶。锁定反馈包含准星、连线与输入进度弧；词条及头顶文本位于独立画布，不参与局部空间扭曲或辉光；视口边缘渐变模糊统一覆盖世界与文字，HUD 不受影响。

菜单词令 `imsuperman` 激活会话内 God Mode，致死自动回满生命、无限终式与闪避；HUD 显示模式和 ∞。此命令不路由到战斗单词输入，刷新页面关闭。

战斗操作与防御参数以 [弹反与节奏设计](DEFENSE-AND-PACING.md) 为准：空格弹反，先按住 1左 / 2上 / 3下 / 4右 或方向键再按空格闪避。沙漏期间继续打字，不再劫持 WASD。数字作为当前咒文有效下一字符时可正常输入。
