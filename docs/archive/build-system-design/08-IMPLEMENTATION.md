## 玩家文案

新增通用术语先收敛为以下三项，已接入[现有术语解释](../../../legacy/web/src/content/glossary.ts)，由现有富文本识别与图鉴共用；“直接施法”保留为“主术”的别名，不再成为另一项需要记忆的概念：

| 术语 | 面向玩家的解释 |
| --- | --- |
| 主术 | 完成咒文后，由当前咒典施放的主要法术。需要亲手输入的额外奖励另行说明。 |
| 复写 | 亲手输入积攒进度，足够后保存一份较弱的主术，稍后自动施放；需要对应天赋或遗物。 |
| 储备 | 保存起来、可以用于后续施法的剩余力量。具体如何获得和使用，由当前天赋与遗物决定。 |

寒气、灼烧、纸灵、护盾等既有概念继续沿用。个别效果名在自身说明中直接解释，不继续扩成一长串通用术语。文案优先说明“什么时候发生、改变什么、付出什么”，只写玩家需要判断的内容。

工程词不进入玩家说明：例如 `owner`、`lot`、回执、能力许可、输入输出性质、编译、Q 单位。用“解锁该天赋后可能找到”解释特殊掉落，用“稍后施放／等待更久／传得更远／保存法术的纸页”说明实际效果。原生节点、遗物和事件的全文更新随全量内容接入进行。

事件摘要已改为“需要付出／选择后的变化”，正负参数统一列为实际变化，避免把缩短等待这样的负数误列成代价。时间明确写秒；房级范围写下一房。战斗记录用施法、抵挡、回收等实际行为替代载体、交付、回执和片段编号。

## 可执行资源流程的边界

- 一个人工回执可原子地给主术与共享制作账户入账。一个复写可以由多个词积攒的制作量支付，输出保留各份真实来源，不把它们改写成一次新的人工输入。
- 命中消耗已经提交的威力，即便目标生命更少，也不回收过量伤害。尚未命中的部分才可保存、抽取或转交。
- 纸页和冰晶共用防御—结束—释放流程；受热开启消耗真实热量并一次领取出口。破裂依据对象结构，不要求同时有冰、火材料。
- 转交同时检查距离、电荷与剩余加工次数。释放只能把待发对象发射一次，不重复使用结束出口；已保存对象的聚合不会刷新最早到期时间，也不会丢弃互不兼容的性质。
- 持续效果命中后只剩未来额度。抽取同步减少这些额度，回收只能由后续人工主术使用，不能等下一词后再把收入追加到旧主术。
- `nextRoom` 回收已接通跨房归档与接收；只转移允许跨房的实际余额，第一份新房人工主术可通过有明确限额的 Attach 规则取用。归档天赋、限额和各模式的完整内容定义仍须继续接通。
- 资源流程入口供权威执行器调用；内容本身不能直接调用这些入口。阶段执行器已检查规则拥有权、次数声明与继承；直接调用原语的测试仍不能替代完整规则收束证明。

## 正式主术入口与有限纸灵攻击

2026-09-24，主控继续实施正式战斗接入，没有新增子任务。本节对应 `native-*` 检查证据。

- `Targeting.input` 记录每个真实接受的位置；显示空格不记入输入，错误、取消和自动补全部分不产生额外制作量。被其他效果击杀的输入目标仍可按原词完成，再选择实际存活目标。
- 施法依次进入输入、组装与发射阶段。冰枪的物理穿透与雷术的即时近邻连锁逐次领取同一份有限威力，重复目标回调不二次扣款。即时连锁在事务结束后交付，避免重入命中结算。
- 火术先从本份威力分出未来灼烧与附近目标份额，再提交即时伤害。持续伤害按有限次数推进，到期不补发一份新资源；旧的独立灼烧伤害入口不同时处理这份命中。火焰绘制读取剩余状态的展示投影。
- 纸灵普通俯冲先从共享制作账户领取已付费的攻击，实际碰撞才结算；找不到目标或超时走统一损耗。输入停止后，纸灵不能重复产生新攻击。原有飞行曲线、轨迹与回旋继续使用。
- 原生法术引用包含房间与对象编号，房间切换后不能命中新对象。房间结束释放本房对象、事件去重记录与工作账户，只有允许跨房的储备通过独立交接传递。
- 普通主术的已付致死命中不会再旁路触发旧的固定伤害碎冰。碎冰视觉保留，完整的分裂伤害规则随全量内容迁移接入。
- 结算将两条迁移入口的真实输入数相加，保证途中获得遗物后，前面已赚的长期进度不会丢失。
- 法术位置仅复制 `x/y`，不会把玩家闪避、敌人字母标记或持续状态的可变数组冻结进快照。相同版本号但不同编译实例不能冒用同一个人工回执。

原生形状和份额参数是待统一校准的实现值。这里的机械检查不证明四书收益相等，也不证明后两档难度目标已达成。
