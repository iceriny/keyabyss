# 开放式 UI 约定

本约定适用于主菜单、战斗 HUD、遗物与路线选择、胜负结算、远征记录和游戏内按钮。默认桌面键鼠、1920×1080 视觉基准，与 [项目核心规则](../AGENT.md) 一起执行。

## 核心观感

界面是悬浮在书库与战场里的文字、刻线和法书。场景负责提供空间与氛围；内容容器只负责排版，不绘制可辨认的矩形底板、四边框、圆角卡片或整块投影。尤其不能为了突出失败、胜利或重要操作，重新套用实体对话框。

需要提高可读性时，对整个背景场景统一压暗、模糊或降低饱和度，不给每个内容分组加不透明底色。Tooltip 属于短暂阅读层，可以保留局部柔和底色，但仍以开放刻线和弱边界呈现。

## 信息层级与交互

- 使用留白、对齐、标题字号和局部细刻线分组；刻线不能连成外框。
- 全局默认「汇文明朝体」，小字、词令和辅助说明使用「京華老宋体v3.0」。主要统计数字必须继承其父级字号，不能被小字规则缩小。
- 按钮使用文字、词令和单侧细线表达点击区域。主操作用亮色文字和刻线区分，危险操作使用克制的红色，不填充整块亮色底板。
- 悬停与键盘焦点通过短暂微光、文字变亮或浅渐变反馈；键盘焦点必须可辨认，但不得用虚线框或环绕外框表示；使用文字微光、法书局部泛光与底部刻线。禁用状态降低亮度，仍能识别文字。
- 输入咒文悬浮展示，完成部分着法书色，施法进度沿底部刻线推进；不使用矩形输入框和整面填充进度。

## 战斗与遗物选择

生命与护盾均使用细进度条，颜色分别偏暖红与冷蓝，保留准确数值。护盾默认以 60 点作为稳定刻度，消耗时不改变分母；扩展内容超过该值时确保不溢出。进度条具有真实的无障碍数值，不为视觉表现修改玩法上限。

连笔采用无底板数字与节拍刻度。数字随连笔增长，在 100 连笔附近达到最大视觉尺寸；容器占位固定。增加时出现数字重影、局部光晕与扩散环，强度随次数提升；减少时轻淡回落。不得遮住目标词或引起 HUD 重排。

遗物选择的三个选项始终是视觉中心。底部以淡入的辅助区域展示当前法书、生命与护盾、构筑名；辅助文字的字号和亮度低于选项。构筑只列名称和叠层，通过已有 Tooltip 查看详情，长列表固定高度，保留局部滚轮滚动但隐藏滚动条；路线选择页复用同一摘要。

底部只有法书可使用持续漂浮、稀疏光点与低亮度法阵环绕，特效限制在法书附近，不在选项背后铺大面积光晕。

## 稳定布局

弹层外容器不滚动，标题、返回、分类导航及保存/确认等主要操作与内容滚动区互为兄弟节点。使用弹性布局与 `min-height: 0` 分配可用高度，滚动仅发生在正文、设置项或列表内部；不要用整窗滚动或仅依赖 sticky 代替明确的内外层职责。短页面保持自然高度，无需为了统一而强制出现滚动条。

首次调校的特效预览与底部继续按钮固定，仅右侧设置列表滚动；图鉴固定分类与查询栏，滚动条目；指南滚动正文；词库保留列表/详情分区和底部导入操作；结算固定标题与重试/返回等操作。

远征记录外层高度由桌面视口决定，不由当前记录内容决定。左侧记录和右侧详情分别滚动，隐藏滚动条但保留滚轮与键盘滚动；「此行构筑」和错词区域占位固定、内部滚动。切换空构筑、满构筑或长文本时，窗口、标题和导航位置不得跳动。

其他可切换内容也应先确定稳定占位，再允许长内容在自身区域滚动，避免整页跟随内容伸缩。

## 动效与验收

入场、胜负和关键操作可以有明显的仪式感；阅读态逐渐收敛。游戏与系统的减少动态设置均停用位移、脉冲、持续旋转及装饰粒子，保留内容、数值和状态颜色。

验收至少查看：战斗 HUD、施法中、低/高连笔、遗物三选一、失败、胜利、长短构筑记录切换。检查按钮键鼠可用、Tooltip 可达、辅助区不挤占选择区、窗口不跳动。无需移动端布局或测试。

实现入口：`src/ui/open-ui.css` 统一交互与战斗表达；`src/ui/results.css` 管理结算和历史布局；`src/ui/BattleReadouts.tsx` 共享血盾、连笔与法书摘要。后续样式调整优先在这些职责内修改，不在旧样式末尾反复添加互相覆盖的例外。

## 首次进入

字体准备页使用系统字体、悬浮文字和短刻线，不使用实体底板、圆角卡片或四边框；独立启动 JS/CSS 不依赖游戏主包。首次访问提供「全屏显示(推荐)」和「继续进入」：全屏不会推进页面，继续按钮仅在字体全部解码后启用，页面不会自动跳过。成功继续后才记录完成；后续访问字体就绪后自动进入。第一次进入主菜单显示调校页，以法阵、粒子和波纹预览展示实时帧率，调整沿用全局设置并立即保存。点击「保存并进入书库」后标记完成，后续访问不再自动打开。预览帧率不代表战斗帧率；隐藏页面停止统计，关闭页释放动画循环。


## 桌面全屏与窗口模式

按实际视口宽高分配空间，全屏和窗口模式不使用两套布局。法书大小同时受宽度和高度约束；书名、词令、介绍和主操作有明确的纵向间隔，禁止各自独立按百分比定位后互相覆盖。低高度时先收紧装饰、间距和辅助法书尺寸，保留主文字与操作；长内容继续在内部滚动。公共桌面适配入口为 `src/ui/desktop.css`，无需新增移动端触屏布局。


## 矢量图标

禁止使用 emoji。遗物由 `src/ui/relic-art.ts` 按 ID 保存各自的 SVG 路径，`RelicIcon.tsx` 统一渲染，沿用稀有度颜色与克制微光。新遗物需有独立物件轮廓；图鉴与选择页共享图案，构筑文字摘要继续只列名称和 Tooltip。路线、补给和图片失败占位也使用矢量图。

## 战场词条与入境

头顶咒文使用无边框的开放式刻线、柔和椭圆阴影与居中文字，禁止实体词框。可选中文释义使用小字号，限宽分为最多两行，超出省略；英文、前缀高亮和输入游标保持同一基线。

资源准备完成后，出征通过法书显现、法阵聚光与扩散环揭开战场；前半段不启动战斗，减少动态效果时使用短淡入淡出。过渡结束清理图层和定时器。

战斗即时提示（终式就绪、连笔提升、防御反馈等）统一使用悬浮文字、淡阴影与短刻线，锚定视口高度约 31% 的上方视线区，禁止实体底板或四边框。提示不拦截鼠标，不搬动常驻 HUD；长文本自然换行，减少动态效果时不使用位移动画。
