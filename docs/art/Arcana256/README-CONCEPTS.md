## 256 个抽象概念与输入映射

这套原创虚构文字包含 **256 个基础符文**，分为 16 个概念族，每族 16 个。原有 001–128 的编号、输入汉字、私用区码位与概念释义全部保留；新概念追加为 129–256。汉字既是输入键，也是查阅释义的标签。符文及其含义不声称来自真实历史文字、宗教或魔法传统。

每个汉字与同序私用区字符调用同一枚符文：`rune-001` 至 `rune-256` 对应 `U+E000` 至 `U+E0FF`。例如 `存` 与 `U+E000` 对应 001，`刚` 与 `U+E080` 对应 129，`道` 与 `U+E0FF` 对应 256。汉字改变显示字形，不会改变原始输入文本。

- `concepts.json`：机器可读的完整字典、32 组连字与书写示例
- `concepts.csv`：UTF-8 BOM 查阅表，可在支持 UTF-8 的表格软件中打开
- `concepts-design.json`：逐字设计依据，包括结构隐喻、轮廓族与近似概念的区别

开发目录中的版本化文件分别为 `concepts-256.json`、`concepts-256.csv` 与 `design-256.json`；交付包可使用上述通用文件名。

### 词义如何区分

新增概念采用限定义项。例如“柔”指适应变形而不断裂，“弱”指相同条件下影响较小；“记”是编码保存，“忆”是调取记忆；“净”是主动去除干扰，“清”是低干扰状态；“全”覆盖全部相关成员，“整”具备全部必要结构。具体含义以完整索引为准。

相关概念可以有亲缘手势，但需要不同轮廓或连接方式。轻重使用重心、宽窄与留白区分，强弱使用支撑与连续性区分，不通过改变字重承担词义。圆、折框、三角、分枝、嵌套、断裂、流动与成对关系共同组成统一的笔画语言。

### 最小书写约定

- 按从左到右的顺序阅读；每个符文首先保留本字典赋予的独立概念。
- 并置表示按书写次序建立关联；空格分隔概念组，标点分隔较完整的意群。
- 可用“主题 → 变化 → 目标”的顺序组织铭文；具体因果、否定、范围等关系需由创作者附上释义。
- 这是一套用于创作的概念书写系统，不具备自动翻译自然语言的完整语法。
- 32 组双字连字是可选书写合体；关闭连字仍保留相同汉字序列与含义。

示例（概念式铭文，需随创作目的附释义）：

- `生 变 成`：从生成，经由变化，走向达成。
- `意志 守 恒`：以持续意向守持恒定原则。
- `因果 循 复`：因果关系按次序循环，并使状态再次出现。
- `梦醒 光 显`：由梦而醒，使原先未知的状态逐渐可知。
- `命运 可 变`：既定条件之下，境况仍有改变的可能。
- `刚柔 合一`：使抵抗与顺应变化的两种方式成为统一原则。
- `记 传承 续`：把内容保存、传递并继续延续。
- `破立 净 化`：破除失效结构、确立新结构，并净化转变。
