# 问题

当前战斗培养系统过于单薄, 重复游玩的可玩性不高, 法书和遗物的联动, 遗物与遗物的联动不足, 玩家对战斗系统可深挖的内容不足, 战场缺少足够的变化用于支撑;

# 思考历程

当前的游戏是快节奏的, 玩家的注意点在打字, 在单词与单词之间快速的跳动, 视觉注意力一般也是在目标单词上的, 当前已经添加了闪避和弹反, 需要在打字的同时随时注意主角自身的位置以应对弹道或其他伤害; 如果玩家还要考虑各种转存, 先后, 连接 等概念, 免不了手忙脚乱; 且, 除了 Boss 之外, 其他的敌对单位血量并不多, 在大量敌对单位刷新的同时, 如果还要让敌对单位能够承受大量的伤害来承担各种状态的变化以及联动, 这太难了, 试想, 本游戏的目前的单次攻击是有 "成本" 的, 敲一个单词, 和传统游戏中的一次攻击相比, 成本是很高的, 这样需要多次攻击联动, 连组合效果的方式, 和当前的游戏模式具有矛盾性; 但是如果只是简单的去掉这些联动, 显然就又到了玩法深度不足的情况, 那么怎么解决矛盾, 怎么巧妙的挖掘玩法, 怎么构建合适的涌现式设计, 怎么构建契合玩法的BD, 你需要深刻思考这些内容;

在当前的基础上, 应该让玩家在构筑时决定“法术怎样联动”，而不是在战斗时逐个操作联动。
让一个词驱动一段完整的法术过程，而不是用多个词拼出一次有效攻击。
这不是简单增加自动施法。真正要改变的，是联动的发生位置、状态的承载对象，以及构筑深度的来源。

更适合的分工是：
升级、事件与主页面中，思考构筑。
战斗中，选择眼前值得攻击的目标，继续打字，处理危险。
已经构筑好的法术体系，负责执行连锁、转化与回收。

类似的分层有可借鉴之处：Brotato 将默认自动开火与波间购买、构筑并置；Magicraft 强调法术之间的组合；Nova Drift 则展示了碎片与追踪等模块组合后，如何形成不同的攻击方式。它们值得借鉴的是“组合规则改变战斗结果”，而不是要求玩家手动操作每一段效果。

但键渊不能连输入也自动化掉。打字仍然是发动法术、指定主要目标和持续维持战斗的核心行为。

此外, 当前的核心法书单元在于每敲出一个单词, 这并没有错, 因为游戏的目的就是能够快速的打出想要的单词, 兼顾英语学习的小作用, 但是, 可以思考在字符层面丰富构筑层次的可能性;

### 第一类联动:

完成一个词 → 这一发复合法术携带冰性结构与火性副术 → 命中时按构筑规则发生反应。

例如，玩家构筑出了“霜焰裂书”：

这一发冰矛带有可碎裂的冰晶结构；附着的火性副术消耗冰晶，产生自动寻敌的灼热碎片。

玩家只打了一个词。主要目标可以当场死亡，碎片仍然正常产生。

这里的冰晶首先是法术自身的结构，不必要求怪物先被冻结、活过一轮，再等待下一次攻击。

这一方向与现有系统也并不割裂：当前冷爆炸已经会先执行 applyCold，再结算伤害；死亡处理随后可以触发碎裂。因此，“一次命中同时建立条件、造成伤害、引出后效”已有实现基础。

需要补充的规则是：一次命中已经获得资格的后续效果，不能因为主要目标先死亡就被吞掉。

这不意味着让尸体继续承受伤害，也不意味着故意延迟死亡。应当记录本次命中真正生效的属性和载荷，死亡后的碎裂、释放等效果从这份记录继续结算。

这类设计的价值

敌人血量低，不再是联动的障碍。

相反，“一词击破，然后法术继续展开”可以成为爽感的重要来源。

不过，一词展开不代表每词免费触发所有效果。副术、碎片和复制仍然需要构筑投资与有限供给，只是不再额外收取一次完整单词的操作成本。

### 第二类联动 状态由法书保存，自动跨目标延续

有些机制确实需要积累，但积累对象不应该是一只随时会死的小怪。

例如灼烧：

原来的问题是：

我给敌人挂了持续伤害，但它很快死了，剩下的效果全部浪费。

合适的改造不是提高敌人血量，而是让某些遗物提供：

敌人死亡时，回收一部分尚未结算的余热；下一次正常施法自动携带这份余热。

玩家不需要选择“存在哪里”，也不需要指定继承者。

他继续打下一个正常目标，法书自动处理。

同样可以扩展到：

多余电荷，存回法书。
没有合法接收目标的回响，保留一次待用。
超出击杀所需的部分威力，通过特定遗物转为下一次施法的附加效果。

这提供了一种很适合键渊的成长方向：

不是让我为了触发效果多打几个词，而是让已经付出的输入更少浪费。

这里的储备应该自动使用、有容量限制，也不要求玩家盯着一个新资源条。没有主动优化它，构筑仍然照常工作。

尤其要避免把“下一次有效”设计成“必须三秒内打完下一词，否则全部消失”。那会把后台回收重新变成前台负担。

当然, 这不意味着取消当前现有战斗机制的灼烧/感电/冰冻等机制, 只不过重心不应该继续放在这上边

### 第三类联动：让自动造物承担复杂生命周期

纸页、回响、冰晶弹壳、护印，都可以比普通敌人活得更久。

但它们不是让玩家摆放和管理的新单位，而是法术内部自动运转的部件。

例如，一张纸页可以经历：

被人工施法生成 → 保存一份法术载荷 → 自动发射，或被防御行为消耗 → 释放剩余载荷。

玩家无需知道“第三张纸页还有多少寿命”。

他只需要理解这套构筑的大致特点：

纸页多时更安全；纸页破裂时会反击；继续打字就能补充纸页。

这就把需要时间才能展开的机制，放到了可靠存在、自动管理的承载对象上，而不是要求每只小怪配合完成一场仪式。

### 元素系统的深化

当前的元素系统还主要是 **研究“怪物身上的状态”**, 仍然过于接近传统的挂状态战斗。

更适合键渊的元素体系，应同时作用于：

**命中的敌人、正在运行的法术，以及法书拥有的有限造物。**

可以先采用这样的分工：

| 元素   | 对敌人的直接价值         | 对法术体系的价值                     |
| ------ | ------------------------ | ------------------------------------ |
| **冰** | 减缓、控制、脆裂         | 形成可碎裂结构，保存或集中载荷       |
| **火** | 即时伤害、灼烧           | 消耗载体、提前释放储量、回收余热     |
| **雷** | 迅速命中、自动传导       | 分配有限载荷，在多个作用对象之间传递 |
| **纸** | 召唤攻击、标记等既有能力 | 承载、复写、护持、交出载荷           |

这样，“火与纸”的组合不必等于：

> 给怪物挂纸标记，再施火，触发纸火爆炸。

它可以是：

> **火性载荷被印入纸页；纸页正常发射时攻击，被消耗时也能通过遗物释放。**

“冰与火”也不必总要求先冻住怪物：

> **火改变冰性法术的碎裂方式，把原本集中命中的冰矛变成较分散的灼热碎片。**

“雷与纸”则可以是：

> **纸页复写一次弱化雷击，或在护页破裂时交出储存的电荷。**

这些机制对低血量敌人一样有效，因为它们首先是在**改造攻击和造物**。

同时，保留“活着有用，死了也不白给”

对于仍然施加在敌人身上的效果，可以采用双出口：

**敌人活着，状态发挥持续价值。**
**敌人死亡，部分投入通过已获得的能力转成后效。**

例如，火对 Boss 可以持续燃烧；对小怪则通过余热回收形成后续收益。冰对耐久目标提供控制；对脆弱目标则可以通过碎裂节点产生清场效果。

但不能反过来，所有能力都围绕击杀设计。否则普通战很热闹，Boss 战又全部停机。

**核心驱动应当来自人工施法、命中和载体消耗；击杀是重要的放大条件，而不是唯一电源。**

### 什么才算真正的涌现，而不是预制好的自动连招？

这是必须回答的一点。否则，把连招自动执行，仍然可能只是换一种方式播放固定配方。

我建议以**能独立成立、能跨场景组合的规则零件**为主体。

看一个具体例子。

#### 三件普通零件
他们可以是遗物, 可以是场外天赋, 只要符合它的身份, 例如 `遗响` 就不适合做遗物, 因为只拿它没有什么效果, 可以是 "解锁某条规则的天赋"

**《复写页》**
人工**直接施法** (或输入多少个字符后) 支付一定墨量，生成一张纸页，保存一份弱化的主法术，随后自动释放一次。

**《护封》**
尚未释放的纸页，可以被消耗，用来拦截一次符合条件的敌方攻击。代价是失去这张纸页原本的攻击机会。

**《遗响》**
承载物因破坏或防御而被消耗时，释放其中尚未释放的合法载荷。

这三条规则组合之后：

> **雷法生成纸页 → 纸页拦截敌弹 → 纸页被消耗 → 储存的雷击释放。**

于是，一部分输出资源变成了防御资源，而防御又成为一次攻击的释放时机。

玩家没有新增任何按键，也没有追踪任何怪物状态。

换成火书，纸页交出的是火性载荷；换成冰书，交出的是冰性载荷。

拿掉《遗响》，护页依然有防御价值，只是牺牲了攻击机会。拿掉《护封》，复写页依然会正常攻击。

**不是三个零件凑齐前都没用，而是每拿到一个零件，已有能力的用途发生变化。**

再加入一件：

**《速朽装订》**
纸页制造成本(输入的字符量?)降低，但寿命缩短。

这时会出现真正值得研究的构筑问题：

在单纯的护页流中，寿命缩短可能让防御不稳定；在能够利用载体消耗释放法术的流派里，它却可能意味着更快兑现载荷。

**同一个属性变化，在不同构筑里，价值甚至可以反转。**

这才是玩法深度的重要来源：不是战斗时记更多东西，而是升级时开始发现——

> “这件遗物在上一局没什么用，放进我现在这套体系却很合适。”

当然，反击用的是纸页原先支付过的有限载荷。它不能因为反击命中，又被算作一次新的人工施法，无限生成纸页。

### 副法书：提供稳定材料，不再提供第二套战斗任务

副法书可以在场外的天赋系统中点出

副法书仍然值得保留，但职责需要收紧。

> **主书决定主要攻击方式；副书提供稳定的材料、载体或加工方式。**

副书不应该再要求玩家：

“等它充好，再找特定目标。”
“先打另一个怪，才能触发转注。”
“这次要留着，等成功弹反后再使用。”

这些都把复杂度放回了玩家眼前。

更合适的副书形态是：

**副冰：让部分主术获得冰性结构或控制属性。**
**副火：为法术或造物提供有限的热性载荷。**
**副雷：为合法攻击提供受限的传导能力。**
**副纸：让部分主术可以被承载、复写或用于护持。**

它们如何发挥作用，再由局内遗物改变。

因此，同样是“主雷＋副纸”，可以发展为快速复写的输出流，也可以发展为护页反击流。**流派不能在选完两本书时就被完全确定。**

主要依据**人工有效输入量**供给，而不是依据派生攻击次数。

当前代码已有人工施法计数、辅助补全，以及按词长产生的部分收益，可以沿这条边界继续拆分。

例如，十二个有效字符，无论来自几个词，都可以贡献相应的副术材料；短词保留出手频率优势，长词则拥有更大的单次承载空间。

不要再用“连续几秒内完成很多词”作为常见核心触发条件。输入速度本来就影响输出，没必要让慢一些的玩家连构筑的基本功能都看不到。

副书槽可以通过较早的合订天赋开放，但应占用明确的培养容量，与单书专精竞争。**不能让副书变成所有构筑无代价多拿的一整套输出。**


# 关于技术问题

## 基础
灵活, 易扩展, 数据逻辑分离, 涌现式设计; 这是整个战斗系统的基石;
所以你可以考虑各种适合 **涌现** 的技术路线, 例如, 通过标签而非通过类型判断, 某个实体存在某个标签它就有对应的效果或作用;

## 遗物
可以使用图模型, 但重点应该从“记忆组合配方”，转向“理解能力怎样供给、转化和消耗”。

节点可以标记：

**产生什么：** 纸页、余热、碎片、电荷。
**需要什么：** 可承载对象、未释放载荷、合法攻击来源。
**改变什么：** 分配方式、消耗方式、保存方式、输出形态。

例如，《遗响》的前置应该是拥有某种稳定的承载能力，而不一定是指定的纸灵法书。

这会让不同来源的同类能力共享一批连接节点，而不是每一对法书都单独制作一整套专属配方。

### 重复选择同一节点，也应沿这个方向质变

以复写页为例：

**Ⅰ阶：** 得到一份简单、可用的自动复写。
**Ⅱ阶：** 获得有限缓存或更灵活的载荷处理。
**Ⅲ阶：** 选择“多页分发”或“少页重印”。

第三阶改变结构，而不是只增加一个百分比。

并且，分支应当有真实的相互排斥或机会成本。否则玩到后面所有节点都拿到，最终仍然会变成一套“什么都会”的通用法术。

保留深化、连接、探索三种候选职能，但连接不应等于系统自动补齐毕业套装。
你不应该标记什么是好的, 应该只是告诉玩家你有什么能当前可选的三个遗物有联动, 比如你已经具有了有 "承载" 功能的遗物或其他的基础, 那么能够依靠 "承载" 的遗物下应该极简的展示;
是的, 展示, 而不是替玩家做选择;
但遗物刷新应该有一定倾向, 有高于普通随机方式的概率选择有联动词条的遗物, 但保留较大空间让玩家探索其他选择;

# 天赋
天赋也可以做成树模型, 以一个整体的天赋图展示, 四本(保留将来可拓展数量的可能)法书作为这个统一天赋图的起点, 也就是法书决定起点, 而非不同的天赋图, 你可以从冰出发, 却往火发展等等;

# 敌人

当前的战斗机制下, 小怪boss的攻击方式都比较单一;
首先是血量, 当前敌人的血量的设计倾向于: 小怪皮薄, 一般构筑合适, 一到两次直接施法就能击杀
这是对的,高级联动要能在主要目标当场死亡时成立。
耐久敌人与 Boss 可以展示持续状态的另一面，但不能成为大多数构筑唯一能运作的场所。

对于敌人的形式, 不能只考虑敌人形态和表现上的区别, 也应该对于玩家所输入单词有所特殊;
例如精英怪可能是一些带符号的特殊单词, 或者是一些短语, 比如 `x-ray` 'let\'s go`这样的;

不让强联动吞掉玩家正在输入的词
当前源码中，锁定目标死亡时会取消输入。这不止会打断输入节奏, 而且因为玩家可能注意不到当前输入部分字符即可, 一次短促连续输入, 反而得不到加强, 反而会因为输入的单词被消除, 而打断"连写(连击)"数量. 随着自动复写、持续伤害和连锁增强，这个问题会更突出。
因此，残响续写依然是前置工作：原目标被友方效果提前击杀时，保留原词和已有进度；完成后按明确规则兑现一次施法。
不能悄悄换词，也不能因为构筑变强，反而让玩家频繁白打半个单词。

不用更多仪表补救复杂机制
副书储备、余热、纸页状态可以在后台精确计算，但不代表都要变成必须盯着的 HUD。
战斗中主要展示：
**当前词与输入进度、必要危险提示、少量能感知构筑身份的反馈。**
复杂因果可以在升级说明和战后记录中呈现。玩家不需要看清每一道电弧来自哪里，才能享受自己构筑成功的结果。

允许长连锁，但不允许无成本自复制
不是要求所有伤害严格守恒。遗物当然可以提供放大，后期也应该允许精彩的爆发。
但每次放大要有明确来源：
人工输入提供新的驱动；材料被实际消耗；复制有有限额度；回收有容量或折损。
**一段法术可以很长，但不能在玩家停笔后，自己生产全部所需资源，永久维持整个战场。**

同样完成一个词，有的构筑把威力集中成一击，有的让法术接续工作，有的把浪费的余量带到下一次攻击，有的把有限火力转换为保护，再利用保护后的残余反击。

**玩家仍然在专心打字，但他亲手构筑的那套规则，正在以不同的方式回应每一个词。**

这比让玩家边打字边记忆一张战术状态表，更适合键渊，也更有机会同时保住快节奏、爽感与构筑深度。
