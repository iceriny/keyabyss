# 原生战场视觉与渲染（2026-09-20）

菜单、战斗 HUD、按钮和结算页统一遵循 [开放式 UI 约定](OPEN-UI.md)。该约定定义面板边界、字体层级、动效强度、遗物选择辅助区和历史记录的稳定布局；历史截图中的实体面板不构成后续设计依据。

造型抽象、材质克制，空间有层次，施法有光，扭曲真实改变环境。以 1920×1080 为画面与像素预算基准，保留 1280×800 设计坐标、1140×510 活动区与 66% 实体比例。16:9 窗口采用等比映射；环境覆盖整个窗口，玩法边界和文字坐标保持一致。

## 场景与管线

平台范围遵循 [项目核心规则](../AGENT.md)：**不需要兼容小屏（移动端）布局。** 优先保证桌面的画面层次、字号、空间关系与特效，不为手机或平板竖屏新增布局断点或削弱桌面表现。

`src/rendering/NativeBattleRenderer.ts` 使用 Three.js 原生场景与实例化几何。远层是程序墨雾与微光，中层是断裂环形刻线，近层是悬浮纸片、符文和边界；视差跟随玩家位置，缓慢运动独立于玩法随机数。

```text
战斗模拟 / 施法事件
  → GPU 环境场景 → 环境纹理
  → 角色图集 / 弹幕 / 粒子实例 → 实体纹理
  → 局部引力与冲击波网格 → 位移纹理
  → 同一批实例的发光部分 → postprocessing 多级辉光金字塔
  → 一次合成：环境偏移采样 + 稳定实体 + 辉光
  → 独立 Canvas 文字、状态和危险预警 / React HUD
```

Canvas 只在初始化时生成 2048×1024 角色图集，保留四本法书、17 种敌人、三个 Boss、节点和折纸精灵的现有剪影；图集上传一次。每帧只有实例位置、旋转、透明度、颜色等属性更新。角色与完整战场不会先绘制到 Canvas，更没有整帧纹理上传。原有模拟碎片使用固定容量实例缓冲；新增爆发粒子交给 `three.quarks` 管理发射、寿命曲线、对象回收与 GPU 批次。16 个发射器复用同一张 512×512 程序光斑纹理。视觉提示通过会话 / 序号游标去重，不改动玩法随机数。零时间差不调用粒子模拟，避免寿命曲线在暂停重绘时前进。

## 光与扭曲

待机保持微光；打字进度驱动手部、法杖与脚下聚光；命中使用短亮核和有方向的碎片；终式扩大照明、冲击与位移后迅速回落。冰霜使用棱形结晶与冻结簇，闪电保留细亮核和侧向分叉，折纸轨迹增加纸屑尾迹与交错轨道；终式使用不同射线数和形态的流派法阵。发光对象统一抽取辉光，无需为每颗粒子创建光源。

引力与冲击波仅在各自覆盖的四边形写入位移，最多 32 个实例；多个场叠加后统一合成。RGBA 分别存储正、负位移，输出限制最大偏移，边缘衰减防止硬接缝。环境刻线、雾与纸片被实际偏移采样；实体、文字和判定预警保持稳定。

默认主场景上限 1920×1080，不随高 DPR 成倍放大。位移和辉光输入在该基准为 960×540，`postprocessing` 在此基础上构建 5 级模糊金字塔，图集固定 2048×1024。支持浮点颜色缓冲时使用半精度浮点以避免暗部色带，其他 WebGL 2 设备使用无符号字节。低特效把辅助纹理降至主场景的 37.5%，减少远景细节和粒子，保留主要施法反馈；减少动态时停用环境运动、视差、震动与空间位移。

## 加载与生命周期

首页不请求 Three.js 战场模块，也不创建 WebGL 上下文。出征依次读取所选词库、加载带内容哈希的经典脚本、初始化图集和目标纹理、编译并实际预热各材质，再开始模拟。进度来自真实阶段；保留取消、失败重试和资源缓存。导出词库不启动战场资源。

`file://` 发行包采用经典脚本延迟加载，不依赖 CDN、HTTP 或本地 ES Module 跨域例外。开发模式由 Vite 延迟导入同一入口。

暂停和首页不持续渲染。窗口变化仅调整渲染目标与相机，不重新上传角色图集。WebGL 上下文丢失时暂停战斗，恢复后重新预热，可手动继续；无 WebGL 2 时出征显示可返回 / 重试的错误，不运行无画面的战斗。销毁时释放纹理、缓冲、材质和监听器。

`art/` 中四张透明法书图用于首页主视觉、选择卡、图鉴与 HUD；通过 AssetManager 共享加载，不逐帧上传 GPU。火焰使用原生实例火舌、暖色亮核、火场裂纹、热扭曲和陨火轨迹。旧 Canvas 战场后处理链路已移除。

## TypeScript 与组件边界

`core.ts`、`game.ts`、Web Audio、渲染入口和着色器模块均迁为 TypeScript；使用明确的实体与特效联合类型，不通过 `any` 或关闭检查迁移。原有模拟对象及绘制状态分别由 `combat/model.ts` 和 `types.ts` 约束。

- `ActorPainter` / `ActorAtlas`：静态剪影生成与一次上传。
- `InstancedBatch`：通用实例图元、缓冲更新及资源释放。
- `EnvironmentLayer` / `SpellBrush`：环境装饰、弧线、晶体、流派法阵与法术表现。
- `BloomLayer` / `ParticleLayer`：成熟库的生命周期、尺寸和游戏事件适配。
- `ScreenPass`：屏幕着色器与渲染目标创建。
- `ui/Sigil`：首页、资源加载与终式能量共用的矢量符印；`useGamePulse` 统一 HUD 采样频率。

卡片、按钮、进度条和施法面板采用 CSS 反馈；符印不截获输入。系统和游戏中的减少动态选项均停用新 UI 动画。


## 全屏与分级视觉（2026-09-20）

撤去内缩场地矩形，环境铺满视口。边缘按短边 10% 的范围逐渐模糊、变暗，覆盖单位和单词；HUD 位于遮盖上方。道具采用小型六边形或菱形封闭轮廓，与敌人剪影区分。

背景刻纹、几何轨道和浮动纸片使用不同相位与速率。低 / 中 / 高统一控制装饰层、粒子及位移 / 辉光分辨率；复用 Quarks、postprocessing 和原生实例图元增强元素爆发与冲击波。前景特效在实体后绘制、关闭深度测试；地面法阵仍位于实体下方。暂停菜单采用开放刻线与无外框统计，减少窗口感。

效果分级与截图见 [全屏与词库实现](FULLSCREEN-AND-VOCABULARY.md) 和 `test-output-fullscreen/`。
