4 个法书起点见总览；本文列 60 个机制、20 个关键改写、122 个数值节点。稳定 ID 已映射为 Godot Resource，通过正式编译器进入战斗与开发试验场；逐项入口与验证族见 [M3 内容映射](../../../migration/M3-CONTENT-MAP.json)。正式成长图购买、配置持久化及统一数值校准仍在后续阶段，实际证据见[阶段总结](../STAGE-SUMMARY.md)。

T 的“使用条件”是运行条件，不自动成为指定节点的购买前置。K 的“购买前置”则引用实际分配的 T 节点。所有节点仍必须沿成长边接入；任何跨区关系都不自动获得一条远程直连。

T23 与 T24 争用同一防御顺序槽；T57 与 T58 争用副书职责，互斥。其他 T 不因同属一个概念就互斥。许可仅用于目录中要求该节点的特殊工具，不能据此推断所有同概念遗物都有硬门槛。

“许可用途别名”便于阅读和检索；实际许可统一为 `permit:talent:<ID>`，例如遗响为 `permit:talent:T22`，不是单独的 `echo` 字符串。T57 的材料加工保留起值为同池 +10%，材料入口已存在时仍只计算一次入口。

T01、T13、T19、T49、T50、T52 同时提供对应入口的一项效率改善，初始幅度 10%：分别为保存加工保留、电荷投入保留、复制折算、持续伤害折算、寒气积累效率、纸灵维持效率。它们进入各自已有数值池，不是独立全伤乘区；已有原生入口也能受益。这样纸主书取得 T19、雷主书取得 T13 等不会花点只重复一项许可，也不会运行两个完整供给入口。最终幅度按路径与实际份额统一校准。
