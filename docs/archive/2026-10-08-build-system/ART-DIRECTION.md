# 金丝水晶 · 视觉规范

> 历史归档：2026-10-08 调整范围前的设计、计划或证据。正文中的要求与“下一步”不构成当前任务；当前实施见[交接文档](../../migration/AGENT-HANDOFF.md).

「金丝水晶」是键渊统一的 UI 视觉风格：以大量半透明、模糊、弱边界和开放的材质形成空间，材质中的纤细金丝呈现自然弧线、藤蔓、枝叶与叶脉般的优雅纹样，辅以局部镶边，再用具有魔法气息的辉光和流转光晕润色。

这是在既有开放式界面上的小幅升级。书、卷、页、墨、法阵与四书元素身份继续成立。本文规定目标外观；实际完成程度见[阶段总结](STAGE-SUMMARY.md)，排版与交互见[开放式 UI](OPEN-UI.md)。

## 材质与空间

| 层次 | 视觉作用 | 表达方式 |
| --- | --- | --- |
| 远处场景 | 提供书库与战场氛围 | 墨青暗部、低频纹理、稀疏冷暖光；中央阅读区对比收敛 |
| 水晶阅读层 | 使悬浮文字和内容有空间归属 | 通透的冷灰染色、柔焦、渐隐明暗；边缘融入场景 |
| 金丝纹样层 | 形成自然、舒展的材质气质 | 柔和弧线、藤蔓般的延展与叶脉般的分生；粗细、曲率和疏密有变化 |
| 内容与符号 | 承担阅读和操作 | 清楚的文字、可辨轮廓和稳定位置，背景透过但不干扰阅读 |
| 魔法光效 | 表达响应、能量与仪式 | 小亮核、柔和外晕、局部流光；高亮后回落 |

“水晶”主要体现透光、轻微色偏、柔和折面和层次，不要求每个容器都画成实体晶块。大区域可有淡薄渐变和模糊，轮廓自然消隐；内容分组仍靠留白、对齐、字号和局部纹路形成。

材质中的金丝以自然生长的观感为主。弧线舒展，分枝有轻重，局部聚合后留出呼吸空间；植物意象可以抽象，不要求处处出现完整花叶。纹样顺应材质与物件的形态，避免密集、等距、硬折线组成的布线感，也不靠随机噪声表现“自然”。

镶边承担局部轮廓，可沿材质切面、法书装订线或节点外形保留较清楚的金属边缘。规整线条集中在有明确结构作用的位置，整体气质由柔美的内部金丝决定。页面容器保持开放，不围成矩形四边框或金色卡片；实体物件与节点可有完整且有意义的外形。

背景纹路和光效不承担文字排版。阅读层需要更清楚时，优先减弱其后的细节和亮度，再调整通透程度；不能只给文字不断叠加描边和辉光。

## 嵌入感与表现成本

金丝可以通过部分清晰、部分隐现的虚实关系，呈现嵌入水晶内部的观感。嵌入深度属于可选的材质强化，不是每个 UI 元素必须具备的效果；自然纹样、通透感与优雅气质本身就应成立。

实现时必须权衡可见提升与运行代价，包括覆盖面积、同时显示的数量、更新频率，以及额外绘制、模糊或采样的成本。可以先用静态纹样、明暗、透明度和局部遮掩暗示深度；更复杂的动态层次、视差或折射，在收益足够明确、成本合适时采用，不预先禁止，也不因使用某种引擎就假定代价可以忽略。

小节点与大面积阅读层可采用不同精细程度，画质分级可调整深度表现，仍保留自然金丝与水晶的共同识别。方案首先依据表现需要和工程判断选择；只有存在影响取舍的具体不确定性时再做相称验证，不为确立风格先开展大量性能试验。

## 色系与职责

颜色先承担语义，再参与装饰。以下是设计参考色；透明叠加后的可读性以实际背景为准，同一角色的色相保持一致。

| 角色 | 参考色 | 使用 |
| --- | --- | --- |
| 墨青深景 | `#101C24` | 远景、静态暗部和通透材质后的空间 |
| 水晶灰青 | `#9CB8C6` | 低强度透光与折面，不作为大面积实色底板 |
| 主文字暖白 | `#E8E4D8` | 正文和关键数值，保持清晰实心字形 |
| 次文字灰青 | `#AAB9C2` | 辅助解释；禁用状态仍可阅读 |
| 金丝基色 | `#C9AE72` | 自然纹样、局部镶边和普通强调 |
| 金丝亮点 | `#F0DDAE` | 焦点、选中、主操作与短时响应 |
| 寒墨冰蓝 | `#8BDEFF` | 冰与寒气身份 |
| 灰烬暖橙 | `#FF994E` | 火与热量身份 |
| 雷鸣浅金 | `#FFD17C` | 雷电身份；结合闪电轮廓区分装饰金丝 |
| 纸灵淡紫 | `#C2A0FF` | 纸灵、复写与相关法术身份 |

四书颜色沿用现有识别基础。金丝是共同材质与装饰语言，不替代元素色；通用区域使用中性色，融合节点通过符号与局部双色说明关联，不铺满高饱和彩虹渐变。

生命与伤害风险使用暖红，护盾使用冷蓝；成功、警告、禁用和错误还须有文字、符号或形状区别。稀有度采用稳定文字与小范围色彩标识，不使所有稀有物都比当前选择更亮。大面积金色保留给短暂关键时刻，普通阅读以中性文字为主。

## 光效与动态

常态只保留微光与低频变化；金丝局部隐约透出或被照亮，不要求整片纹样持续发光。悬停是局部响应，选中是稳定而明确的重点；提交或解锁可以让光沿舒展的弧线与分枝缓缓显现、消退。光效有清楚的结束，不同时让所有纹样和节点循环闪烁。

金丝主脉、金丝分叉和水晶光晕分别控制。交互控件的分叉短而非常淡，退居主脉之后；金丝流光是一段缓慢移动、平滑衰减的柔和受光，各控件错开节奏，避免集中的白亮点与同步扫光。主脉可以延长，但不额外叠一条生硬或锯齿状的横线。

水晶光晕应有可感知的透光和流转，不因追求克制而压成几乎看不见的静态轮廓。两侧受光有曲率、强弱和错位，局部折射与透射共同表达厚度，不做两道均匀的粗亮柱。增加光晕亮度或流动感，不意味着增加金丝长度、分叉密度或整页植物装饰。

悬停文字背光渐入，中部较亮、两侧较快衰减；正文保持清楚。用户提供的 SVG 是纹样素材，应随版面、材质坡度、虚实和局部受光融入界面，不能生硬贴在上方，也不能让每个按钮铺同一幅底纹。通用金丝保持中性金属色，法书主题色只影响有元素语义的部分。

流转光晕顺应自然纹样与材质轮廓，功能路径上的高亮另按交互状态表达，不能随机游走到文字背后抢占注意。辉光外层柔和，亮核小而清晰，保留字形和节点轮廓；模糊只作用于合适的背景与材质，文字和危险预警保持锐利。

入境、终式与结算可有较强仪式感，长时间阅读逐步安静。减少动态设置停用装饰漂移、旋转、脉冲、流光和震动，保留静态材质、颜色、轮廓与交互反馈。

## 节点与连线

- 普通数值节点是小而朴素的水晶刻点，具有克制的单层高光。
- 机制节点有可辨的图形、局部金丝镶嵌和折面；能力差异通过轮廓与符号表达。
- 关键改写拥有更明显的外形、留白和内部结构，不能仅放大光晕。
- 法书起点是宏观地标，使用法书自身形象与元素光，不把整个邻域染成不透明色块。
- 成长线有低亮底脉和清楚的细芯，可采用舒缓曲线；准确可追踪的连接关系优先，已选路径、可购买邻接、未选路径形成层级。曲率与高亮宽度仍须满足几何间距。
- 植物金丝属于材质装饰，不能伪装成额外成长路径；分枝与叶脉不连接本来无成长关系的节点，不给可走路线增加虚假岔口。
- 边界处的颜色过渡说明相邻概念，不掩盖交叉、穿字或不可走的连接。零交叉与近邻要求先于材质润色。

图谱的宏伟感来自整体关系、局部细节和缩放层级。远看保留书位、关键轮廓和路径节奏，近看才展开细节与文字；页面打开时布局稳定。

## 页面应用

| 页面 | 视觉中心 | 金丝水晶的应用 |
| --- | --- | --- |
| 书库与出征 | 法书和当前主操作 | 悬浮排版、两翼展开、薄晶光层与法书局部镶线 |
| 图谱 | 整体网络及当前选择 | 全屏空间、近邻细脉、固定开放详情，不挤成双栏面板 |
| 奖励与事件 | 可比较的效果和代价 | 图形、文字与短刻线组织选项，辅助构筑摘要退居次要 |
| 战斗 HUD | 咒文、生命护盾、防御状态 | 锐利文字与细条、稳定占位，装饰远离威胁信息 |
| 图鉴、设置与记录 | 阅读内容与稳定操作 | 柔焦阅读层、固定标题、正文内部滚动 |
| 胜负与归档 | 结果和主要操作 | 短时仪式光效后收敛，内容保持开放，无实体对话框 |

## 与战斗画面的联系

四书继续保留不同形态：冰有晶棱与碎屑，火有暖核、焰舌与热扰动，雷有细亮主干和分叉，纸灵有连贯曲线与纸屑。装饰分支不产生额外判定，画面随机不影响玩法。

战斗整体追求简约但有层次、干净但有细节、柔和且轮廓可辨。普通、强化和终式有可区分的形态与节奏；飞行物由实体、连续尾迹、局部柔光与克制粒子共同表现，不以一团圆形柔光代替运动质感。热扰动等效果按受效范围选择，不要求全屏铺设。边缘冷区弱化场景，中央词条、HUD 和危险预警保持清晰。

冲击与扭曲可改变环境的观感，文字、真实危险范围和关键交互位置保持稳定。UI 的水晶层不能模糊正在输入的词，金丝和流光不能冒充敌人攻击预警。

## 视觉验收标准

看整体截图与实际交互，确认通透、柔焦、开放、金丝和魔法光具有统一层级；不能仅凭用了透明度和模糊就认定风格完成。

检查主菜单、出征、图谱远近景、固定详情、奖励、事件、战斗高压状态、设置、长记录及结算。重点确认文字可读、元素身份明确、金丝自然舒展且疏密有度、装饰与功能连线可区分、重点唯一、减少动态后仍有材质质感，以及切换内容时版面稳定。嵌入深度按其观感收益与成本判断，不以使用了复杂效果作为品质标准。
