## 3. 概念邻域，而非固定扇区

| 概念邻域 | 主要靠近 | 与其他邻域的实际联系 |
| --- | --- | --- |
| 寒气与晶体 | 寒墨方向 | 保存、穿透、碎裂、局部缓行 |
| 保存与时间 | 寒墨和纸灵之间，也向内部延伸 | 受热、护页、中继、聚合、继承 |
| 受热与结构 | 灰烬内侧，向寒墨概念过渡 | 薄壁、耐热、提前开启、持续份额 |
| 电性与路径 | 雷鸣方向及两侧 | 多目标分配、外壳转交、区域过路 |
| 复写与词形 | 纸灵附近及内侧 | 实际输入、保存、继承、准确收益 |
| 聚散与目标 | 内部多处共享区域 | 冰矛、雷链、纸灵运输、过量损耗 |
| 防御与生命 | 纸灵和寒墨之间，部分伸向灰烬风险内容 | 护页、弹反、低血、清房恢复 |
| 储备与回收 | 灰烬至内部和纸灵方向 | 灼烧剩余、无目标、跨房、区域结束 |
| 移动与位置 | 雷鸣、纸灵之间并连向内部 | 闪避、牵引、击退、有限地面作用 |
| 专精与兼修 | 各起点向内的共享邻域 | 全图可达，不挂在单独某两本书之间 |

内容中的概念词映射到共同词汇，形成语义权重。一个节点可以涉及多个概念；不强制一件遗物归属于唯一法书。比如“冷却墨片”与持续效果、保存、寒气都有联系，不能因为名字带冷就放到冰书最外端。

数值节点不是无意义收费点。生成器从其具体作用、使用条件及多向邻接安排位置；不能为了铺路在没有保存能力的初始路径连续塞满保存空间。

### 相邻书籍之间应当发生的过渡

| 相邻方向 | 连续的共同问题 | 可进入该邻域的候选举例 | 不应形成的结构 |
| --- | --- | --- | --- |
| 火—雷 | 已付持续作用怎样转交、铺开，并处理远近目标 | T07 回收、T17 留电、T45 区域、T47 区域传导 | 只靠一个“火雷共鸣”节点接通两棵树 |
| 雷—冰 | 结构怎样分配、穿透、分裂与接力 | T02 脆壳、T03 棱面、T13 导路、T16 近织 | 两侧节点各自成团，中间只留一条长线 |
| 冰—纸 | 怎样保存、聚合、防御，再把剩余释放出去 | T01 晶匣、T19 复写、T21 护页、T27 并卷 | 只有冰能做晶壳、只有纸能保存和防御 |
| 纸—火 | 延迟法术怎样受热、提前打开，以及余量怎样再用 | T05 热启、T07 余温入卷、T22 遗响、T25 递书 | 在某件指定纸火套装齐全前全段都无效 |

表格给出语义连续性，不指定节点必须排成上述次序或直接相连。火和冰虽不在环周相邻，其结构、热处理和保存内容可在内侧靠近；远处核心通过有用的近邻路径抵达。共同概念允许穿过多个邻域，四本书不各占一块封闭扇区。

## 4. 关键节点的特殊性

T 节点开放或修改一种通用规则；K 节点引入明确模式交换。K01 冰藏、K11 速朽在保存时间上冲突；K04 炉心、K05 燃尽在热处理上冲突；K08 长廊、K09 密网在传递组织上冲突。

不是所有关键节点彼此排斥。玩家可以跨区选择防御、运输和回收的兼容改写，支付沿途成本后组合。K19 与 K20 分别依赖合订、独卷，其互斥来自职责而非全图数量上限。

“T01 或 T19”等 K 节点前置是天赋购买条件；T 目录中的“使用条件”是战斗能否实际生效，不应自动翻译为指定天赋 ID 的硬前置。[数据契约](06-DATA-AND-ALGORITHMS.md)分别建模。

基础入口节点 T01、T13、T19、T49、T50、T52 除操作许可外还有对应效率改善，详见候选附录。因此原生法书已有相同入口时，取得这些节点仍有实际收益，不会被迫在长路径上购买纯重复开关。

T58 独卷在出征前从本书的两种原子改写中选一种，配置随本局冻结；它不是完整构筑配方。K20 只改变选定形状内部的目标分配，不同时取得两种改写：

| 主书 | 形状选项一 | 形状选项二 |
| --- | --- | --- |
| 寒墨 | 贯冰：集中成较少的穿透份额，减少侧向碎片 | 环晶：降低正面份额，命中时向近处展开已有晶体份额 |
| 灰烬 | 焰柱：更集中地兑现即时部分，沿实际施法线留下较小的有限区域 | 余烬：把更多已有热性份额留在命中处，即时伤害降低 |
| 雷鸣 | 束雷：较少目标分得较大电性份额 | 辐雷：更多近邻分得较小电性份额，单跳距离缩短 |
| 纸灵 | 孤刃：较少纸灵分享维持预算，攻击更集中 | 巡刃：较多纸灵分享原预算，分散覆盖、单只较弱 |

这些变化不额外产生原始收入；首轮幅度采用约 25% 的分配交换，具体次数取可执行整数并同步调整单份份额。没有合适目标时仍按同一份额账处理，不回退为另一套完整形状。

K20 的默认自动选择在每次人工完词时判定：主目标附近合法作用范围内至少有 3 个目标时采用分散分配，否则采用集中分配。只计算一次并冻结到本次法术，不在飞行中反复切换；阈值 3 属于统一可调参数。R168 余式匣把尚未分配的保存法术的判定推迟至真正释放时，代价是等待更久；它不能重新拼合已经分出的法术，也不能对同一份额反复重选。

合订与走到其他书根可以重叠，但不重复发材料。合订的直接价值是从任意发展方向指定一个非主书入口，以及该种材料的同池效率改善；它不代替远方节点的购买路径。独卷只关闭这个选择槽，仍可走长路径取得其他性质，详见[系统框架](04-SYSTEM-FRAMEWORK.md)的供给规则。

## 5. 遗物的获取与价格

所有普通候选都占一次标准奖励机会，初始制作预算 8 BP。数值遗物可叠层时，每层另占一次机会；机制工具默认只取得一次。事件临时借用按期限和实际机会成本评估。

继承式演化预算为旧资产预算加本次付出的机会预算；只有明确的演化才继承。候选中的“覆写底本”替换“同文底片”，“重订字谱”替换“聚字压片”，父效果移除；其他工具没有隐含家族前置。

除候选明确列出的这两条资产演化外，不自动继承旧族模板的遗物层数前置。七件法书深层改写保留主书限制并新增天赋许可，按一次奖励重新定价；不能取消旧前置后继续携带旧觉醒强度。

许可列非空的特殊遗物，要求相应 T 或 K 已实际分配。购买了许可仍须满足使用条件；许可不换算成这件遗物额外免费的 BP。当前目录为部分工具和七件法书深层改写设置许可，基础供给与可靠数值保持开放。

旧遗物的描述数字不是候选终值。例如原有 25% 直接增伤、全局 10% 时间速度均不能因为保留名称就沿用；后者已明确替代为局部防御窗口。

## 6. 候选参数的初始标尺

以下用于准备数据，未经过测试，不可当作最终玩家说明：

| 参数 | 候选起值与范围 | 调整时同时检查 |
| --- | --- | --- |
| 数值节点成本 | 1 点／约 3 BP | 路径总投入与实际覆盖比例 |
| T / K 节点成本 | 2 / 4 点，约 6 / 12 BP | 核心入口可用性、代价与交互 |
| 普通保存 | 等待 1.8 秒、寿命 5 秒 | 制作节律、移动敌人、短词和慢输入 |
| 速朽模式 | 等待保持 1.8 秒、寿命 1 秒 | 依靠已取得的结束释放，不能私自把普通等待改成 0.5 秒 |
| 基础复制 | 每约 12 个真实字符的制作额支持一份，威力约主术 35% | 四书共同收入、复制效率与材料竞争 |
| 回收 | 基础保留 35%，叠加后首轮上限 70% | 单次领取、跨房损耗、再投入与停笔收束 |
| 事件少量恢复 | 12 生命，不能溢出 | 生命上限变化与当前是否有实际用途 |
| 事件普通借阅 | 最多本章；付 1 次未来奖励或明确模式代价 | 章末到期和最后章节无后续奖励情况 |
| 暂减保存空间 | 1 个标准小份单位 | 空间不能减成负数；已有对象如何完成旧生命周期 |
| 事件普通迟发／早发 | 等待增减 0.4 秒；下限 0.2 秒 | 不用负等待跳过所有阶段 |
| 多／少落点 | 首轮增减 1 个，分配总额不变 | 没有可用目标与耐久单体表现 |
| 距离交换 | 单跳 ±25%，与落点交换绑定 | 实际近邻范围和路径费用 |
| 模式提高／降低比例 | 同池 ±10% 为起始幅度 | 指明影响哪个池，不能通用成独立全伤乘区 |

事件表每个“更多／更少”必须绑定相应参数键；不存在通用的“给所有属性加 10%”解释。未列出的专门效果采用[数据契约](06-DATA-AND-ALGORITHMS.md)的类型化规则与 BP 初估填写，不允许实现器自行更改其业务意义。

## 7. 涌现覆盖如何检查

这些候选不组成固定流派清单。检查采用操作交叉：

- 保存至少与热处理、防御、传导、运输、词形、聚合发生关系。
- 回收至少接受持续剩余、外壳剩余、无目标和区域剩余；各种入口不能双领。
- 同一外壳寿命变化在 K01、K11 与 T14 下有不同价值。
- 专精仍可接受 R069 晶体、R110 等通用路径工具；兼修不会自动获得所有收入。
- 所有原生法书都有未投资基线、早期机制与深层改写；没有只有纸灵能保存、只有冰火能分裂的硬编码限定。
- 输入慢、短命敌人和耐久 Boss 不会让整个组合语言停机；个别条件工具可以弱，整条发展路径不应完全失效。

上面的内容引用是检查实例，不是专属配方。参数与节点数量可调整，但不能通过删除难以评估的组合掩盖框架不足。
