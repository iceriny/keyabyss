# 墨境背景集成

依据用户提供的 `arcane_background.html`，保留墨青纸色、细纤维与页边法印，改为菜单和战场共用的 GPU 程序材质。

- 两组同权重、非平行的弯曲纹路，加一层较淡的等高墨纹；中央椭圆视场保留低对比柔边刻纹，外围逐渐清晰，兼顾词条阅读和冲击波折射参照。
- 约 16.5 秒的整体明暗呼吸、独立纹路形变、边缘刻印缓转及冷暖光晕移动，不依赖鼠标。
- 移除旧环境矩形纸片。战场复用实例批次，光尘双轴游曳，采用清晰小亮核与紧凑弱光晕，高档 35 颗；菜单复用固定粒子缓冲，高档 56 颗小光点。减少动态时隐藏装饰粒子并固定背景时间。
- 战场替换原有环境 pass，菜单增加一个全屏绘制；没有新增背景贴图、SVG 节点、逐帧纹理上传或 RAF。移除旧环境的中心同心轨道、重复六边形和规则参考点，纹路本身作为折射参照。
- 统一线性色彩处理，保留现有打字照明、冲击波/引力位移、质量分档和资源释放。

菜单使用独立 `presence=0.64`，减轻边缘黑色遮罩，保留可辨认的符文；中央柔化而非整屏压黑。战场中央保留 30% 纹理权重作为折射参照，向边缘渐入。对角法阵用线段距离函数恢复原稿全部 12 种符文笔画，保留不完整环带及内侧多边形，仍不增加贴图。

玩家初始、新开局及换房间位置统一为设计坐标 `(640,400)`，经视口等比映射后落在实际画面中心。

实现：`src/rendering/ArcaneBackdrop.ts`、`EnvironmentLayer.ts`、`MenuScene.ts`。原始下载文件未修改。

## 验证

`npm run build` 通过内容、依赖架构、TypeScript 与离线构建；`npm test` 157 项通过。历史弹道快照显式保留原有出发点，不改写既有轨迹；新增新开局/换房间居中验证。

`python -X utf8 tests/arcane-background-browser.py` 通过：离线菜单/战斗与实际视口出生居中、移除粒子和法书光圈后纸纹仍独立变化、系统及游戏减少动态、暂停逐像素一致、引力实际改变画面、打字照明、三级画质切换且纹理数量稳定、1024×640 / 1920×1080 / 3440×1440 / 3840×2160、返回菜单；没有浏览器或着色器错误。

本机 Chrome、1920×1080、高画质、150 帧轻负载运行样本：约 59.95 FPS，帧间隔 P95 16.8 ms，CPU 渲染提交 P95 0.8 ms，18 次战场绘制、15 张纹理。菜单为 4 次绘制。该样本不是密集战斗、长时或其他设备的性能结论，也不是与独立 SVG 原稿的同条件基准对比。
