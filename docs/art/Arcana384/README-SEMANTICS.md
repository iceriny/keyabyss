# Arcana384 语义说明

当前版本使用 384 个基础字符和 50 个常用合词。50 个合词包含 47 个双根词、3 个三根词，服务于日常交流与魔法叙事。它们已经替代早期的 80 组短语合字；旧登记只作为历史资料保存，不再进入活动连字查找。

## 基础根与常用词

384 个基础字符包括操作核心与明确列出的高频词根。这里的核心是本创作系统选择的可独立调用语义，不声称是自然语言或世界中唯一不可再分的原子。风、雷、海、雨、病、伤、饥、渴属于明确保留的高频词根；冰、生命、家园、灵魂、祝福、仪式使用已登记的合词。

基础根的核心义保持固定。合词可以由透明组合形成，也可以有可学习的约定词义。例如，忆是调取记忆的动作，记忆这个词指保存并可回想的内容；凝是凝固动作，凝水这个词指冰。构词不要求把每个日常词都改写成施法程序。

同一汉字与同序私用区 U+E000–U+E17F 指向同一基础符形。Clean 与 Imprint 共用这张映射；合词与标点不计入 384 个基础字符。中文释名只是词典标签，输入冰不会由字体自动翻译为凝水。

## 词界与合写

词间使用空格或可见标点，词内的根连续书写。只有完整连续根串恰好等于一个登记词时，才使用它的合字。未知长串保持基础字形，不在内部猜词界或捞取子串。

- 共行人：一个词，表示同伴
- 共行 人：合作与人分别书写
- 共行人身：未登记的连续根串，不自动拆成同伴加身
- 记忆·归域：中点分开的记忆与家园两个词

合字功能 dlig 只改变书写外观。同一个登记词开启时合写，关闭时按基础符形分写，词义始终相同。不可见连接符和零宽字符不作为可靠词界；预览会提示改用空格或可见标点。

## 冰与凝固操作

凝水是已经登记的词，表示水凝固后的固态水，即冰。凝(水)用括号明确表示凝固水的操作。区分来自词汇与写法，不来自 dlig 开关。

- 冷水：低温的液态水，只做性质修饰，不自动表示冰
- 水冷：陈述指定水的低温状态
- 水变冷：陈述水进入低温状态
- 使(水冷)：明确致使低温状态成立，仍未说明已经结冰
- 凝(水)：凝固水的操作
- 果(凝(水))：该操作产生的结果，可以用常用词凝水指称
- 水气：登记词，表示气态水
- 气水：登记词，表示悬浮细小液滴形成的雾

普通交流直接使用这些词即可。描述精确操作时，再写清对象、条件、范围与必要参数。

## 五种基础角色与核心语法

- entity：可被指称的对象、材料、状态、过程或数值
- quality：对对象成立的性质，修饰不自动包含致使或转化
- action：事件或操作，在精确操作式中明确对象与必要参数
- relation：连接端点的关系，其参照由表达或上下文说明
- logic：条件、量化、控制或数值运算标记

这些是基础根的主要角色；登记合词可以整体成为可谈论的概念、事物或关系。合词的派生义见 ligatures.json 和 compound-lexicon.json，精确操作的构式见 grammar.json。

QO可表示性质修饰，OQ可表示状态；变表达状态改变，化表达类别转化，使表达有意致使。复杂操作用括号与参数明确范围，例如 若(水冷)则(凝(水))。已登记词义与操作式发生同形可能时，使用明确括号区分。

关系可以写成 属(此,人)、水之温。后仍只指未来时段，前只指空间前方；触仍是接触关系，不凭汉语字面自动换成另一含义。

数位按十进制位值连接：二五六表示256，三八四表示384。十、百、千、万不另占基础根。

这些规则服务于创作、交流与排版。字体负责显示与合写，不自动翻译句子或执行操作。

## 版本迁移

从早期256字版本迁入384字版本时，索引与部分根义曾重新编排。不要直接把旧版PUA文本套用本字体；逐字对应见 migration-from-256.json / .csv。原20个退根的替换提示只用于人工迁移，不保证对所有旧句机械等价，也不属于当前50词登记表。

384版保留的重定义包括：冷／热为温度义，光为物理光，暗为低照度，音为可听声音；能为可用能量，凝／融为凝固和熔融，一为数字1，称为称量，概为概括。下面的完整根表给出权威核心义。

本次50词更新没有改变384根的含义、编码与字形。早期80组短语合字退出活动表，其中凝水的登记词义改为冰，原操作必须明确写为凝(水)。其余旧短语仍可按普通基础根表达书写。详细对应见 lexical-migration-80-to-50.json；旧合字材料存于历史目录。
