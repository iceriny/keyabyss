# 遗物能力图

> 历史归档：保留当时的方案、状态或检查结果，不作为当前待办、完成声明或实施约束。当前入口见[文档导航](../README.md)。

遗物关联由能力描述，主书、副书、天赋和已经获得的遗物可以提供同一种能力。资格与候选关联只读取当前能力，不按法书组合或来源 ID 写配方。当前内容有140件遗物，图由 `src/content/graphs.ts` 根据定义生成，并与144节点天赋图、24个构筑事件共用确定性星环布局和视口交互。能力派生在 `src/shared/combat-capabilities.ts`，内容入口仍是 `src/content/manifest.ts`。

| 字段 | 含义 |
| --- | --- |
| `provides` | 获得后提供的能力；本身不构成前置要求 |
| `needs` | 当前必须已经拥有的全部能力 |
| `modifies` | 会改变或连接的能力，用于展示现有构筑关联 |
| `requires` | 必须已获得的遗物 |
| `requiresLevels` | 指定遗物的最低层级 |
| `excludes` | 互斥遗物；选择检查同时读取候选和已拥有遗物两侧声明 |
| `evolution` | 用新节点替换已取得的旧零件；旧件不继续占有其原数值和资格 |
| `eventOnly` | 只由对应事件授予，不进入常规遗物候选池 |

能力词汇为冰结构 `cold`、火载荷 `heat`、传导 `conduction`、承载 `carrier`、防御 `guard`、释放 `release`、回收 `recovery`。法书数据声明元素和能力；已获得遗物的 `provides` 与副书、天赋提供的额外能力去重合并。

## 复写与加工

复写以有效人工字符累积供给，基础成本为12字；纸页同时存在数量取决于构筑容量。散页偏向更多、更薄的份额，重印偏向更少、更强的份额，速朽缩短制造与交付等待并减少寿命。不同来源的复写供给按合法增量累加，但每份载荷独立付费，不能把同一材料整份复制给所有页。冰晶、余烬与导电零件增加相应供给或加工能力；晶壳可在无纸供给时从人工主术划出已付威力。

载体攻击、防御、热释放与到期采用一次性出口。护持先消耗有限份额；遗响只交出剩余份额。兼容片段可聚合，纸灵运输占用原攻击周期。余热匣只接收符合来源资格的灼烧余额和合法剩余的折损份额；回收产物不再回收，跨房保留需要明确的储备能力。具体结算遵循 [战斗组合规则](COMBAT-RULES.md)。

## 图与事件

图节点与关系由内容中的 `requires`、`requiresLevels`、`excludes`、`evolution`、能力连接和内容明示的连接推导；能力交汇点只用于展示，不是免费遗物。共享布局按图定义确定坐标和路径，星环的区域与节点数量随内容变动，不维护手写固定节点坐标。事件有房间、章节或整局作用域；借阅在期限到后撤销，改写与熔接可替换现有零件，试炼在满足房间条件后兑现。事件变化会重编当前构筑，已付在途片段保留创建时快照。

## 候选与展示

先保留符合已有层级、法书、词长、能力和互斥条件的遗物；已被同效开关覆盖且不开启后续路径的零件，以及仅事件授予的零件，不进入普通候选。再从合格池按权重抽取最多三个不同选项。每次选中后移除该项，同一次候选中同家族其他零件权重乘0.55；继续使用相同的玩法随机数发生器抽取，因此同内容、状态与随机种子可复现。

| 条件 | 权重增量 |
| --- | ---: |
| 基础 | 1.00 |
| 已拥有且未满层 | +0.35 |
| `needs` 或 `modifies` 与当前能力相交 | +0.35 |
| 法书 `affinity` 匹配 | +0.15 |
| `awaken` 稀有度 | +0.35 |

所有合格项都有正权重，保留探索空间。选择项用中文短词显示已有能力关联，权重不构成排序或毕业套装保证。图鉴和选择页通过同一 `RelicIcon` 与 `src/ui/relic-art.ts` 使用每件遗物的独立 SVG。

内容校验检查能力词汇、互斥引用、层级范围和依赖环。当前实施阶段按要求未运行测试或构建，图布局、候选与整体数值待统一验收。
