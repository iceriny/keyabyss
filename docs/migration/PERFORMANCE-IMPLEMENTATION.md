实现采用一个仅处理尾迹几何的C#批次：GDScript一次打包现有采样点，批次内部复用列表、每段只算一次平滑节点、窄／宽尾迹共享弧长和法向，保留同弹窄带／宽带顺序。使用工程已有.NET依赖；没有迁移规则或引入线程。ArrayMesh复用资源，当前仍重建单个surface并上传，是否值得进一步做区域更新由这批端到端结果决定。粒子绑定只初始化新增粒子，原有集合每帧统一维护；隐藏的主术尾迹跳过构建。

流体活动对象的清理集合由线性数组改为字典，避免每帧对每个对象重新扫描所有活动身份；流体源的顺序、预算、求解频率和参数保持原样。
