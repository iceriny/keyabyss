外观依据 [金丝水晶](../../../docs/ART-DIRECTION.md) 与 [开放 UI](../../../docs/OPEN-UI.md)，本 Skill 记录实施方法，不另立视觉规范。审美相关设计、实现和实际画面检查由主控完成。

## 从问题定位到成品

1. 明确用户指的是哪一对象与绘制层，追到实际场景、材质实例、资源和事件。恢复旧效果时同时查触发、过渡、中断、声音和受效范围；旧截图只解释静态状态。
2. 先定位合成、坐标、像素密度、状态或时钟问题，再调整形态／参数。同样的矩形、黑边或锯齿不能套用上一次修复。
3. 正式改动保存到根工程，在独立 Forward+／HDR 2D 窗口观察。MCP 先刷新并核对副本；旧 CSS 数值、线性截图或嵌入缩放不能代替最终显示。
4. 按变化选择观察：静态材质看实际帧；动作看起手、持续、消退与中断；共用层改动复查正文／词咒／危险提示；涉及生命周期才扩到暂停、退出与画质切换。

| 冰火／流体、消退、慢动作、GPU 生命周期、首次卡顿、性能 | [效果与渲染实践](references/effects-and-rendering.md) |

Theme 管字体与层级，装饰／材质进入受效场景，正文和危险信息在清晰层。屏幕读取明确 BackBufferCopy 范围与绘制顺序；不为每个局部效果重复全屏复制。画质调整装饰成本，减少动态独立控制运动和闪烁，均保留攻击及范围辨识。

新固定材质／shader 接入正式原生资源和渲染准备清单；只 preload shader 或加载 Resource 不证明实际管线已准备。按 [TESTING](../../../docs/TESTING.md) 选针对性窗口检查，截图、断言、性能和用户审美认可分别交付。
