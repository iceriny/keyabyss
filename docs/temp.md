其中，纹理 `needsUpdate` 会触发 GPU 上传；动态整张画布每帧更新，会持续产生这部分成本。[Three.js 纹理文档](https://threejs.org/docs/pages/Texture.html#needsUpdate)

同时，全屏着色器按像素执行。即使画面中只有一个小范围引力场，之前的实现仍让整个屏幕计算它。DPR 为 2 时，像素数量又是 DPR 为 1 的四倍。再叠加 Canvas 阴影和多遍辉光，计算成本与“看起来有几个特效”并不成比例。

还有一个需要纠正的地方：**此前的测试证明了移除这条渲染链路能提高帧率，但没有测出每个环节分别占多少 GPU 时间。** JavaScript 的 `render()` 返回很快，也不意味着 GPU 已经画完。因此不能把所有问题都归因于某一个效果，更不能据此决定把效果删掉。
