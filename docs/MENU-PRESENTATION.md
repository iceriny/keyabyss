# 菜单原生光效与魔法纹路

首屏 `StartupGate` 原本已通过 `SessionView.prepare()` 加载 Three.js 并预热战场。此次保持这个时机，将此前主菜单中的清屏分支扩展为菜单场景，复用同一画布、WebGL 上下文和游戏循环。

## 职责与扩展

- `src/contracts/menu-scene.ts`：仅传颜色、流派参数、CSS 像素中心/半径与减少动态设置，不传 DOM 或模拟对象。
- `src/ui/useMenuScene.ts`：在法书、布局、滚动、系统动态偏好变化时测量特写和选中图标，交给 `SessionView.setMenuScene()`；卸载清除锚点。
- `src/rendering/MenuScene.ts`：独立场景和正交相机，共享一个平面几何、两个着色器材质。光弧、雾光、微粒由着色器绘制，不启用战斗的后处理链。背景由 MenuDust 的一个 Points 批次提供，完整菜单共三次绘制调用。
- `Game`：首页绘制菜单，进入战斗切回原生战场；低档菜单至多 30 次更新/秒，中高档至多 60 次。隐藏页面停止绘制，减少动态只在状态变化时重绘。销毁时一并释放菜单几何和材质。

菜单锚点随桌面窗口尺寸调整，仅提交可见元素的锚点。布局遵循 [项目核心规则](../AGENT.md)：不需要兼容小屏（移动端）布局，不为移动端隐藏特写或另设菜单排版。没有创建第二个 WebGLRenderer，也没有额外的动画循环。

## 首屏到主菜单的 7 秒节奏

点击或任意键继续后立刻闪亮法阵，并释放第一道明显但较轻的空间扭曲波，持续至 1.15 秒；1.15–2.4 秒停顿蓄能；2.4 秒重锤同步释放第二道强冲击波，位移强度约为第一道的 2.8 倍。第二道波在 5.45 秒前越过屏幕四角，此后余光消退，7 秒时完成主菜单交接。法阵局部辉光加强，扩散光晕的半径、亮度与扭曲仍共用同一时间轴。

入场音效分别跳过 0.17 秒、0.465 秒的素材前奏，使点击与降调重锤的瞬态起音贴住两次波的释放。蓄能声在 1.2 秒开始，按播放速率裁定持续时间，使尾部在 2.4 秒重锤到来时收住；重锤尾音在交接前淡出。

`StartupWave` 使用一次生成的径向位移图和 SVG `feDisplacementMap` 扭曲实际首屏像素，只在冲击波期间开启滤镜。临时动画循环在扩散结束时停止，组件卸载清理；不新建 WebGL 上下文。减少动态模式保留快速淡入入口，入场手势及过渡期间的输入不传给主菜单。

## SVG 资源

`art/runes/` 提供寒霜、雷鸣、纸灵、灰烬四个 1024×1024 的透明矢量符印，分别使用放射冰晶、折线闪电、交叠灵轨和火舌轮廓。素材登记在 `src/content/assets.ts`，构建复制到 `assets/art/`。

`MagicPattern` 负责统一引用、装饰语义和着色，可直接用于新的 UI。当前用于主菜单特写背景、法书卡片和通用窗口标题。使用原生 SVG 图片，兼容离线 `file://`；外部 CSS 遮罩在该环境会受到浏览器跨源限制，因此没有使用它。

## 下拉列表

共用 `Select` 保留原有键盘语义与焦点管理，改用上下刻线、深色渐变模糊底和金色渐变选中态，移除封闭描边、圆角与蓝色选中框。底色保留足够遮蔽度，避免后方说明文字干扰选项阅读。

## 验证入口

- `npm run build`：内容登记、架构边界、TypeScript、按需资产和离线发布。
- `npm run test:menu`：真实 GPU 像素变化、四法书切换、离线 SVG、下拉焦点操作、缩放锚点、减少动态、进出战斗共享上下文。
- `npm run test:ui`、`npm run test:startup`：现有交互与首屏回归。
