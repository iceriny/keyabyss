# 书脉天赋

天赋是一张144节点、四书区域与八条共享书脊互通的星环图。四种主书各有一个起点，所选主书的起点自动点亮且免费，并实际授予该元素的基础晶体、热载、传导或复写供给；从其他书区域连入其起点需支付该节点的两点费用。每个已选节点必须与主书起点连通，且满足前置能力和节点；撤回节点时，失去连接或前置的节点一并撤回并返还点数。普通与 God 配置均最多保留两个关键节点。

正常档案初始有两点。每累计完成 120 个有效人工字符获得一点，最多 24 点。只统计成功完成词条中的实际人工输入，主动结束也保留已完成的字符。旧战报没有 `manualCharacters` 时不追溯奖励。每个 `runId` 保留已计入的最大累计字符，继续周目只结算增量；结算 ID 防止同份战报再次奖励。

合订节点消耗两点，开放主书以外的一本副书；副书材料按有效人工字符与材料供给率积累，基础每12字一份，并受缓存和每词领取上限约束。独卷节点也消耗两点，关闭副书槽；后续结构节点仅按当前主书生效：冰增穿透并少分碎片、火改变储备与抽取、雷减少落点以集中份额、纸扩大有限编队与运输。合订和独卷互斥，没有通用30%增伤。遗响必须连接承页并实际拥有承载能力。

天赋在书库和战后调整，按主书分别保存分配。切换主书会重新检查该主书的图与副书。准备出征时可查看花费并选择已经开放的副书。战后记录保存出征天赋、副书、有效人工字符以及该次结算获得的点数。调整天赋用于下一次新远征，继续当前周目沿用本次远征的出征配置。

`resolveTalents(book, allocated, budget, godMode)` 是模拟与 UI 共用的入口，返回有效节点、花费、数值授予和能力。它清除未知、重复、超预算、不连通、缺前置、超出两个关键节点及互斥的输入。普通预算只接受有限数值，取整数后限制在 0–24；God Mode 不限预算，但仍检查图、前置、互斥和关键节点上限。节点遍历使用内容固定顺序，所以输入数组顺序不会影响结果。主书起点的免费 `grants` 与后续同名节点的授予相加。

普通进度保存在 StorageAdapter 的 `talents` 键，包括累计字符、各局最高计入值、结算回执与按主书分配。当前 `graphVersion` 为 2；旧图分配迁移时清空并返还为可用预算，但保留已累计人工字符与据此取得的点数。God Mode 配置单独保存在 `talents-god`，不奖励或消耗普通进度。新增的 God 战报只增加档案 `godCareer`，其检查点标记 `godMode`，不增加普通职业累计。God Mode 面板提供清理操作，重置其配置、清除 God 职业累计，并删除 God 战报与所有已标记的 God 检查点，包括已经超出最近 50 份战报范围的检查点。普通进度、普通战报和词库设置保持不变。现有档案不含 `settledIds`，以战报结算 ID 与按局检查点去重；旧 God 战报仍可识别并删除，但旧职业累计没有来源标记，因此不推算或改写该聚合值。

图与节点定义位于 `src/content/talents.ts`，纯校验位于 `src/shared/talents.ts`，跨局结算位于 `src/application/talentProgression.ts`。图位置由共享确定性布局生成，天赋与遗物使用同一视口交互规则。当前实施阶段按要求未运行测试或构建，整体待统一验收。
