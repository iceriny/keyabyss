# 整合设计与完成标准

本文件把框架、内容和算法组织成可理解的完整体验。它规定设计与验收口径，不记录历史步骤，也不宣称已经实现。状态见[阶段总结](../STAGE-SUMMARY.md)，工作清单见[TODO](../TODO.md)，详细目录见[总纲](00-DESIGN-BRIEF.md)。

当前先做 [M4 天赋图基础](../migration/M4-TALENT-GRAPH-PLAN.md)，再接正式成长与获取。构筑体验结合实际购买路径和 M5 遭遇判断，整体平衡在 M5 完成后的 M6 统一验收。

## 一局的完整流程

| 时点 | 玩家体验 | 必须成立的系统语义 |
| --- | --- | --- |
| 出征前 | 规划天赋，理解主书、模式和特殊遗物机会 | 合法购买闭包、预算、许可和配置冻结；普通／God 分离 |
| 前期 | 原生主术和早期机制立即有用，可深化也可转向 | 来源合并不重复供给，基础奖励提供探索入口 |
| 中期 | 保存、持续、运输、词形和回收改变零件用途 | 自动处理仍需支付，互斥与有限性可解释 |
| 事件 | 选择借阅、改写、资产交换、挑战或离开 | 报价冻结对象、数字、期限；原子提交和单次回执 |
| 后期 | 构筑优缺点在密集、分散、支援、耐久与弹幕中体现 | 公开遭遇压力，不按账号点数暗中改变规则 |
| 战后 | 理解关键因果，获得真实成长，保留历史构筑 | 房内结算、期限收尾、只按增量赚点，不重复发奖 |

前期不要求齐套才开机；后期不能仅靠点满全部模式消除取舍。继续周目仍沿用本次出征配置，累计结算只追加真实增量。

## 三类贯穿关系

### 攻击、保存、防御与释放

一份主术先把部分威力保存，剩余立即攻击。保存份额可用于挡伤，也可在合法出口释放；用于挡伤的部分不能再攻击。首目标致死不会删除已经支付的保存份额。

例如总额 100 中，40 立即提交、60 分成两份各 30；第一份挡伤消耗 12 后，最多剩 18 可释放，第二份仍有 30。过量伤害不倒流回账。这是解释所有权的纸面例子，不是平衡参数。

换成另一种可保存的材质，基本关系仍成立；热启可能提前用掉防御机会，中继可能消耗费用，运输改变实际位置。收益变化来自通用性质和成本，不依赖指定三件套。

### 持续剩余、回收与跨房

目标死亡或合法抽取时，只能回收未结算的持续份额；已经造成的伤害不再可用。耐久目标仍在承受伤害时，抽取减少它的后续伤害。用于治疗或下一词的同一份储备不能再归档一次。

事件改变容量或保留效率，可能使原先不重视的工具变得有用；恢复原容量不自动补满资源。短命目标与 Boss 都能检验这组规则。

### 临时能力、特殊许可与资产

借到遗响可以让当前合格法术获得结束释放，但不能伪造 T22 的出征许可；专属遗物仍不因此进入永久获取池。普通保存工具可按其自身条件取得。

借阅到期时，永久遗物保留，缺条件的效果暂停；借来的资产按合同归还。原有天赋被临时覆盖模式时，实际出征许可仍在。已有法术按冻结配置合法收尾，不把旧规则带到新制造的对象上。

## 跨系统不变量

| 关系 | 设计约束 |
| --- | --- |
| 性质与来源 | 性质可以改变，人工回执、敌弹事实与天赋许可不能任意赋予 |
| 同效入口 | 多种来源开放同一能力时去重；真实参数改善可以合并 |
| 复制与加工 | 消耗已赚额度，继承允许部分，不复制收入和已领取机会 |
| 资产与奖励 | 演化替换移除父效果；借还不刷新使用回执；机会成本真实计入 |
| 关系与连线 | 玩法关联不必是成长邻接，成长线必须真实可走、近邻、零交叉 |
| 模式与自由度 | 具体决策冲突才互斥，不设无理由的全局关键节点数量墙 |
| 显示与执行 | 图标、说明、预览和战报来自同一语义；可显示不等于已执行 |
| 成长与存档 | 新游戏不承接浏览器进度；本游戏后续版本保留已赚字符与回执，规则或拓扑变化重新验证，纯布局变化不退点 |
| 规则与表现 | 装饰不额外判定，显示随机不改变奖励或遭遇 |

详细所有权与错误语义见[数据与算法](06-DATA-AND-ALGORITHMS.md)；这些业务条件独立于实现模块的组织方式。

## 内容、路径与视觉的完成标准

- 所有保留候选实际接入，或有明确增删理由；名称、描述、登记和正式可用范围逐项对应。
- 每书初始投入至少开放一种立即可用的机制。相邻／对侧路径的 8–14／14–22 点作为候选观察值，M4 记录实际路线与用途，M6 再与成长预算共同校准；不靠无用节点凑连通。
- 图依据完整语义与真实购买约束生成，四书约 0.4R，成长线零交叉、仅近邻、不穿节点和文字。算法失败不能发布一个“交叉较少”的结果。
- 模式前置有合法购买顺序见证；路线搜索找到的路径可重放，未穷尽时不能声称不可达或最短。
- 两图共用基础，但关系含义准确；全屏空间、固定详情、检索与缩放可用，不在打开或拖拽时重新求整图布局。
- 按[金丝水晶](../ART-DIRECTION.md)统一材质、色彩、光效和节点层级；实际观察全图与细节，几何检查不能替代审美。
- 效果说明直白、图形可辨、全局设置不重复进入每个详情；阅读态安静，减少动态后仍保留层次。

## 统一收益与难度验收

沿用[统一收益模型](../COMBAT-BALANCE-DESIGN.md)：`U = exp(Σp·G)`，`ΔBP = 100·ln(U后/U前)`；增量效率以真实路径和奖励机会成本归一。推进与生存已经包含控制、防御和储备的影响，不再另计同一收益。

免费换模式采用同成本比较，不除以零；健康代价已在轨迹中体现，不再反向补成免费预算。反事实必须合法，不能把非法组合当作零分制造巨大协同。

| 样本组 | 要确认什么 |
| --- | --- |
| 初始成长、高手策略、后两档 | 不能用操作完全覆盖成长门槛；合法通关反例必须审查 |
| 初始成长、极高输入、理想选择 | 检查公开推进要求的乐观收益上界，不能只依靠普通机器人失败 |
| 成熟成长、中等操作、合理多样构筑 | 有跨书籍和规则方向的通关机会，不只一套精挑配方 |
| 同点数但缺协同的构筑 | 足够点数不等于自动通关 |
| 同预算单书、兼修、不同三机制组合 | 有场景取舍，没有一个方向全面支配 |
| 普通与较好运气 | 好运来自正式抽取和事件，不能直接注入全套毕业资产 |

输入速度只是策略的一维，目标与防御决策也要定义。原方案的 45／60、120／150 WPM、240 WPM 压力策略及每格至少 64 个种子，是评估设计候选；不等同于真人水平，也不是已经取得的证据。

预登记种子、词库、策略、权重和退出条件；保留失败、超时、缺覆盖及置信区间。0/64 不证明真实概率为零，绝对成长门槛仍需可解释的保守上界；上界不完备就明确未证明。中等成熟构筑的 10%–40% 通关率曾作为观察候选，最终口径不能靠换种子或权重凑出。

## 验证的边界

正确性按资源、阶段、资产、图谱、配置和记录组织；数值统一使用正式内容、模拟与获取流程，在 M5 完成后的 M6 进行整体评估。日常修改只做相称检查，见[验证范围](../TESTING.md)。

工程、视觉、性能、数据、完整收益和难度分别验收。节点数量、编译通过、局部测试、脚本成功或平均收益不能互相替代；没有实测的项目不写成通过。
