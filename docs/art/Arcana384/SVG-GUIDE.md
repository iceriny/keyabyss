# 秘序384 · 矢量使用

基础384根保留两套SVG：svg-clean/与svg-imprint/。当前50登记词位于ligatures-clean/与ligatures-imprint/，47双根、3三根；旧80词形不在这些活动目录。

基础viewBox为0 0 128 128；词形viewBox高度128，宽度208–312，须保持原纵横比。清线使用4.8单位圆端笔画，刻印为闭合填充轮廓。所有独立SVG均透明，无可见标签、字体或栅格依赖。

四份sprite与各自独立SVG一致。基础按rune-001等ID调用，词形按liga-001等ID调用。

词义见README-LEXICAL-50.md。合写与分写的词义相同；词间用空格或可见标点。刻印粗细请通过可变字体调整，或按中心线与冻结的v4几何方法重新生成，不建议直接对填充轮廓外加描边。
