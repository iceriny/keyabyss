# Arcana384 常用合词 50

这50个合词用于日常交流与魔法叙事。词义经过登记，合写和分写只是两种字形。47个双根词、3个三根词，不另增加基础字符。

## 怎样书写

- 词间用空格或可见标点，词内的根连续写；不可见控制字符不作为词界
- 凝水表示冰，无论合字开关是否开启；凝(水)明确表示凝固水的操作
- 共行人表示同伴；共行 人表示合作与人分别书写
- 未登记的连续长串不在内部猜词或局部合写
- 中文释名是查词标签，字体不会自动把“冰”翻译成“凝水”

## 词义与根义

时空、因果、心态的组合较透明；家园、生命、灵魂、祝福、仪式使用明确登记的约定词义。它们都可以像普通词一样学习和使用，无需在每次日常交流时写出完整解释。精确术式另用括号和必要参数写清作用。

记忆指保存并可回想的内容；忆仍是调取记忆的动作。身灵指与一个生命身份相联系的非实体主体；灵仍是一般非实体主体。术能指施术用能量，术文指术式文本。

旧80组参数化短语已退出活动合字表，并留在历史资料中。除凝水改登记为冰外，其余旧表达仍可按普通根表达书写；需要凝固动作时写凝(水)。
