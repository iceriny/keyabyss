# 秘序 · Arcana 256

256 个以概念为依据重新设计的原创虚构符文。圆、方、三角、弧线、断裂、围合与方向变化共同构成图形语言；每个符号都对应一个汉字和一个抽象概念。

## 先从这里开始

1. 用浏览器打开 `preview.html`。字体已经内嵌，可以离线试写、拖动字重、切换连字、搜索概念和点击字卡输入。
2. 安装 `fonts/Arcana256-VF.ttf`，在支持可变字体的软件中选择 **Arcana256 VF**。
3. 字重轴为 **wght 300–750**，默认 **400**。这是真正的轮廓插值，不是软件模拟加粗。
4. 如果软件不支持可变字体，安装 `Arcana256-Regular.ttf`、`Arcana256-Medium.ttf` 或 `Arcana256-Bold.ttf`，分别对应 400、500、700。

可变字体与静态字体的家族名不同，可以同时安装。部分软件会把 Medium 单独显示为 **Arcana256 Medium**。如果安装时软件已经打开，可能需要重新启动该软件以刷新字体列表。

## 如何输入

- 输入 `concepts.csv` / `concepts.json` 中的汉字，选择本字体，即显示对应符文
- 例如：`存无生灭 时空 因果 梦醒 光暗`
- 每个字形同时映射到私用区 **U+E000–U+E0FF**，按 001–256 顺序排列
- 汉字与 PUA 是同一个字形的两个输入入口，并非两套图形
- 原始文字仍然是输入的汉字或 PUA 字符；更换字体会改变它的显示方式
- 若需要把符文作为独立图形使用，可选用 `svg/` 中对应编号的 SVG

本字体只有 **256 个基本符号 + 32 个可选连字**，另有技术必需的空白 `.notdef` 和空格。没有普通拉丁字母、数字、标点或完整汉字字库；其他字符可能回退到系统字体。若要严格只显示符号，请只输入字表中包含的汉字或 PUA 字符。

## 可选连字

32 组双概念连字使用 OpenType **dlig**，默认关闭。开启后两个相邻字符通过共享笔画、围合或嵌套，重组为一个新的单字符宽度合成符号；不改变底层两个字符。汉字输入和对应的 PUA 输入都支持。

原有：始终、生灭、虚实、真幻、时空、契誓、内外、越界、因果、合一、梦醒、意志、命运、聚散、光暗、感应

新增：刚柔、轻重、强弱、深浅、松紧、对称、疏密、繁简、推演、概率、安宁、喜悲、传承、盈亏、破立、数理

在支持 OpenType 高级选项的设计软件中，打开“可选连字 / Discretionary ligatures”。不支持这个功能的软件仍可正常显示 256 个基础符号。`font-ligatures.png` 展示了真实字体的开关对比。

## 网页中使用

`Arcana256.css` 提供可直接使用的字体声明。可变 WOFF2 在 `fonts/Arcana256-VF.woff2`；三个静态字重也各有 TTF 和 WOFF2。

```html
<link rel="stylesheet" href="Arcana256.css">
<p class="arcana" style="font-weight: 500">时空 因果 梦醒</p>
<p class="arcana arcana-ligatures" style="font-weight: 700">生灭 光暗</p>
```

若已自行定义样式，核心设置是 `font-family: "Arcana256 VF"`、`font-weight: 300` 至 `750`。需要连字时加入 `font-feature-settings: "dlig" 1`。

## 文件目录

- `fonts/`：1 套可变字体 + 3 个静态字重，各含 TTF / WOFF2
- `preview.html`：内嵌字体的离线交互试写页
- `Arcana256.css`：网页字体用法
- `svg/`：256 个独立的透明背景 SVG
- `overview.svg` / `overview.png`：最终概念版字形总览
- `sprite.svg`：256 个可复用的 SVG symbol
- `concepts.csv` / `concepts.json`：汉字、含义、编号、PUA 和连字映射
- `concepts-design.json`：每个概念的图形设计依据
- `README-CONCEPTS.md`：概念体系、解释与组合用法
- `glyphs.json`：最终 256 个中心线路径源数据，版本 6 / concept-led
- `ligature-glyphs.json`：32 个专门设计的融合连字中心线路径
- `font-specimen-300.png` / `400.png` / `700.png`：真实字体渲染的完整 256 字检查图
- `font-weights.png`：真实可变字重对比
- `font-refinements.png`：字体位置细节优化的实际渲染对比
- `font-ligatures.png`：真实字体的 32 组连字开关对比
- `font-validation.json`：编码、字重实例、整形和文件检查结果

## 技术说明

- 版本：字体 2.000；语义映射 v3；图形源 v6（concept-led）
- UPM：1000；基础字符与连字等宽 1000，空格宽 500
- 从中心线生成封闭轮廓，采用统一点结构的兼容主字重插值；圆帽与外圆角采用二次曲线
- 转折与端点保留圆角，交叉笔画包含明确的重叠标记
- 已逐一验证 256 个汉字与 PUA 别名；已验证 32 组连字的 Han / PUA 整形；已实例化并检查 300–750 内 10 个不同字重
- 字重图和连字图直接由成品字体通过 FreeType / HarfBuzz 渲染，非 SVG 效果替代
- 离线预览嵌入 WOFF2，无外部字体、图片或网络依赖
- 预览页已通过结构与交互逻辑检查；浏览器实机交互尚未核验

## 本版细节优化

- 在字体中修正偏左、偏右或偏低的符号位置，使等宽单元的两侧留白与竖向位置更统一
- 定位偏移在所有字重中保持一致，不拉伸图形，也不改变原始中心线之间的关系
- 将圆形端点和外侧圆角改为真正的二次曲线轮廓，避免放大时多边形端点的折线感
- 原有 128 个输入汉字、PUA 对应关系和 16 个融合连字全部保留；新增 128 个字形顺序接至 U+E0FF
- 名称与版本升级至 Arcana256 / 2.000，可与 Arcana128 同时安装

这些符号是原创虚构设计，其意义由本项目约定，不代表真实文字、宗教或历史传统，也不进行自动翻译。
