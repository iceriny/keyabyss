# 组合空间与玩法探索

> 历史归档：2026-10-08 调整范围前的设计、计划或证据。正文中的要求与“下一步”不构成当前任务；当前实施见[交接文档](../../../migration/AGENT-HANDOFF.md).

定位：可持续使用的探索材料。以下不是固定流派、掉落配方或全部采纳的机制；去留见[内容取舍](03-CONTENT-DECISIONS.md)。设计目标见[总纲](00-DESIGN-BRIEF.md)，输入基线见[旧系统盘点](../../build-system-design/01-CURRENT-SYSTEM.md)。实际接入程度见[阶段总结](../STAGE-SUMMARY.md)。

## 1. 从“谁和谁配套”转向“什么能够被改变”

已有内容经常用书名或七种能力判断能否联动。新的设计先问：一份法术有没有尚未使用的威力？它能否保存、分开、传递、用于防御？它的外壳会受热、破裂或导电吗？这个机会来自输入、命中、消耗还是死亡？

每个零件只需回答自己的局部问题。玩家可以让这些回答串起来，不需要系统认识一套名为“某某流”的完整组合。

一个性质不能只用于显示。声明“易碎”，就应有具体破裂条件、破裂后去向和消耗；声明“导电”，就应有可经过的路径和有限电荷。反过来，“来自人工输入”是不可伪造的来源，不是随便加上的属性。

## 2. 可研究的对象、性质与操作

| 对象 | 能拥有的性质 | 可以改变什么 | 不该产生的额外操作负担 |
| --- | --- | --- | --- |
| 一份运行中的法术 | 伤害组成、形状、剩余威力、穿透次数、来源 | 分裂、集中、转向、保存、改换伤害组成 | 不要求玩家逐发选择加工顺序 |
| 保存法术的纸页或晶壳 | 容量、寿命、耐热、易碎、导电、可防御 | 提前打开、挡弹、运输、传电、破裂、回收 | 不要求挑选第三张纸页或手动排队 |
| 敌人身上的持续效果 | 剩余伤害、持续时间、冷却量、附着位置 | 提前兑现、迁移剩余、折损抽取 | 不要求小怪存活数轮才开机 |
| 有限的地面区域 | 覆盖、剩余作用次数、储量、持续时间 | 吸附、导电、维持局部寒气、改变落点 | 不要求摆放阵地；落点由正常施法决定 |
| 法书中的储备 | 类型、容量、来源、下次投入比例 | 转存、混合、封存、定额释放 | 不新增需要盯着的资源轮盘 |
| 已输入字符与字母标记 | 真实输入位置、词长、无错字记录、尚未兑换的标记 | 分散标记、延续输入、把已兑现收益改作保存法术 | 不把自动补全算成新人工输入 |

候选操作语言为：供给、附着、分配、保存、转交、受热、破裂、传导、释放、复制、聚合、回收、转换、防御、标记、留下区域。具体语义由系统框架、候选内容与数据契约共同约束。

## 3. 三十种值得探索的碰撞

表中“天赋／遗物／事件”只是可能的职责安排。任何例子都至少要接受一次同功能来源替换，不把三项内容 ID 写成专属配方。

| 编号 | 规则碰撞 | 可能出现的玩法 | 代价或反例 |
| --- | --- | --- | --- |
| X01 | 保存 + 防御 + 结束时释放剩余 | 天赋开放遗响，遗物提供纸页，事件改变守页顺序；防御成为攻击时机 | 防御已消耗的份额不能再次攻击 |
| X02 | 缩短寿命 + 遗响 | 短命纸页从“不稳定防御”变为更早释放 | 无遗响时短寿命仍可能亏损，必须在选择前说明 |
| X03 | 延长寿命 + 电性中继 | 原本拖慢输出的保存时间，变成稳定的连锁落脚点 | 中继只转交已有电荷，不每次经过就加满伤害 |
| X04 | 热加工 + 易碎外壳 | 热量使冰晶、玻璃或其他易碎结构展开 | 不是检查冰书加火书；必须真的有可消耗结构 |
| X05 | 热加工 + 耐热外壳 | 同样的热量转成暂存，留给后续打开 | 放弃立即展开，热量有容量上限 |
| X06 | 冷却 + 灼烧剩余 | 从“抑制现在伤害”变为“保护下一词可用储备” | 冷却不能既完整减速又完整保留所有伤害 |
| X07 | 碎片 + 保存 | 小份法术进入多个小壳，分散时间与目标 | 更多数量占更多容量，不能每个壳复制完整主术 |
| X08 | 聚合 + 保存 | 多份小法术装成一份，改善穿透或单体兑现 | 来源账保留；较慢且容易过量击杀 |
| X09 | 聚合 + 防御 | 集中的储量承受更强攻击 | 防御消耗更多攻击潜力，不能因数量变少而免费变硬 |
| X10 | 分散 + 中继 | 更多小型储存点让长路径传递可达 | 每次传递花费电荷，广覆盖不等于广覆盖全伤害 |
| X11 | 运输 + 延时 | 纸灵在原攻击周期带走一个等待中的法术 | 占用纸灵一次攻击，不叠出免费攻击周期 |
| X12 | 运输 + 受热 | 移动的纸页把热量送到远处再打开 | 途中防御、到时打开和受热打开竞争同一份法术 |
| X13 | 无目标 + 回收 | 原目标先死亡不再令已付威力全部消失 | 回收有损耗；安全空放不能刷出新预算 |
| X14 | 剩余灼烧 + 下词输入 | 小怪死亡把未结算部分留给新目标；Boss 活着则继续烧 | 不是把已经造成的伤害再存一遍 |
| X15 | 未命中 + 折返 | 分散敌人使一次落空成为下词附加 | 折返不等于永久追踪；同份剩余只结算一次 |
| X16 | 穿透 + 余量分配 | 第一目标只消耗自己所需份额，余量沿方向继续 | 没有长队目标时收益下降；新目标不重取初始威力 |
| X17 | 拉拢 + 穿透 | 聚怪遗物让冰矛、冲击或射线更易兑现 | 拉拢是敌人位置改变，不是额外伤害乘区 |
| X18 | 推开 + 链路 | 近距强链可能被推开破坏；长链却更安全 | 允许机制有负协同，UI 提醒真实条件而非宣布“不能配” |
| X19 | 地面区域 + 电性路径 | 区域成为一次有限过路点，跨越敌人间空隙 | 不能把整片区域变成无限复制的电源 |
| X20 | 区域持续 + 冷却 | 较慢的法术在移动战中提供稳定安全区 | 敌人离开后没有虚构命中收益 |
| X21 | 散字 + 保存收益 | 亲手输入亮字母的收益改为后续法术，降低瞬时过杀 | 标记既换了保存法术，就不能同时领取完整直伤 |
| X22 | 散字 + 多目标分配 | 从同一目标叠高奖励，变为让多个词各有机会 | 无匹配字母时不能自动创造输入或强塞奖励 |
| X23 | 长词 + 定额储备 | 较长输入积累更稳定的辅助份额，不依赖很短的连击窗口 | 每字符收益仍受统一输入预算约束 |
| X24 | 短词 + 释放节奏 | 单次份额小但更频繁释放，适合大量短命目标 | 不能用固定“每词送一份”无限放大短词词库 |
| X25 | 无错字 + 暂存增幅 | 准确输入积累有限强化，失误只影响尚未赚到的部分 | 不清空整局资产，不要求超短时间再次完词 |
| X26 | 闪避 + 有限留痕 | 路径留下少量冷区、火区或引力作用 | 付闪避充能和已存工作量，站在安全处不能刷产能 |
| X27 | 弹反 + 附着 | 返还攻击用现有法书材料加工 | 敌弹提供一次防御事件，不成为无限人工供给来源 |
| X28 | 低血增幅 + 防御分配 | 低生命玩法从盲目堆伤害转为主动依靠保存法术挡伤 | 治疗可能降低增幅；防御也挤占输出份额 |
| X29 | 兼修 + 通用加工 | 副书增加一种稳定材料入口，遗物决定其用途 | 多来源竞争有限供给，不能点四书就获得四份完整收入 |
| X30 | 独卷 + 来源替换 | 单书改写基础形状，仍可接受异质遗物和事件 | 独卷不应封死所有外来性质，否则涌现空间缩水 |

## 4. 事件应该制造新的问题

事件不必替玩家补最后一个零件。更有价值的是改变机会成本：

- **机会交换：**暂时扩大保存空间，但占用下一次奖励。之前嫌慢的聚合现在可能值得投资。
- **对象改性：**把本局纸页改成耐热薄片，热量不再催促打开而可暂存。防御价值、等待时间与后续遗物价值一起改变。
- **范围换期限：**一章内更广的连锁，代价是单份电荷更薄；不能只截取最高收益的一房评估。
- **既有规则分歧：**保留旧页防守或保留新页防守，影响哪些等待更久的法术先兑现。
- **资产改造：**把一件具体遗物改成另一种加工方式，旧效果确实移除；玩家能看见替换对象。
- **遭遇机会：**接受下一房敌人分散、持续推进或有支援单位的公开挑战，换取本局永久改写。不能靠隐瞒挑战内容制造选择。
- **暂借能力：**让玩家试用尚未长期投入的能力，但不默默替他永久解锁对应特殊遗物。

同一事件面对不同构筑可能有不同好选项，也可能全部不合适。退出必须成立；不能设置一个总是占优的无代价选项，再把其余选项伪装成取舍。

## 5. 价值反转与来源替换是探索的验收单位

| 可变因素 | 在一种构筑中的价值 | 换一个条件之后 |
| --- | --- | --- |
| 更长保存时间 | 多数直发构筑兑现变慢 | 防御、中继、聚合获得更长机会 |
| 更少目标 | 清杂覆盖下降 | 单体集中、降低重复找目标的损失 |
| 更多碎片 | 小怪清理更灵活 | Boss 缺少合适落点时，份额和容量浪费 |
| 更高回收阈值 | 起效更慢 | 短命目标留下的余量可以集中打耐久目标 |
| 更高热量 | 更容易提前打开 | 耐热结构中可能保存更久，也可能挤满储备 |
| 更多纸灵 | 运输机会增加 | 若工作量供给不变，只增加等待位置而不增伤 |
| 治疗 | 常规生存更稳定 | 背水增幅减弱，但可能换得一次公开危险试炼 |

对 X01，不只检查“雷书—护页—遗响”：换成冰晶保存火术、换成遗物授予防御、换成临时事件授予遗响，分别推演；再移除遗响、防御或热量，验证剩下的规则仍有用途。其他例子同理。

## 6. 探索的负例与边界

不采用“所有标签相同就互相增伤”、任意元素两两生成一种专属爆炸、让用户拖拽程序执行顺序、把死亡敌人保活到反应结束、给每种材料新增可操作资源条。它们分别会退回数值套装、配方表、额外操作或不符合快节奏打字的负担。

无限回收、自动效果再冒充人工施法、无成本复制完整状态、事件随意改写永久天赋，均不能因“涌现”而豁免资源与权限约束。

探索允许保留尚待判断的候选；是否采纳由内容取舍与框架决定，是否实现由阶段总结记录。外壳耐热、电性区域、有限地面作用和聚合防御等已有部分正式接入，不能从本探索表推断当前状态。星空只作为未来可添加的新材料和书位，不提前创造占位内容。

## 7. 探索的使用方式

得到六类对象、操作候选、30 个组合探针和七组价值反转。它们覆盖即时击杀、持续单体、分散群体、输入节律、移动防御和跨房周转；没有把任何三件内容定义为必须齐全的配方。

审查候选时检查：一个零件是否独立可用、是否只是重复开关、是否依赖特定书名、代价是否真实，以及能否支持至少两种不同的组合方向。结果维护在内容取舍和候选目录，不把探索例子变成指定路线。
