# 输入、法书平衡与法阵更新

## 输入与界面

- 方向键按下即朝对应方向闪避；Alt 自动择位；空格始终是弹反。按住产生的重复事件不再连续消耗闪避。数字保留给咒文输入和菜单快捷键。
- 自动择位比较周围 16 个落点：敌人距离、预测 0.7 秒弹道段、激光带、爆炸区、边界截短与离场心距离共同计分。固定候选数，复杂度为 O(敌人 + 弹道 + 危险区域)，不保证在全部落点都有威胁时完全安全。闪避仍提供至少 1 秒无敌。
- `navigation.ts` 集中声明菜单焦点顺序；控件退出浏览器默认 Tab 顺序，KeyboardLayer 负责导航与游戏式高亮。返回、导入、导出、删除、全屏等次要操作不进入主导航，仍可点击或输入词令。文本字段与下拉仍自行处理编辑和选项按键。
- `ArcaneCursor` 隐藏系统鼠标，显示尖角光标、交互光环与点击扩散；不拦截命中，位移按事件更新，离开页面或窗口失焦时隐藏。触摸输入不启用。
- 移除出征页的「双手打字，无自由移动……」说明段落。
- 设置新增独立「音效音量」（词令 `sfx`）。`sfxVolume` 控制音效总线，不改变氛围音；总音量仍同时控制两者。旧设置默认补为 100%。

## 法书

雷鸣普通直击倍率由 0.91 提高至 1.12，强化直击由 1.25 提高至 1.50；连锁起始倍率由 0.66 提高至 0.78，基础额外目标由 2 增至 3，合计覆盖四名敌人。过载规则与已有遗物继续叠加。

纸灵每次完成一个词条只增加一只已唤醒纸灵，基础上限三只。上限继续由法书、召唤遗物与终式计算，`summonCapacity` 统一管理；新增 `awakenedSpirits` 区分上限和当前唤醒数。持续时间耗尽、重新开局或换房时清空。终式保留额外唤醒四只与临时上限 +4；终式结束后裁回正常上限。其他法书通过遗物召唤的规则保持原样。

## 视觉与资源

- 四个纹路 SVG 升级为 1024×1024 viewBox，包含多重环带、60 枚原创字形、交错星形、六组副法阵和流派中心图案。`tools/generate-runes.ts` 可重新生成；`src/shared/sigil.ts` 共享笔画与几何构造。
- 首屏使用同套字形的分层 SVG 法阵，粒子由 24 增至 64；主菜单新增一个 Three.Points 批次，低/中/高档分别 24/56/96 个背景粒子。与两个法书着色器平面共用现有场景，完整菜单共三次绘制调用。
- 弹反成功的扩散位移强度由 36 增至 64，中高档叠加中心旋转扭曲。仍遵守减少动态设置和现有前景渲染顺序。
