# 秘序384 · Arcana384 / Arcana384 Imprint

## 3.002：384基础词根＋50登记词

本版用50个常用词替换旧80组短语连字：47个双根词、3个三根词。基础384词根的定义、编码、轮廓和度量与3.001完全相同；v4刻印处理也保持不变。

- 清线：圆端、圆角，统一线宽
- 刻印：方向性粗细、压力变化、侧壁刀痕和多样化起收笔
- 两种风格各有真实可变字体wght300–750，以及Regular400、Medium500、Bold700静态字体

## 直接使用

1. 打开preview.html，字体已内嵌，可以离线使用
2. 搜索根字、词名或词码；点击词卡会带词界插入试写区
3. 用空格或中点分词，再选择是否合写。切换风格、字重和合字开关不改变登记词义
4. 安装fonts/Arcana384-VF.ttf与fonts/Arcana384-Imprint-VF.ttf，在软件中选择对应VF家族
5. 不支持可变字体的软件可用各风格的Regular、Medium、Bold静态TTF；部分软件把Medium显示为独立家族

TTF用于安装，WOFF2用于网页，共16个字体文件。3.002使用原384家族名；已安装旧版时，请替换字体文件并重新打开使用字体的软件。

## 词义与合写是两件事

- 凝水是登记词“冰”，dlig开启或关闭都表示冰
- 凝(水)明确表示使水凝固的操作
- 共行人是“同伴”；共行 人是“合作＋人”
- 共行人身未登记，保留各根分写，不从内部截出共行人或共行

字体只执行书写规则，不翻译自然语言，也不判断任意整句是否有合法含义。词卡上的中文名称是释义；实际输入使用其词码，例如冰对应凝水。

## 整词边界与dlig

仅完整连续根串恰好等于一个登记词时才合写。字体在3根、2根规则前设置前后根约束，防止未知长串内部或跨词位置被局部合并。

词间用空格或可见标点；括号明确分开操作与参数。一词中请保持统一字体样式。不可见控制符不能用作可靠词界：预览会报警并对相关片段强制关闭合写；独立字体不承诺替作者解释这些字符。

dlig是可选连字功能，默认关闭。应用需支持Discretionary ligatures；不支持时仍可正常显示384个基础根及词的分写形式。

## 编码、字宽与矢量图

每个基础根同时映射到一个汉字和U+E000–U+E17F私用区；Han、PUA及二者混用均可输入。基础字宽1000，空格宽500，UPM1000。词形按构形采用独立横向字宽，两种风格的前进宽度和垂直度量一致。

本字体仅包含384根、50词形、空白.notdef与空格；没有普通字母、数字、标点或完整汉字字库。括号与中点等由使用软件的后备字体显示。

svg-clean/与svg-imprint/各有384张基础SVG；ligatures-clean/与ligatures-imprint/各有50张词形SVG。基础视框128×128，词形高度128、宽度按各自viewBox指定；不应强制压回正方形。

## 文件与迁移

- README-LEXICAL-50.md、lexicon-50.json：当前50词及固定词义
- grammar-lexical-50.json：整词、分词及操作表达规则
- lexical-migration-80-to-50.json：旧80表的逐项迁移说明。79串退出活动表；凝水登记义变为冰，旧操作义写凝(水)
- README-LEXICAL-ART-REVIEW.md、semantic-lexical-art-audit.json：50词的最终形义复核
- concepts.json/.csv、glyphs.json：不变的384根表及中心线原稿
- ligature-glyphs.json：当前50横向词形原稿
- font-ligatures-clean.png、font-ligatures-imprint.png：全部50词的分写/合写对照
- font-rhythm.png、font-lexical-examples.png：实际字体排版与词界示例
- font-validation.json、lexical-font-revision-report.json：字体、边界、旧表退出与基础轮廓保持检查

旧80图源和旧用法仅存档，不在本版活动字表内。从256版迁移仍须核对migration-from-256.json/.csv，尤其不要直接换字体解释旧PUA文本。

## 网页用法

引用Arcana384.css，使用arcana或arcana arcana-imprint类；font-weight取300–750，arcana-ligatures类开启dlig。输入词之间保留空格，例如“时空 命运 凝水”。

## 验证范围

已检查两种字体的10档字重、Han/PUA/混合输入、整词匹配、79条退役序列和词界反例，并检查小号与展示字号实际渲染。预览的控制逻辑、词义标签、隐藏字符保护和内嵌字体字节已验证；浏览器实机交互尚未核验。

这是一套原创虚构语义文字，使用者仍需要学习登记词义；图形不是现实魔法或历史文字。
