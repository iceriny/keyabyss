# 星空之书灵感与机制研究

研究更新：2026-10-18。星空之书以**引力改变危险的去向，以轨道承接捕获，以吞噬完成坍缩**为主线。一次词咒在目标处打开短暂视界：敌群向内偏移，有限敌弹脱离进攻轨迹、绕行后坠入，最后释放潮汐伤害。梦幻星海贯穿整个过程，力量显现为深度、弯光与短暂的缺光。

主术「引潮」、第三次强化「坍星」、闪避「掠星」与终式「星海归墟」构成同一套机制。玩家的判断集中在先处理哪个危险源、何时转火、何时闪避与释放终式；每次视界自行完成捕获和收束。观测器物提供书体与法印语言，恒星诞灭提供阶段表现。

本文是机制与表现设计草案，包含可供原型使用的初始参数，尚未经过玩法、数值或实机画面验证。现行产品仍为[四书](FOUR-BOOKS-DESIGN.md)，正式遗物范围与资格以[遗物系统](RELIC-SYSTEM.md)为准；星空之书和本文新增遗物均未接入。产品基础见[产品设计](PRODUCT-DESIGN.md)，研究状态统一见 [TODO](TODO.md)。

## 操作基础

玩家双手主要用于打字，没有普通移动，依靠御术和有限方向的闪避应对危险。敌人位置随来袭、移动、击退和死亡变化；玩家选择的是可以输入的词咒，而非任意坐标。

因此，天体中心、视界、透镜与观测对象应由当前词咒目标或实际威胁自动确定。新书的变化来自“这次文字让什么规律发生改变”，可用的选择仍是继续输入、换一个词咒、使用防御和挑选遗物。基础体验不依赖精确摆位或额外的持续操作。

正确字符可以逐步显露目标背后的星盘与薄弧，完成有效词咒才造成伤害并打开视界。视界有自己的有限寿命，随后输入其他词咒不会延长它。每次施法都能自行走完整个过程，输入速度只影响施法频率。

## 灵感地图

| 意象 | 最有价值的感受 | 可以进入玩法的动词 | 主要视觉形态 |
| --- | --- | --- | --- |
| 梦幻 | 远近与时间仿佛轻微错位，熟悉的战场显露另一个深度 | 显影、重叠、隐去 | 半透明星幕、迟到的光、前后错层的倒影 |
| 引力 | 无形而确定的力量，周围事物开始朝同一个原因运动 | 牵引、弯折、撕裂 | 弯曲星光、潮汐拉长、暗心与偏亮光弧 |
| 扭曲 | 两点之间的距离和路径发生变化 | 折叠、偏转、映射 | 引力透镜、重像、沿曲面折转的轨迹 |
| 吞噬 | 威胁跨过一个边界后消失，场面反而安静 | 捕获、坠入、转化 | 星光缺口、收紧的吸积纹、向内消失的尾迹 |
| 恒星 | 诞生、稳定、膨胀与寂灭，力量具有生命过程 | 点燃、演化、塌缩 | 珍珠般的光球、薄冕、膨胀外壳、致密余核 |
| 漫天星辰 | 小人物面对巨大星空，力量从环境整体显现 | 覆映、照见、降临 | 多层远星、银河薄带、场景深处显露的星穹 |
| 天体轨道 | 运动具有可感知的秩序，偶尔相遇形成重大事件 | 环绕、共振、脱轨 | 偏心椭圆、长短不同的弧段、短暂合相 |
| 观测与预言 | 看见将发生的事，并用文字干预结果 | 观测、预示、注定、改写 | 星盘刻度、淡薄先影、未来轨迹与现实重合 |

梦幻与漫天星辰统摄视觉；引力、轨道、吞噬组成主行为；恒星演化服务于开井、收束和终式。星图与占候保留为世界观灵感，不另设需要管理的预言状态。

## 参考资料与可借用的内容

### 深空与光学

[NASA 黑洞结构资料](https://science.nasa.gov/universe/black-holes/anatomy/)区分了黑洞暗区、发光的吸积盘、光环与喷流，并解释引力透镜及盘面两侧的明暗差。适合借用的是“中心缺光、周围光被弯曲”的关系。吞噬发生时可以先让附近细节向内滑动，再留下短暂的空缺；光不必在所有边缘均匀发亮。

[NASA Hubble 引力透镜资料](https://science.nasa.gov/mission/hubble/science/universe-uncovered/hubbles-gravitational-lenses/)展示背景天体被拉成弧、环或多个像的现象。它提供了扭曲的图形语言：目标后方一颗星被拉长，绕过暗心，再在另一侧显现。游戏中的路径折叠与攻击映射属于魔法机制推演，不能由一层画面折射自动代替。

[ESA Webb 巨蛇座星云影像](https://esawebb.org/images/weic2415d/)呈现气尘的层次、暗部和稀疏亮星，其可见颜色由近红外波段映射而来。适合借用前后遮蔽和稀薄结构，设计配色可以重新组织成月白、靛蓝、灰紫与微量珠光。

[NASA V838 Monocerotis 光回声资料](https://science.nasa.gov/asset/hubble/hubbles-latest-views-of-light-echo-from-star-v838-monocerotis/)说明，经过尘埃散射的光因路径更长而较晚到达。可据此探索“已经发生的事仍在远处显影”：一次冲击结束后，更深层的尘幕才被照亮。光回声可支撑梦幻感与回溯意象；预知未来则属于本书的魔法设定。

### 恒星与轨道

[NASA 恒星生命周期资料](https://science.nasa.gov/mission/webb/star-lifecycle/)将恒星描述为内压与引力之间的平衡，并介绍形成、燃料消耗、膨胀、爆发及致密残骸等不同演化路径。值得借用的是作用性质的改变：稳定时向外辐射，失衡时收缩或剥离外层，终点留下另一种具有不同作用的天体。具体阶段可按玩法选择，无需逐项复刻天文学。

[ESA 伽利略卫星轨道动画](https://www.esa.int/ESA_Multimedia/Videos/2021/07/The_orbits_of_the_Galilean_moons)展示木卫三、木卫二与木卫一的1∶2∶4轨道周期关系。它启发的是多个过程具有不同速度，却能在某个时刻重新对齐。用于键渊时，合相应由正常输入自动推动或由构筑改变，不要求玩家等待亮点转到某个角度再按键。

[Mobius Digital 对 Outer Wilds 的介绍](https://www.mobiusdigitalgames.com/outer-wilds.html)强调随时间变化的行星、不断被环境改写的地点和对规律的理解。可借鉴的设计方法是让天体确实改变环境，而不仅给法术一个宇宙名称；其自由移动、探索与时间循环不属于键渊的操作前提。

### 观测器物与星象

[英国图书馆 IDP 敦煌星图](https://idp.bl.uk/discover/learning/chinese-astronomy/articles/the-chinese-sky/the-dunhuang-star-atlas/)兼有分区星图、北天圆图和与占候相关的文字。星点、星官与古籍之间有天然联系，适合构成法书的观察体系与文学气质。借用小圆点的疏密、局部连缀和页间天象，不把整套星官名称变成玩家必须背诵的术语。

[格林尼治皇家博物馆星盘 AST0565](https://www.rmg.co.uk/collections/objects/rmgc-object-10727)具有黄铜材质与波焰形星指。其镂空网架、刻度和弯曲指针能与项目的自然金丝结合：输入时，一小段刻度对准目标；开井时，指针与偏心盘的长轴重合。器物结构主要出现在书体、局部法印和遗物上。

这些参考共同支持一种气质：古老的观测工具打开了很深、很安静、却会改变现实的星空。外部事实提供形态与联想，后续候选机制是设计提案。

## 战斗身份与完整循环

星空擅长处理**正在制造弹幕的危险源与其附近敌群**。主术先造成可靠的直接伤害，再用短暂引力争取局部空间；吞噬真实敌弹增加本次坍缩的收益。射手发出的弹尚在其身边时，优先输入它的词咒尤其有价值。来弹已经离开局部视界时，仍需御术和闪避。

敌人不发弹时，主击与基础坍缩照常成立。Boss 不必被拖动，也不必交出弹幕，才允许本书造成完整基础伤害。高速敌人可能离开坍缩区域，激光、近战和地面危险不能被视界吞掉，这些构成明确的场景弱项。

一次完整过程是：**选词咒 → 完词造成潮汐撕裂 → 局部捕获与有限绕行 → 坍缩 → 星光恢复**。每次施法的视界独立结束，目标切换只决定下一次施法的位置。捕获物属于这一次天象，不能积存到下一次强化。

| 技能 | 作用位置 | 主要作用 | 玩家当下的判断 |
| --- | --- | --- | --- |
| 主术·引潮 | 完词目标当时的位置 | 主击、轻牵引、有限捕获，短延迟后坍缩 | 先杀近身威胁，还是先压制正在发弹的敌人 |
| 强化·坍星 | 第三次施法目标的位置 | 更大的视界、更强的牵引与坍缩；本次捕获额度翻倍 | 将更大的一次投入交给耐久目标或自然聚集的敌群 |
| 闪避·掠星 | 玩家实际经过的闪避路径 | 留下短暂透镜带，卷离少量沿途敌弹 | 使用既有方向闪避或自动闪避，脱离当前危险 |
| 终式·星海归墟 | 释放时玩家位置，之后固定 | 共同解围；大范围、有限次数的捕获与潮汐收束 | 在持续来敌时开启一段稳定输入时间 |

### 参数口径

以下数字是同一套原型起点，便于比较实际收益，不代表平衡结论。距离使用1920×1080逻辑战场单位；技能时间使用世界秒，暂停冻结，慢时间同步放慢牵引、绕行与坍缩。

`m`为本词有效人工字符数，`B`沿用四书的人工投入威力：`m × 12`再计入本次适用的连笔、无错和遗物收益。辅助字母不增加`m`。标准五人工字符、无额外收益时`B = 60`。`U`为终式释放时五字符基准威力，只取适用于终式的角色与构筑增伤，不借用某次词咒的无错、首击或反制强化。

普通捕获额度`q = min(5, ceil(m / 2))`；强化为`2q`。一、三、五、七、九人工字符的普通额度分别为1、2、3、4、5。长词提高威力与单次捕获能力，短词保留更多开井机会；额度不跨施法累计。

## 主术、强化、闪避与终式

### 主术·引潮

完成敌人词咒时，目标直接受到`0.85B`潮汐伤害，其当前地点打开一口视界。作用即时到达合法目标，不增加需要瞄准的飞行物。中心固定在本次命中位置，后续不追随目标。

| 阶段 | 起点参数 | 实际行为 |
| --- | --- | --- |
| 开井 | `t = 0`；捕获／牵引半径140 | 结算一次主击与其合格遗物效果，建立本次视界 |
| 捕获 | `0～0.65秒`；至多`q`枚 | 合格敌弹进入范围即退出敌方威胁，沿偏心轨道绕行；范围内可移动普通敌人受到向心加速度`160 / 质量` |
| 收束 | `0.65～0.90秒` | 停止新增捕获和牵引；已有轨迹向内收紧 |
| 坍缩 | `t = 0.90秒`；伤害半径100 | 对范围内每个敌人造成`(0.20 + 0.05n)B`，`n`为本次实际捕获数；随后视界结束 |

敌人牵引只改变位移，不冻结攻击进度或取消已经开始的动作。主击不额外施加通用向外击退；视界提供本书的向内运动。Boss 与不可移动单位不接受位移，照常受伤。多口星空视界重叠时，敌人只受当下最强的一份原生牵引，避免连续打字叠成无限吸力。

主目标离开半径100后可以躲过尾段。主击杀死目标时，视界仍留在该处完成剩余阶段，能处理附近敌人与敌弹；没有额外敌人时自然空收束。已经付出的主击不因此转投，也不生成第二口视界。

### 强化·坍星

第三次有效敌人词咒完成时，用下表替换该次引潮参数。它是一口更强的视界，普通与强化不各开一口；与前两次视界的存亡、捕获数量无关。

| 项目 | 引潮 | 坍星 |
| --- | ---: | ---: |
| 主击 | `0.85B` | `1.10B` |
| 捕获／牵引半径 | 140 | 220 |
| 向心加速度 | `160 / 质量` | `220 / 质量` |
| 捕获额度 | `q` | `2q` |
| 捕获结束／坍缩时刻 | 0.65／0.90秒 | 0.65／0.90秒 |
| 坍缩半径 | 100 | 160 |
| 坍缩伤害，每个实际覆盖目标 | `(0.20 + 0.05n)B` | `(0.35 + 0.05n)B` |

强化的画面先出现一层稍大的珍珠薄冕，再向暗心剥落；真正的高潮是较宽区域一同向内凹陷。额外捕获代表本次可承受更多弹幕，不让已经吞掉的弹重新出现。

### 闪避·掠星

沿既有闪避的**实际经过路径**留下半宽40的透镜带，落地后再保留0.6秒。整次闪避共捕获至多2枚合格敌弹；被捕获的弹立刻失去威胁，在最近的路径点绕过一段小弧，0.35秒内消隐。透镜不伤害敌人，不牵引敌人，也不增加无敌时间。

它清理经过的窄带，减少落地附近继续追来的弹。方向、距离、充能与自动选点沿用共同闪避；预览不把尚未经过的位置显示为已经安全。没有捕获时，仍能看到一次浅淡的背景折光。

完美闪避先以起手时的真实危险判定，之后才处理掠星捕获。被掠星移除的弹不会补算擦弹、御术或反制；激光和地面危险仍通过原闪避无敌应对。

### 终式·星海归墟

释放时沿用共同解围：清除玩家周围650范围敌弹，420范围击退，普通／Boss冲量500／120再除质量；不取消已开始的近战、激光和地面攻击。清弹先完成，再打开以释放位置为中心、半径420、持续6秒的星海视界。

星海每1秒完成一轮天体收束，共6轮。每轮前0.75秒可以捕获域内至多2枚新敌弹，后0.25秒将其轨道收紧，轮末造成一次全域潮汐：每名域内敌人受到`(0.22 + 0.04n)U`伤害，`n`取该轮实际捕获数。未用额度在该轮结束时失效；被捕获的弹也在本轮结束，不留到下一轮。

每轮捕获阶段，对距中心120～420的可移动普通敌人施加`180 / 质量`向心加速度，仍遵守原生牵引不叠加和Boss位移规则。内圈停止施加吸力，但敌人自身移动、冲锋与攻击照常进行，内圈不是安全区。未捕获的敌弹保持原有危险，不随背景星海一起转弯。六轮最多捕获12枚，起手清弹不计入其中，也不给额外伤害或新遗物的捕获收益。

玩家继续正常打字，主术和第三次强化照常运行，不变成每次强化。主术捕获与终式捕获各有额度，一枚弹只归属于先实际捕获它的效果。终式期间沿用停止共鸣收入的规则。

画面中，深处显露一个远大于战场的天体边缘；每一轮都有宽而薄的偏心轨道逐渐向内落下。实际伤害范围由稳定的稀疏边缘光表达，远景巨环只承担尺度感。最后一轮结束，轨道一层层退入深空，留下仍可辨认的敌人和词咒。

### 三个具体局面

| 局面 | 五人工字符、`B = U = 60`时的结果 | 玩家选择的意义 |
| --- | --- | --- |
| 孤立近战／不发弹Boss | 普通主击51，留在范围内再受12；强化66＋21。无弹幕也有63／87基础伤害 | 集中处理耐久目标；高速移动可能损失尾段 |
| 射手旁有来弹 | 普通捕获3枚时坍缩21，主目标合计72；强化捕获6枚时坍缩39，主目标合计105 | 先压制弹幕源，同时减少真实危险；额外收益有上限 |
| 终式覆盖持续来敌 | 零捕获时六轮合计79.2；每轮捕获满时合计108，按每轮实际在域内的敌人结算 | 固定区域提供有限防守与群攻，持续输入仍承担主输出 |

这些是忽略护甲、易伤、过量伤害与离场的理论值。一个三词周期，对始终在范围内的单目标，零捕获合计213，满捕获合计249；差额36说明吞弹提供额外收益，主输出不以敌人先发弹为前提。

## 轨道、吞噬与结算边界

### 敌弹的三种状态

| 状态 | 碰撞与攻击归属 | 表现 |
| --- | --- | --- |
| 未捕获 | 原敌弹，继续威胁玩家；额度已满时也照常飞行 | 保持敌方色彩、弹头和真实轨迹 |
| 已捕获、绕行中 | 从敌方碰撞与威胁预测中移除；基础版不伤害任何单位 | 原弹头褪成月白细核，进入绕行弧；轨道逐渐缩短 |
| 收束 | 基础版吞噬并加入该视界一次坍缩；白洞遗物可改为有限回击 | 向暗心消失，或沿明确的友方出射轨迹离开 |

捕获是危险消失的时刻；吞噬是本次转换完成的时刻。绕行承担可读的时间过程和回击分支的真实出发位置。基础绕行没有接触伤害，不按圈数累计收益，不建立跟随玩家的单位。

只捕获当前清弹体系允许移除的独立敌方弹体。激光、地面危险、近战、冲锋本体、友方主术和已反射弹体不在捕获集合；敌人尚未射出的攻击也没有可支付的捕获对象。残影、尾迹和一个弹头的多层装饰均不另算数量。

视界建立时先处理范围内已有合格弹，其后处理新进入者。同一步超额时按距中心由近到远选取，同距沿现有稳定顺序；重叠视界按实际首次进入时刻归属，同刻优先较早建立者。捕获后的单枚弹不能再被另一口视界、纸鹤或御术领取。

### 输入、派生与生命周期

| 边界 | 本书采用的行为 |
| --- | --- |
| 输入与死亡转投 | 沿用当前词咒完成及死亡后输入延续；完成时有合法承接目标才开井；无目标不制造空视界 |
| 辅助补全 | 有人工投入的有效敌人词咒照常推进一次三次计数；伤害和捕获额度只用人工字符。要求完全人工的遗物继续检查完全人工资格 |
| 额外强化 | 行距尺等将本次视界升为坍星；与原生第三次同时满足时仍只有一口，三次计数照常推进 |
| 复制与追击 | 候选接线仅复制主击及既有复制比例，不额外开井、捕获或推进计数；坍缩、回击、终式潮汐没有人工主术资格 |
| 伤害与状态 | 本书不添加第五种敌人点数。主击按既有规则读取旧状态、消费与施加新状态；所有伤害在实际扣血入口只应用一次易伤 |
| 捕获收益 | 原敌弹伤害、词长和发射者强度不转成法术威力；只取本次`B`／`U`及捕获额度。捕获不提供人工输入收入、共鸣或反制资格 |
| 目标死亡 | 已打开视界保持原中心与余寿；死亡不续期、复制或转交视界。回击分支按其单独规则寻找合法对象 |
| 暂停与换页 | 暂停冻结全部阶段；段间继续推进。页胜利按现有飞行物延续机制暂停并交接中心、余寿、已捕获对象和已支付份额，下一页／跨章继续，不能重置额度或重复开井 |

书的原生牵引只移动合格敌人和已捕获对象。现有牵引墨／折返墨涡还会作用于弹道，联动时保持其各自作用与归属。实现阶段不能直接把现有全体弹道吸引调用当作新书捕获，因为它并不等价于“先移除威胁，再进入轨道”。

## 视觉风格与场面组织

### 三层气质

| 深空视界 | 暗心、偏心吸积弧、弯折光线 | 墨靛暗部占主，珍珠白亮边与少量冷金；内收运动形成重量 | 吞噬、引力、轨道 |
| 恒星诞灭 | 极薄日冕、剥离壳层、致密余核 | 冷白到浅香槟的局部变化，透明壳层之间保留暗缝 | 强化坍缩、终式每轮收束与退场 |

三层共同构成同一本书，沿用[金丝水晶](ART-DIRECTION.md)的通透、柔焦与开放边缘。书体承载古老星盘与星图，战斗主体用天体现象表达力量。金丝提供器物归属，天体光提供法术身份。

### 色彩与层次

参考暗色为墨靛 `#111A32`，中层雾蓝 `#7183AC`，局部灰紫 `#A9A0C6`，星光月白 `#E8ECFF`，恒星薄冕浅香槟 `#E5D3AA`；金丝沿用 `#C9AE72`。这些是概念配色，尚未在实际战场验证。

梦幻场面可同时有冷暖光，但主色占比稳定。灰紫只在薄层与重像中出现，月白小核、曲面暗心和偏心轨道承担主要识别。与纸灵的折页、寒墨的晶棱、雷鸣的分叉、灰烬的焰舌保持形态差别。

层次由深到浅依次为远星、星云薄层、局部天体现象、实体与真实攻击、词咒及危险预警。全屏天象主要改变远景和局部环境受光，输入文字、生命护盾与危险轮廓保持稳定位置。

星海的梦幻感来自稀薄层次和尺度反差：远星密而暗，中层银河薄如纱，近处只有少量明亮光点。一次小型坍缩结束后，更深处的尘幕才慢半拍显露；终式则让一直藏在远景中的巨大天体边缘出现。暗心保持小而深，柔光主要落在偏心盘的一侧，避免把全场染成浓紫或铺成均匀亮环。

### 几个关键动作

| 动作 | 起势 | 兑现 | 退场 |
| --- | --- | --- | --- |
| 引潮开井 | 输入时短刻度对准目标，只有装饰显影 | 完词主击时目标背后微凹，140范围露出稀疏边缘光 | 中心固定，转入捕获阶段 |
| 捕获与轨道 | 真实合格敌弹跨入范围，先转换归属 | 敌方弹头褪成月白，尾迹弯成偏心弧；近点加速、远端变暗 | 收束阶段半径缩小，捕获满额时可捕获边缘光变暗 |
| 吞噬与坍星 | 暗心周围细节拉长，强化多一层薄冕 | 全部捕获轨迹向内消失，坍缩范围短时内凹 | 留下一瞬缺光和迟到的淡薄尘光 |
| 掠星 | 真实闪避经过的路径压出细长透镜 | 有限敌弹被卷向最近的路径点，闪避主体保持清晰 | 小弧消隐，透镜边缘自然融回背景 |

| 星海归墟 | 远景逐层显露，巨大天体边缘进入画面 | 每秒的有限捕获与潮汐对应一次宽薄轨道内落 | 最后一轮后远景退隐，残余合法攻击按自身寿命结束 |

捕获用轻微的弯音确认归属变化，吞噬时短暂收窄环境声，留下低频内收与细小金属共振；坍星采用由细到宽再迅速抽空的动态。终式的潮汐保持较低响度，只在首轮和末轮加强仪式感。声音跟随真实事件，装饰星点保持安静。

### 自动构图与可读性

天体中心由本次施法命中点、实际闪避路径或终式释放点确定，轨道与星盘自动构图。薄椭圆表达立体盘面，地面稀疏边缘光表达真实圆形作用范围，两者不能互相冒充。背景折射可以弯曲场景，词咒、敌方弹头、危险预警与HUD在折射之后保持清晰。

减少动态时保留静态暗心、范围与阶段变化，关闭装饰公转、镜头震动、背景漂移和透镜动画；无伤害绕行可简化为定点细核与收束淡出，白洞真实回击的位置和运动照常可见。低画质可以去掉多层星云与环境照明，但归属转换、剩余额度耗尽和坍缩时刻仍清楚。

局部透镜、有限轨迹和稀疏远星值得先研究；大面积多层折射与漫天独立发光物需要在选定视觉后评估成本。当前没有实机效果或性能结论。

**控场与转火：零度批注＋初版书。** 先伤害并减慢危险源，再输入另一目标；前一个视界自行完成。主要收益是可靠的延迟范围伤害，捕获只是加值。

**局部聚拢与群攻：牵引墨＋爆墨瓶。** 遗物爆墨在主击时兑现，不能享受后续才发生的聚拢；真正利用持续牵引的是0.9秒后的坍缩。多名敌人实际进入坍缩范围，才算这组组合的收益。

**防御与危险转换：折返墨涡＋停笔书签。** 闪避起点留牵引、路径留掠星、落点清弹，慢时间提供更长的真实输入空间。已清掉的弹不会再回流成伤害或资源，范围之外的危险仍需处理。

## 专属遗物与觉醒候选

以下为五件普通遗物与两件互斥觉醒的设计草案，暂不分配正式ID、稀有度和奖励权重。普通候选均按一层描述，首轮不依赖重复叠层才成立。**普通遗物只改变引潮／坍星的视界**，不把终式、闪避或回批铭文的捕获变成同一套进攻来源。

| 候选 | 具体效果 | 收益与代价 | 独立图形 |
| --- | --- | --- | --- |
| 远日星盘 | 主术捕获半径增加40；牵引与坍缩半径不变，额度不变 | 更容易捕获周边来弹，适合射手散布；不会因范围更大而多吞或多伤 | 一道偏离中心的长椭圆，远端一枚细星指 |

白洞在视界结束时，从各捕获物最后的轨道位置发出友方攻击。优先指向原受术目标；其已死亡时，在中心320范围内选最近合法敌人，同距按既有稳定顺序；无目标则消隐。目标选择先于本次基础坍缩，坍缩后若目标已死亡，则沿已确定方向飞出。采用首击前追踪、速度720、最长1.5秒、首次实际接触一个敌人后结束。发出后目标死亡沿末速度继续，不再次换目标。它们没有绕行接触伤害、主术联动或二次捕获能力，不继承原敌弹的伤害与攻击行为，也不算御术反射。

致密星核先按普通`q`或强化`2q`取值，再减1。远日只扩大捕获，长夜只延长本次阶段；所有效果仍消费同一口视界的额度。薄暮与白洞可以共同生效，因为护盾在真实捕获时取得，之后才决定吞噬或回击。

| 永夜 | 长夜残页＋致密星核 | 普通／强化主击改为`0.15B／0.20B`，让出的`0.70B／0.90B`等额移入基础坍缩；坍缩半径改为该口视界的捕获半径。其余额度与1.4秒时序保持 | 把即时伤害转成较大范围的迟发潮汐；原目标离开时可能落空，聚拢与减速更有价值 |

白夜与永夜互斥，持有任一后另一条觉醒不进入报价。两条前置各自提供完整的单件作用；觉醒不另建星尘货币、技能按键或场外成长树。永夜转移的是既有主击份额，不在尾段复制一份原主击；白夜替换白洞的多枚回击，不同时发出光束与原弹。

五字符例子：白洞普通视界捕获3枚时，群体坍缩只保留12，另有三次各7.2的有限回击；白夜则是一束21.6伤害、最多实际命中两敌的光。永夜含两个前置，普通主击9、尾段63，至多捕获2枚再加6；强化主击12、尾段84，至多捕获5枚再加15。即时补刀能力下降，尾段是否覆盖到敌人才是构筑成立的条件。

### 来源资格

星空原生提供主术视界、有限捕获与坍缩来源；白洞提供轨道回击，薄暮提供护盾。新遗物的资格应按这些实际来源声明，并保持主书限制。金色光、轨道形状或“吞噬”名称不授予感电、易伤、纸灵或反制来源。

薄暮作为独立护盾来源可支持既有护盾容量增强；取得容量增强仍须先有薄暮、行距尺等实际来源。其他四书的专属、主术增强与终式遗物保持各自法书条件。R057的星空分支属于需要新增的接线，不能仅凭通用遗物身份宣称已经支持。

## 设计判断与验证边界

本方案的体验目标是：一次输入让附近危险发生可见的内收，玩家在继续打字时看见其自然坍缩。强度来自人工投入、局部覆盖和有限危险转换；轨道负责转换过程与遗物分支，未形成需要长期维持的队伍或资源槽。

| 判断问题 | 原型需要观察到的证据 |
| --- | --- |
| 引力是否真实且易读 | 轻牵引改变敌人位置，捕获改变敌弹归属；尚未捕获的危险与无害轨道能够立即区分 |
| 局部吞噬是否留有防御判断 | 额度满后剩余弹幕仍可读，远处来弹、激光、近战仍需要御术／闪避；不能靠停笔维持清场 |
| 低弹幕与Boss是否可用 | 在零捕获下也能靠主击与坍缩完成战斗；不能用高弹幕收益掩盖基础伤害不足 |
| 固定中心是否有代价 | 高速敌人可能躲过尾段；减速、牵引、转火和永夜的迟发群攻产生可解释差异 |
| 词长与辅助是否合理 | 同输入速度比较短词频率、长词威力与捕获额度；辅助字母不放大支付，复制不生成免费视界 |
| 遗物取舍是否成立 | 白洞有实际回击损失与命中，永夜有真实延迟代价；清弹、捕获、御术和反制不重复领取 |
| 梦幻星海是否保留可读性 | 大尺度远景与局部暗心明显，词咒、生命护盾及危险不被折射和柔光淹没；减少动态仍能判断归属 |

机制规则、阶段时序与表现事件应一致，特别是捕获时移除威胁、尾段伤害及页间余寿。性能研究应关注同时存在的视界、轨道与折射覆盖；可以合并装饰轨迹与降低星云层数，但不能因画质改变捕获额度、持续时间或伤害。
