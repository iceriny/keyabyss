# 产品设计

键渊是一款以打字施法为核心的肉鸽游戏。玩家选择法书与词库，通过输入、防御和局内遗物完成远征；持续挑战的积累主要来自本次远征获得的遗物，场外只提供少量线性成长。本文规定目标行为，当前代码状态见[阶段总结](STAGE-SUMMARY.md)，实施交接见[接力文档](migration/AGENT-HANDOFF.md)。

## 战斗与操作

- 双手打字，没有普通移动；完成敌人的词咒释放主术。首字母锁定，错字保留进度，Tab 切换目标，Backspace 放弃当前词咒。
- Space 御术；方向键定向闪避，Alt 自动择位闪避；单独按 Shift 在共鸣充满时释放终式；Esc 暂停或返回。
- 打字是主要进攻来源。御术和闪避保护输入并保留有力反馈，防御不能成为无需打字即可持续通关的主要输出方式。
- 完词、无错字、词长和法书节律可以直接带来额外效果。派生攻击不重发人工输入或无限递归；停止输入后已产生的过程可以有限收尾。不要求所有增益竞争同一个制作账户。
- 敌人被友方效果提前击杀时，已输入的词咒可继续完成；后续法术有合法目标或明确结束。威力按原词的实际输入投入计算，输入与施法各结算一次。
- 辅助补全由遗物「通灵羽毛笔」解锁：每亲手完成 4 个词咒获得一次机会，输入当前词咒的一部分后按 Ctrl 主动消耗。未持有遗物时不能补全，通用输入资源不能兑换补全；玩家可以选择继续输入，辅助字母不计人工成长或完整手打奖励，不自动截断长词。
- 基础防御从开局完整可用。御术只判断将命中玩家的敌弹、近战及冲锋：普通防御免除该次伤害并轻推周围敌人，挡住冲锋时终止本次冲锋并让双方弹开；完美防御强力击退并反射敌弹，成功后短时间可连续反弹，防住近战或冲锋时中断施攻者。圆形爆圈和横竖激光等区域攻击穿过御术，需闪避。反射保留真实飞行和接触，闪避轨迹与免伤反馈对应规则。准确避开即将命中的攻击属于完美闪避，包含区域攻击，奖励更多共鸣，并放慢战场至本次无敌结束。
- 冷区敌人进入有效战场后开放词目标和攻击；有效锁定后保留交战资格，击退到边缘不隐藏输入中的词咒。目标新词服从主术命中时序；耐久目标的连续输入空档在实际试玩中检查。
- 文字、输入进度和危险预警优先于特效。暂停、减少动态与低画质不改变输入和判定规则。
- 每波来袭方向表示一段扇区，敌人在扇区内独立分布；反制、爆墨与法书区域各有对应的触发和范围反馈。反制以大范围反射敌弹和打断动作（包括 Boss）为主，伤害为辅。敌弹以可辨认的光核和连续尾迹表达方向。

## 四本法书

| 法书 | 完整的基础体验 |
| --- | --- |
| 纸灵 | 瞬时标记与易伤、逐步唤醒和维持纸灵、交叉斩集火、符文纸鹤、狂暴；冷启动较弱，持续输入后成型输出更强 |
| 灰烬 | 阻挡式火弹、延迟灼烧与余热、焰印、递减叠加的火雾、全场火浪与火域；依靠伤害预判转火 |
| 寒墨 | 等额穿透冰锥与冰矛、移动和攻击减速、冻结、冰雾遮蔽、护盾与定向冰锥领域；以控制争取输入时间 |
| 雷鸣 | 衰减电链、感电连接、电爆主击与单条电链、闪避雷电路径、持续充电的雷电领域；利用敌群传播 |

每书拥有原生强化节律和终式，首次出征即可体验。局内遗物可以增加其他书的局部效果，仍围绕当前主书施法。出征配置只有法书、词库、词长与难度等必要选项，不设置副书、独卷形状、材料选择或天赋路线。

四书每第三次直接施法触发原生强化；终极释放均有近身击退和大范围清弹。易伤、灼烧、寒气与感电分别以 0～127 整数点数表达。完整机制、参数候选与实施定参见[四书战斗机制](FOUR-BOOKS-DESIGN.md)。各书保留不同启动曲线和擅长场景，按实际遭遇中的输入投入、战果与生存能力统一校准。

## 局内遗物与路线

局内构筑以重构前 Web 提交 `b713c6eea472f6c01d608710434e7daee407247f` 为基线：58 件遗物、三选一、有限叠层、法书倾向、局内前置和觉醒组合。逐项恢复其玩法意图；数值可按 Godot 的真实战斗校准，不能只保留名字而替换成资源加工。必要合并需说明用途重叠，不能用新增工具填回删减规模。

无错字增伤、短词与长词偏好、复制、连锁、冻结碎裂、纸灵、防御、恢复和少量风险交换共同提供本局变化。遗物应在当前条件下有可理解的作用；奖励按主书、已持有遗物、层数和词库适用性筛选，不要求场外天赋许可。

房间路线沿用休息、试炼、赠礼、庇护、付血换遗物等直接取舍。展示条件、代价与结果后一次提交；不建设借阅、抵押、归还、未来奖励债务和多层期限交易。图鉴提供检索、效果与局内觉醒条件，不要求大型关系图。

三选一支持鼠标及空词令状态下的数字键 1／2／3；查看详情时不触发背景领取。暂停中的构筑展示本局已取得的遗物，图鉴展示完整遗物目录；两者返回暂停。词库在出征前配置。

## 线性成长与连续挑战

场外采用全书共享的一条有上限成长线。有效人工字符自动累计，里程碑自动给予少量基础容错；没有可分配点数、分支、洗点、独立书籍培养或成长货币。基础机制和遗物池不由这条线解锁。级数、阈值与增益幅度留到代表性远征可玩后校准，不沿用 60 点曲线。

远征保留三章九场和五档难度。通关后玩家可以结束，或保留当前主书、遗物与层数进入下一档难度；最高档通关后可继续更强周目。沿途奖励继续积累，换档不重新领取已有遗物的获取奖励或刷新已消耗的一次机会。生命、恢复、重抽等延续规则先按基线核对，再统一校准，不默认满血或重置构筑。

最高档要求已有成长积累：高手也不应以初始成长、空遗物直接开局并完成最高档通关。成长来源包括连续远征积累的遗物，场外线性成长只提供少量帮助；保留遗物升档是到达最高档的重要路径，不把门槛全部压到场外数值。前四档不设置“高手初始成长也不能通关”的目标。

最高档门槛通过公开的遭遇压力与资源需求实现，不通过检测账号等级直接判负。中等输入水平在成长积累、合理局内组合与较好运气下，应有通关最高档的机会。具体输入水平、成长条件和通过标准由[收益与难度评估](COMBAT-BALANCE-DESIGN.md)统一明确。

胜利、战败、主动结束分别记录。连续挑战只结算新增人工字符和战果；重复结果不重复发成长。结束连续远征后的普通重开清空局内遗物，保留线性成长、设置、词库与记录。普通与 God 档案隔离，God 不参与正常难度平衡。

当前档案只保留一份未完远征。中途关闭游戏保留进度，再次出征时选择继续或重新出征；取消重开准备不会丢弃原存档。战斗中断后从该房恢复，保留已取得遗物、已记录收入与奖励事实，已发奖励不重复取得。远征记录专门回顾已结束的旅程与最终构筑，不承担继续功能。暂停中主动结束一次完成归档并返回书库。

God 仅通过菜单或暂停中输入隐藏词令 `imsuperman` 单向激活，没有显式开关。激活后致死回满生命、无限终式与闪避；本次应用会话内保持，重新启动应用恢复普通档。进行中的远征转入隔离档，激活前的人工收入保留在普通档，之后的收入只计 God；不覆盖另一份未完的 God 远征。

## 词库、说明与表现

玩家选择词库、词长范围与渐进规则，也可导入自己的词表。敌人词形服从选定词库，短语空格与辅助字母不冒充人工字符；习字不发战斗成长。战报保留准确率、输入量、速度、错误词和实际战果，帮助理解这次远征。

同时分配给敌人和道具的词咒首字母互不重复，每个当前合法词条等概率抽取；词长按去掉空格后的可输入字符数计算。长词敌人在当前范围内优先选择至少七字符的词，范围内没有时使用普通候选。渐进的初始上限为最小词长加三，每完成五词增加一；初始区间没有词时从所选范围的最短可用词开始，不越过玩家设置的上限。候选首字母耗尽时，敌人等待空位后补词，道具不生成无词对象，习字页展示现有合法候选；不以重复首字母补足数量。已发主术等待命中期间保留原词占用；正在输入的死亡目标保留到完词或放弃。

界面遵循[金丝水晶](ART-DIRECTION.md)、[开放式 UI](OPEN-UI.md)与[文案规范](CONTENT-STYLE.md)。保留四书插画、声音、独立遗物图形和开放排版；标题及主要操作固定，长正文内部滚动。普通控件不启用默认焦点链或悬浮 Tooltip。

新用户首次完成入场后配置总音量、中文释义（默认开启）、画质和流体精度，并通过真实战斗试映与实时FPS观察效果。试映独立于远征与存档；设置中可重新打开校准，暂停中的远征保持暂停。已有有效设置保留原选择，不强制重做首访配置。显示FPS默认关闭，可在设置中开启；关于页暂由设置进入，包含版本、作者、项目与反馈链接、许可致谢和本机保存位置。

校准中的真实战斗铺满背景，前景设置组居中，FPS保留右上；以柔焦和中央自然消隐的渐进压暗保护阅读，保留完整渲染分辨率与计算压力，推荐FPS大于60帧。垂直同步默认开启，可在设置的显示页关闭并保存；关闭后仍按当前显示器刷新率封顶，移动到另一显示器时更新上限，支持高刷新率。固定战斗步长保持不变。

词咒文字按背后画面的亮度渐进增加字形范围内的柔和下阴影，暗背景下不显示；不为整块词咒添加阴影底板。

Godot 是唯一活动工程，不建设旧浏览器档案迁移。已有 Godot 档案保留人工字符、设置、词库和记录；旧天赋配置不映射为无关能力，规则不兼容的进行中远征按明确边界结束并保留原档。
