## 获取、事件与规则口径

`AcquisitionService` 共用于奖励、赠礼、交换和演化；许可取自本局冻结天赋，临时能力不授永久许可。171 件逐项报告在 `.temp/godot-m4/rewards/acquisition-evidence.json`，包含合法配置、拒绝原因、主书、层数、父实例和能力输入。该报告是资格证据，不是每件战斗效果或平衡验收。

这些目录情境明确使用手工报价、供给资产或储备 fixture；不把它们写成 32 项随机自然出现。E17 的能力存在、尚未创建、真实 Unicode 创建标记、清房后历史资格和后续新标记变化另由 `.temp/godot-m4/events/battle-history-1461534/results.json` 验证，不能由手工历史替代。

R021 已同步至内容政策、Resource 和实施方案：持有生效期间合格基础经验增加 35%，每章额外经验上限为进入章前冻结的预定基础经验 25%。事件加敌不抬高基准，取得前与停用期不累计，返还／再取得不重置，累计小数余量避免拆分舍入差异。额外经验只进入奖励进度，未来债务容量只以预定基础行程担保。

事件恢复和开场附加使用真实储备的非消费快照；成交后才转移所有权。抽取直接并入当前术，不能伪造储备入口；力量与电荷回收按实际对象区分。一次性获取效果在候选事务内领取，保存后只发布。旧房结束 → 到期撤销与返还 → 有后续的试炼奖励 → 最终编译与保存 → 新章报价的顺序由 `RunSession` 持有。
