## 如何判断一项内容的状态

- **设计要求**说明应该发生什么，不代表已经实现。
- **候选参数与内容卡**允许调整；修改时同步取舍、语义和覆盖说明，数量本身不是完成标准。
- **展示数据**只证明名称、描述或关联已经登记，不证明效果进入正式战斗、奖励或事件。
- **规则登记与局部接入**仍需核对正式配置、获取、生命周期和记录；模块检查通过不等于全流程通过。
- **验收结果**只适用于其代码状态、内容集合、场景和设备，不能跨阶段累加通过数量。

当前进度以阶段总结为准，未完成工作以 TODO 为准；设计语义由对应专题维护。发现冲突时修正这三个入口，不再向旧流水追加一份并行计划。

「金丝水晶」是已确认的目标视觉规范，实际界面覆盖程度由阶段总结记录。不要从规范已经成文推断视觉已经实现或验收。
